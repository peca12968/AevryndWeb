# 女人偶外觀精修

保留 `public/assets/character-third-pants.glb` 作為來源；`character-female-review-v1.glb` 保留使用者評為 40/100 的上一輪版本，以相同鏡頭／燈光與上一輪材質設定比較。正式預覽載入 `character-female-refined.glb`，未修改男人偶。

## 重建

在專案根目錄，以 Blender 5.2 背景執行 `scripts/refine-female.py`。腳本使用相鄰工作區的 `ToolCache/meshoptimizer-1.2-build/Release/gltfpack.exe`，輸出資產與 JSON 清單。中間檔放在已忽略的 `.character-build/`。

以 `node scripts/test-character.mjs .character-build/authoring.glb` 驗證分層覆蓋、解碼、法線、蒙皮權重、預設中性臉型、十個塑形目標、身體壓縮誤差和衣物背面間距，再執行 `node scripts/test-contact.mjs`、`node scripts/test-head.mjs` 與 `pnpm build`。

調整資產時可設定 `AEVRYND_CHARACTER_STAGE`，將候選 GLB／JSON 輸出到 `.character-build/`，驗收後才替換正式預覽。`test-contact.mjs` 接受候選 GLB 路徑；`test-character.mjs` 可用 `AEVRYND_CHARACTER_TEST_ASSET` 指定候選資產。

## 內容

- 身體曲面細分，保留 UV、材質區域、骨架及每個塑形目標。
- 褲腰曲面修整與膝部、褲腳小幅褶皺；外套與內搭背面增加實際間距，修復原始資產重疊。
- 獨立 512px 虹膜纖維材質、較小的明亮環境瞳孔、440 根眉毛與既有睫毛。皮膚微法線使用獨立 UV 通道，嘴唇另有細紋與較低塗層反光。
- 皮膚、嘴唇、指甲、眼睛、髮絲、皮革和織物各自設定反光；保留來源皮膚色彩貼圖，織物與皮革細節使用程式材質。
- 15 個可切換材質分層、三種燈光、上一輪／本輪模型比較及既有穿衣／裸體確認流程。
- 服裝由內到外建立實際間距：內搭 1.8mm、長褲 2.5mm、外套 3mm，頭髮接觸 1mm 的修整目標。另保留壓縮容差；這些是局部投影目標，並非全模型最小距離的宣稱。
- 移除來源深入身體的衣物封口／髮片，放鬆接觸區衣料，再以三角面交線檢查補足頂點、邊中點與面內取樣。保留完整身體，不以關閉皮膚掩蓋穿模。
- 正式模型以 Three.js 實際解碼後的位置、骨架與塑形檢查接觸。量化位置必須用 `getVertexPosition()` 展開到世界座標，不能直接依賴量化屬性的靜態合併結果。
- 臉型輸入在同一事件內先做 BVH 接觸判定；不安全值以二分搜尋限制，必要時回復先前安全狀態。上一輪使用已修整的資產，套用當時材質設定供比較。

## 接觸驗收範圍

`test-contact.mjs` 檢查身體與所有外部服裝／頭髮、服裝層彼此、頭髮與服裝之間共 18 組三角面相交，以及所有外部頂點、三角形中心與邊中點的身體接觸取樣。另檢查 32 組臉型極值組合、160 次連續設定、刻意移入頭部的反例，以及滑桿安全回退。

安全範圍是網站目前的固定姿勢與五項臉型塑形；旋轉檢視不改變角色姿勢。這不是通用剛體物理或動態布料模擬。新增骨骼動畫、體型變更或新服裝時，必須重新建立接觸限制與驗收。髮片相互交疊屬既有髮型的體積呈現方式；眼球與睫毛根部的解剖接合不屬這份外部分層交線測試。

## 實際限制

這是現有資產的即時外觀精修，並非掃描重建或完整角色重製。皮膚採用少量包覆漫反射近似，沒有宣稱為物理體積次表面散射。眼睛使用表面塗層近似濕潤反光，沒有額外角膜體積。頭髮改為 220 束連續曲面髮束、3400 條細絲、140 條碎髮與 308 條髮際線短毛，再依接觸情況修整。這仍是即時網格與透明遮罩的髮型，並非逐根圓柱毛髮光學模擬；本輪未新增表情動畫或動態布料模擬。

Blender 可用於資產多角度渲染檢查；離線渲染與網站的 Three.js 光照不完全相同。自動測試使用正式 GLTFLoader 和 MeshoptDecoder 執行 CPU 幾何檢查，不代表所有瀏覽器／GPU 都已完成互動驗收。

## 匯出注意

新建塑形明確使用 `from_mix=False` 並將 `value` 歸零。先匯出未壓縮 GLB，再由 gltfpack 壓縮，保留必要 UV、節點、材質與自訂資料。不要啟用 Blender 的中間 meshopt 壓縮；本次近景檢查發現該路徑會產生曲面瑕疵。

## 第二輪頭部材質與髮束

`hair-groom.py` 重建連續髮流，`head-detail.py` 建立獨立微法線、皮膚粗糙度、唇紋、虹膜紋理與髮絲遮罩。髮絲遮罩以 GREATER_THAN 節點匯出 glTF MASK，避免 BLEND 導致整片半透明髮卡。

完整人體 UV 貼圖的 imagegen 候選生成被工具拒絕，未採用任何生成影像，也未修改原始皮膚色彩貼圖。本轮新增細節由 3D 材質與幾何建立。

`AEVRYND_SKIP_CONTACT=1` 僅供指定了候選路徑的離線材質檢視；其輸出不得替換正式模型。正式驗收必須重新執行接觸修整與測試。
