# Aevrynd female-next r0491

This Blender file contains the r490 B control and two unaccepted graduated grooms on the same complete neutral woman. B is visible on opening. Each layout has 15 independently drawn outer paths and nine shorter paths beneath the rear and sides. The shorter paths receive 5,584 existing strands. All 24,831 strands keep their original bound roots, point IDs, radii and material.

The matched views show a narrower rear outline and a clearer diagonal front sweep in B. The enlarged opening near the center of the rear and the sheet-like side sections still fail the appearance gate. The r490 B reference and the r491 B front sweep are useful comparisons for the next construction.

Both native guide layouts regenerate exactly when the saved file is reopened. Moving a rear inner guide station by 5 mm changes the 1,177 strands assigned to it. The other sections remain exact, and restoring the station restores the evaluated positions. Earlier research banks remain in the immutable source archives.

Both layouts had two oriented control-point warnings that all three recheck rays placed outside with radius clearance. For B, Blender's Curve to Points node in Evaluated mode produced 949 samples on each of 24,831 curves. The audit checks the ownership, root and tip coordinates and endpoint radii on every curve. The 55 negative oriented sample warnings all resolved to outside with clearance under the ray recheck. The smallest gap after that recheck was approximately 0.0848 mm, at curve 9270. The inherited skin fixture has known boundary and orientation defects, so ray classifications are evidence rather than a closed-solid certification. Native sample spacing, hair self-contact, garments and motion remain separate checks.

The direct Curves conversion attempt failed. A temporary mesh host then read the evaluated samples without modifying the saved groom. The system commit reserve interrupted it after 12,480 verified curves. The next worker checked the source hash and resumed from that saved boundary. Both implementations and all execution logs are retained in the evidence directory.
