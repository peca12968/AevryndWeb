# Aevrynd female-next r0487

This Blender source archives two unaccepted hair studies on the same neutral woman. A drapes around the outside of the pinna. B sweeps toward the back of the pinna and is the active preview on opening the file. Both replace the r486 left and right rear falls with shared posterior guide ownership.

The 15 matched renders show a closed posterior gap and a clearer ear silhouette in B. Both studies introduce a conspicuous lateral ledge around ear height, a deeper crown notch and a rigid silhouette at character scale. The selected neutral contact probes still contain negative gaps. Both candidates are rejected for character adoption. The assessment leaves prior scores and adoption decisions in force.

The two data files reproduce both sets of 140 guide paths and the eight guide weights per follicle. The source has 24,831 strands per variant with the same root coordinates, persistent IDs, skin binding and radii as r486. An independent Blender session reconstructed each geometry bit for bit. Moving one posterior guide and regenerating the displayed strands changed 2,262 dependent curves. The operation restored the original evaluated positions before rendering. The original file remained byte-identical during this test.

The contact evidence compares matching point indices selected by the union of the control and two candidates in each anatomical window. It uses the neutral skin's nearest oriented triangle and subtracts strand radius from the signed center distance. A point selected by one candidate can lie outside that window in another candidate. The report gives the negative sample counts, the lowest sampled gaps and the coordinates of those points. Full strand contact, strand self-contact, animation, clothing, export and Aevrynd timing remain unverified.

The evidence folder contains the guide diagnostic views, matched complete renders, Blender Python scripts, construction receipts and the decision report. To regenerate the study, place that evidence in a round working folder with the previous r486 source and the r470 camera and r477 render references at the sibling paths used by the scripts. Place both NPZ files beside the author and preview scripts. For a fresh rebuild, run the guide script, inspect its four diagnostic views, run the author script and run the preview script with Blender 5.2.3 LTS. The guide visualization uses thickened diagnostic strands. Complete renders use the original strand radii.
