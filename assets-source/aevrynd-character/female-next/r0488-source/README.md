# Aevrynd female-next r0488

This Blender source holds the A tapered bob and B swept layers on the same complete neutral woman. Each layout gives 15 locks independently authored middle turns, tip turns, crest relief and lengths. The source opens on B. A is the preferred research starting point because the rear coverage is more continuous.

The matched front, rear oblique, profile, posterior detail and full-body renders show a smaller ledge at ear height, a closed crown notch and distinct end lengths. The close views still show broad, flat locks with abrupt edges. B exposes a larger opening above the nape. Both remain unaccepted for character adoption.

The 24,831 original follicles, persistent IDs, radii and binding attributes are preserved in both variants. Each follicle is assigned one lock and generates its own trajectory in an anatomical chart of the actual neutral skin. The layout is stored on the Blender object as `Aevrynd_Lock_Stations`. The native witness curves show the resulting path shapes. They are outputs of the layout and carry the original source curve IDs. Independent replay reproduces both saved banks bit for bit. Changing one crest setting in the opened file and replaying it changed 2,019 evaluated strands in that lock. Restoring the setting restored the original geometry.

The earlier ear and rear subsamples had zero negative gaps in both new variants. Checking all 1,986,480 evaluated control points per variant found 3,699 nearest-normal negative radius-adjusted gaps for A and 3,384 for B. The largest groups occur at the first five points after attachment. Three independent ray directions confirmed that the deepest departure center for each layout is inside the crown. The deepest free-length sign warnings gave zero intersections along all three directions and lay outside the measured exact radial skin in both variants. The report preserves that disagreement. The negative counts are nearest-normal probe results and cannot be interpreted as an exact count of penetrations. Complete swept-strand contact, hair self-contact, dynamic contact, clothes, export and engine timings remain open.

The Blender source, skin atlas, layout generator, audit scripts and matched renders are archived together. For replay, place the atlas beside the r488 scripts and use the previous r487 source, continuation and preview scripts along with the r470 camera and r477 render references at the sibling paths named by the scripts. The scripts run offline in Blender 5.2.3 LTS. Both assets carry the same source attribution and historical qualifications as r487. The older common ear envelope and repeated dense combing remain retired.
