# v249r1016–r1019 contiguous eyelid topology review

This review records four rejected or technical-only eye-topology studies. None is approved for the website.

- `contact-sheet-r1016.jpg`: fragmented r1015 boundaries create stepped dark seams at every inner-wall depth.
- `contact-sheet-r1017.jpg`: the cut is reduced to one connected 24-edge boundary per eye and keeps zero body/eye/lash overlap at frames 1/20/33/61, but the visible rim is too coarse.
- `contact-sheet-r1018.jpg`: a shallow 0.35 mm wall stays collision-free but does not materially improve the face; 0.65 and 1.00 mm produce 26 and 44 overlaps.
- `contact-sheet-r1019.jpg`: anatomical-guide projection remains collision-free through 2.126 mm maximum ring movement, but cannot replace the missing support topology.

Strict decision: retain r1017 only as the locator for a denser local eyelid patch. Reject r1016, r1018 and r1019 visually. Keep website v83 unchanged.

All renders use the inherited fixed review lighting. These studies change no material, light, exposure or view transform and do not darken the character.
