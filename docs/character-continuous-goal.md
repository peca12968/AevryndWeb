**開工卡最多六行，寫完即做：** 來源與受保護收益；完整頭／身最多三個問題及唯一主缺陷；參考／權利與三維構造；直接 Blender 動作及改變的失敗前提；可見判退條件；原始開工、具體預覽截止與資源上限。

2. **把參考變成可編輯的空間關係。** 說清表面、內壁、依附、根梢、變形和材質如何成立。做頭髮時先直接建立符合當前頭皮的分線、髮際線、根到梢導引、髮束層級與整體流向，再增加細絲；用多角度真人參考判斷。來源連通片、名稱或端點不自動代表毛囊、完整髮束、父子延續或伴隨層，重用前要有角色／連續性依據。原生雕塑、曲線雕梳、網格編輯或程式皆可；工具選擇服從造型，更多公式／點／纖維不能代替構造。
3. **限時支援，只做一個可判斷候選。** 原開工起初始研究／診斷／工具支援合計最多10分鐘；一次最小實作確認能力便直接製作，不反覆巡查來源、API 或求解器。預設一個候選，最多三種構造不同的方法，不必做滿、不掃參數。權利未知內容只作參考；採用已核實來源或原創製作，不為期限繞過權利。
4. **通常30分鐘內交完整預覽。** 自原開工計時，輸出與基線相同鏡位、光、曝光、姿勢的完整頭／身 A/B 加缺陷角度；操作改動加實際中間、終態及回中性。自己實際查看圖／動作，退出碼0不代表完成。孤立零件、導引、代理、灰模、髮殼、生成圖及他人作品只作診斷／參考。延期須到期前留下已有產物、理由和新截止，原期限及逾時仍保留；純啟動修復不另算人物輪次。
5. **完整外觀不成立就停止該方向。** 主缺陷無可辨識淨改善，或完整真人感／受保護外觀退步，立即判退，停止其精修、變體及廣泛稽核，只留最低重現、獨立重開、權利與回退。造型／根梢構造失敗，不用顏色、密度、半徑、曝光或遮蓋補成「通過」，也不交使用者替判已知失敗。方向成立才補第二照明、相關操作與接觸；不要求每輪先證全域，也不以漂亮局部抵銷完整失敗。
6. **驗證實際顯示幾何。** 獨立重開 .blend，操作現在求值後的可見結果、完成動作並復原；確認控制真正驅動當前人物，相關範圍無已知失敗。導引、屬性、is_bound 或單點編輯只證其元件能力。頭髮自然動態須看實際髮型轉頭、急停、風力與回穩，根部跟隨不等於自然運動。只補本輪主張及受影響範圍的證據，沿用舊證據前核對版本與前提。
