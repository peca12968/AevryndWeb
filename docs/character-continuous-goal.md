## 製作迴圈：先有完整畫面，再擴充驗證

**完整基線 → 一個直接 Blender 修正 → 同條件完整頭部／全身 A/B → 視覺保留或判退 → 受影響驗證 → 接回人物並交付。**

- 預設一個候選，單輪最多三種實質不同構造，不必做滿。密度、半徑、色素、粗糙度、權重、步數、剛度、阻尼及容差掃描不是新方法。校準記單位、尺度及依據；人口均值不是本人物真值。
- 初步搜尋、診斷及支援最多 **10 分鐘**；首次實際完整預覽通常在開工後 **30 分鐘內**。先訂具體截止；確需更久，須在到期前交代必要工作和新截止。到點仍在支援就停止擴充工具，改用能直接製作且可回退的構造。不能事後改期限、把白模／局部診斷算完整預覽，或用換輪次掩蓋逾時。中斷與維護耗時另記，保留原時間戳。
- 先修大形、解剖、分區和髮束，再補毛孔、細絲及著色。公式生成大量曲線不能替代髮型造型工作。A/B 固定鏡位、姿勢、燈光及曝光，交完整頭部、全身與缺陷角度；與當前工作人物及受保護的較好歷史特徵比較，不能只挑破損基線。
- 第一完整預覽若主要大形／結構失敗，立即判退該方向，停止加密、全面動畫及廣泛稽核，只留重現、安全重開、授權和回退必要資料。方向成立才補相關角度、第二照明、受影響操作與接觸。便宜檢查已知的失敗不可隱瞞。
- 需要動態時，先用短片否證，再擴展轉頭、急停、風力、回穩等實際顯示變形。導引運動、穩定求解及剛體跟隨不等於自然飄動。控制輸入必須證明已送達求值後人物，不能只改屬性便宣稱表情通過。接觸修正也要看外觀。
- 重用已有工具，只修阻塞當前交付的錯誤。首次完整預覽前不得把工作擴成泛用 API、求解器、驗證器或封存框架。必要檢查通過且無新疑點就交付，不反覆驗未改部分。**嚴格驗收是判斷結果的規則，不能成為遲遲沒有模型預覽的理由。**

## 決策與防止無效循環

每輪分開寫：**可見收益／退步、實際接回範圍、已證明範圍、仍未驗收範圍。** 局部好形體可留在完整工作人物繼續修；其他門未完成不要求丟掉它，也不能把保留方向包裝成採用完整改善。

| 結果 | 證據與聲稱界線 |
| --- | --- |
| 採用完整人物外觀改善 | 有實際完整 A/B、明確採用範圍及受影響門結果；關鍵失敗或缺證仍在不得聲稱。正式 runtime 推廣另須驗收。 |
| 新增完整可用操作 | 完整人物可重現操作、回中性且無退步。局部移點、切換、還原、像素差或存檔成功不自動成立；功能不能代替外觀。 |
| 保留局部方向／研究 | 說明實際價值和缺口，接回可繼續修的完整人物；不重設完整外觀停滯。 |
| 判退 | 記實際失敗、停用範圍及必要回退；不要以更多版本或報告淡化。 |

- 同一方法兩個無效輪次就停用。重試須有新證據改變失敗前提，先便宜否證；改名、加導引／分區／步數、換殼或包裝求解器均不足。歷史已停用方法立即生效。
- **三個實際製作輪次沒有採用完整外觀改善，下一輪立即改變與主缺陷相關的基底／構造，交可見完整預覽。** 形體差就重建形體，依附／操作阻塞就保護好形體並重建阻塞構造。下載、換來源名稱或重新規劃不算構造收益。
- 臉／毛髮仍不可信時，任意三個實際製作輪次至少兩輪直接製作主要可見缺陷；不可見支援最多連續兩輪，下一輪回到可見製作。每三個實際製作輪次檢視完整女人，併入當輪交付；失敗及未登記實作也算。快照／提案不算已完成試驗，未知計數不捏造。
- 提示詞、研究、診斷、功能、資料修復及 Git 保存不重設外觀停滯。無採用外觀收益寫「本輪沒有採用外觀改善」；也無新增完整可用操作時，寫 **「本輪未改善完整人物」**，再分列局部保留收益。不可用 progress 標籤代替這個結論。

接觸結論必須與證據同範圍：

- 靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進；固定根部、數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱；封閉邊不證明無自交。
- 解剖接合／包含須有結構依據。禁刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過。有藝術／解剖依據的重建與尺度校準可以做，但原受影響結論失效，改根部重驗依附、解剖與接觸。來源問題不豁免，舊證據須核對版本與前提。
- 先便宜否證，不要求每輪先證全域；缺證不能說全通過。禁放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋失敗；診斷材質／光另列。
