# Aevrynd 仿真人物持續目標 v25

更新：2026-10-20。取代 v24 的執行方式。先處理使用者當前要求；提示詞維護不啟動人物製作輪次。

## 持續目標

用已安裝的 Blender 持續製作**同一位可信、完整、可編輯、可動的寫實成年女性**，將網格、骨架、表情、材質、貼圖、毛髮、服裝、碰撞、LOD 及可重建匯入流程整合進 Aevrynd 自研引擎。裸體與穿衣、近景與全身、多角度與不同照明、靜止與指定動作均須成立，無可見穿模。全部品質門通過且使用者明確認可女性後，才開始男性。

**主要交付是逐步變得可信、可用的完整人物。** 診斷、分層、局部數據、文件、版號及 Git 提交只是支援。每輪分別回答「完整人物哪個主要外觀缺陷改善了？」和「哪項完整操作現在可用？」。無外觀改善就明寫；功能進展另列，不能替代寫實度。

## 一、先選值得製作的成果

1. 讀本文、`engine/assets/characters/female-next/female-next.asset.json`、最新有效證據及 continuation；核對完整工作來源／雜湊、未登記成果和 live job。最新檔不自動等於最佳檔，不因登記落後重做成果。
2. 看實際完整頭部、全身和缺陷角度，列前三項主要問題，選一個**完整人物尺度的成果**。條件相符的舊畫面可重用；nextAction 只是待核實建議。
3. 臉和毛髮仍明顯像人偶時，優先其形體、結構、髮型與表面反應。每三個實際製作輪次至少兩輪直接製作主要可見缺陷；必要功能／接觸工作交錯進行。選題須解決連貫問題，例如完整髮型與髮束、眼眶／眼皮／眼球共同結構，避免無限拆成局部鼓包、參數和命名工作。
4. 優先把已有收益的研究接回同一完整工作人物；未驗收研究可暫存，不能永遠以獨立研究代替整合。完整工作檔、限定用途基礎、回退、未驗收研究和正式 runtime 分開。

開工最多六行：來源與 job、主要缺陷、預期畫面／操作、參考對應的 Blender 動作、便宜判退及整合終點、預覽與資源上限。不要另開計畫／報告輪。

## 二、每輪只跑有效製作流程

**看人物 → 選一項連貫成果 → 製作 → 便宜預覽／否證 → 有效才補檢查及整合 → 交付。**

- **依據落到操作。** 必要時查真人解剖、專業角色及 Blender 社群，記作者、來源、用途，說明參考如何落到本人物。先大形、結構、髮束，再微細節；允許重雕、重拓撲、重梳可編輯導引或更換限制品質的部件。不用遮蓋層、細絲及反覆配準掩蓋根本問題；外部不同光線的作品僅作定性參考。
- **預設一個候選。** 新證據支持實質不同構造才增加，單輪最多三種方法，並非必做滿。色素、粗糙度、密度、半徑、權重、剛度、阻尼、步數及容差掃描不算方法轉換。
- **先判退，再付驗收成本。** 先做看得清缺陷的低成本完整頭部／全身 A/B，及最易揭露失敗的有效檢查。被否證立即停；不替失敗候選補全角度、全面物理或引擎測試。方向成立才補必要角度、第二照明和受影響操作／接觸。
- **診斷只解除當前阻擋。** 初步支援診斷限 10 分鐘，到點交代製作依據或具體否證；不可行則換可回退層或不同構造，不無限延長搜尋／工具開發。不可見依賴／支援最多連續兩個製作輪次，下一輪回到主要可見缺陷。
- **採用有範圍。** 可見改善且受影響檢查成立，才記外觀收益；完整操作可重現、回中性且外觀未退步，才記該操作可用。來源面分離、開關、重命名、精確還原只證明其用途，不證明新增解剖、自然動態、寫實度或完整角色能力。部分通過不提升正式資產，也不替其他層取得資格。
- **檢查有終點。** 驗證器有錯以獨立依據修正、記原因，不為候選放寬標準。受影響檢查通過且無新疑點即可交付，不無限擴測。

## 三、停滯必須改方法

同一方法連續兩輪無實質收益即停用；只有新證據改變原失敗前提才重試。換版號、名稱、參數或工具包裝不算新方法。

每三個實際製作輪次，在當輪比較窗口前後完整人物。失敗、未登記、未封存試驗照計。主要缺陷未解決且無新增完整可用能力，下一輪須改製作依據或構造，不再延長原診斷／微調。**臉／毛髮外觀停滯單獨記錄，功能進展不重設外觀停滯。** 局部證明、來源修復、研究、封存及提示詞修改不重設整體停滯；不追溯編造缺失計數。

無主要外觀改善也無完整操作收益，明寫**「本輪未改善完整人物」**，保存最小失敗證據，指出下一個實質不同的 Blender 動作。不得以 progress 分類或局部數字淡化失敗；回顧併入製作，不另開報告輪。

## 四、四道品質門分開驗收

| 品質門 | 必須證明的範圍 |
| --- | --- |
| 外觀 | 實際完整頭部／全身，同鏡位、姿勢、光線、曝光 A/B；方向成立後補相關角度及第二照明。列收益、退步、最大剩餘缺陷；像素不同不等於更真。 |
| 功能 | .blend 獨立重開、資料有限；分層、拓撲、UV、權重、骨架、表情及編輯可用，操作可重現並回中性，來源可重建匯出。改動動態須實際片段；分組不等於蒙皮。 |
| 接觸 | 聲稱範圍內的實際顯示幾何、有限厚度、姿態／時間檢查及人工多角度檢視；列版本、配對、表示、距離定義、容差、失敗位置。未測或證據不足即未驗收。 |
| 引擎 | Aevrynd 場景實際載入材質、骨架、表情、動畫、毛髮、碰撞和 LOD。先定硬體、解析度、品質及預算，再量單角色近景、遊戲距離、多角色 CPU／GPU 時間與記憶體。 |

接觸／物理聲稱須符合證據：

- 核實曲線／曲面／體積、插值、世界姿態及厚度；導引、控制點、代理、髮片透明區不能代替全部顯示髮絲。作者假設與實際渲染表示未核實一致，不宣稱渲染幾何精確通過或被精確否證。
- 人體接觸、自碰撞、衣物分開；靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進。固定根部、剛體跟隨和數值穩定不證明自然飄動。
- 區分取樣最小值、保守下界和全域最短距離。包絡重疊不等於穿透，正間距不足不等於相交；凹面內外不能只憑最近面法線。弦長、粒子邊長、弧長與材料伸長不混稱。
- 解剖接合／包含須有結構及來源依據；禁止刪失敗髮絲、排除髮根、縮薄、移走或遮住問題來通過。改根部重驗依附、解剖、接觸；來源既有問題不豁免，沿用證據先核對版本／前提。
- 藝術製作先做便宜有效否證，無須每次先證全域；缺證也不得宣稱全通過。禁止放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋缺陷。

## 五、完整女性的完成條件

- **頭臉／皮膚：** 成年解剖、骨性結構、五官、耳頸肩和自然不對稱多角度合理；無蠟像、面具、過度平滑。角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線、眉睫、上下牙齒、牙齦、舌頭、必要口腔內壁與下頜控制齊備，近似表示明示。區域色差、粗糙度、微法線、次表面反應有依據，固定曝光追蹤膚色。
- **毛髮：** 髮際線、分線、鬢角、耳後、後腦、髮尾連續；大形、中束、細絲、少量飛散髮可讀，無帽殼、片簾、漏斗、切齊、鋼絲感。真實頭皮依附、合理分區剛度、重力、慣性、阻尼與接觸；驗證轉頭、急停、風力、回穩，明示彎曲、扭轉、摩擦、氣動校準範圍。
- **身體／服裝：** 裸體比例、手腳、關節、變形可信，不靠衣髮遮解剖。服裝有厚度、接縫、摺痕及活動空間。裸體、單層、多層，中性、走路、跑步、蹲下、轉身、抬手、眨眼、轉眼、張嘴、微笑均無塌陷、糖紙扭縮、可見穿模。
- **分層／整合：** 身體、眼部組件、口腔、上下牙齒、牙齦、舌頭、眉睫、頭皮、頭髮、內外衣、配件、骨架、控制器、碰撞代理明確命名、可獨立編輯／切換，記完成度、綁定、運行表示。網格、UV、貼圖、材質、骨架、morph、動畫、毛髮、碰撞、LOD、匯入程式可從 Blender 權威來源重建，實際引擎品質／效能達預算。

評分先列可見缺陷，再附版本、證據、扣分理由及信心範圍。40 為明顯人偶／嚴重缺陷，60 人工感強，80 多角度可信但不足，90 近景與動態可靠；這是審核估計，非客觀真人相似度。無新證據不升分，不把舊分套新版；缺項標未驗收，不計完整總分。

權重：解剖 15%、臉部 15%、眼睛 10%、皮膚 10%、毛髮 15%、服裝與分層 10%、骨架與動態 10%、碰撞 10%、引擎效能 5%。**全部同時成立才完成：加權至少 85、每項至少 80；完整層及指定動作齊全；靜態／動態無可見穿模；引擎品質／效能通過；來源獨立開啟並可重建；使用者明確認可女性。** 硬性失敗不能被平均分抵銷，之前不標 complete、不開始男性。

## 七、交付、接手與生效

製作交付依序：**完整人物實際外觀收益或明確未改善 → 真實頭部／全身 A/B、必要缺陷角度及變更動態 → 可開啟 .blend 絕對路徑 → 外觀／功能／接觸／引擎結果及缺口 → 採用範圍 → 下一個具體 Blender 動作 → 核實 GitHub 狀態。** 無新完整候選就明說，不以重複基線、生成參考圖或他人作品當成果。

continuation 簡記來源／雜湊、未登記成果、有效證據、已通過範圍、主要缺陷、整合缺口、停用方法與原因、live job、資源、下一建議。外觀、完整功能、局部收益、診斷分開；保留真實三輪窗口和停滯計數，不為交接另做大型報告。

**提示詞維護只改本文及接手入口。** 不開模型輪次，不改模型、manifest、分數、採用、女性認可、計數或既有失敗結論；未封存工作只記最小接手，不擴成製作／診斷。本文與歷史庫 `docs/character-continuous-goal.md` 逐位元組一致，兩處 AGENTS.md 指向 v25。

目標保持 active。現有工具能讀 objective、變更狀態，沒有原地改寫 active objective 的介面；此次修改專案執行提示詞，不宣稱工具內舊 objective 已替換，不清除／重建目標、不新增排程。後續依本文修正舊 objective 的強制多候選、逐候選全面檢查及進展分類，女性目標與完成標準保留。使用者當前要求及更高優先規則優先。只有使用者明確要求才暫停；真正阻塞依目標工具規則處理，不因困難自行停目標。
