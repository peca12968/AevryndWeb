交付順序是**完整人物的可信外觀 → 完整可用操作 → 引擎實際品質與效能**。可以交錯解除技術風險，但不能長期用局部研究取代人物製作。女性通過全部品質門與使用者明確認可後才開始男性。

## 1. 每次接續先決定要交付什麼

1. 讀本文、`engine/assets/characters/female-next/female-next.asset.json`、其最新有效 evidence／continuation，以及本次提示詞更新的最小 pending handoff。核對實際檔案、來源雜湊、未登記成果、工作程序與既有失敗；較新版不自動較好，登記落後不代表要重做。
2. 看實際完整頭部、全身和主要缺陷角度。列最多三項主要可見缺陷，選一項**完整尺度、可製作的成果**，寫清「現況缺陷 → 要出現的畫面／操作 → 判退依據」。以完整髮型、頭臉共同結構等連貫問題為單位，允許相關部件一起重建。
3. 選能直接改變該結果的 Blender 製作依據：真人解剖、專業流程、可核實社群作品或來源結構。說明參考如何變成本人物的形體、拓撲、髮束或控制；文章讀過、模型下載、資料轉格式本身都不是人物改善。
4. 開工最多六行，涵蓋來源／live job、主要缺陷、預期完整成果、具體製作動作、便宜判退與接回完整人物的終點、首次預覽及資源上限。接著直接製作，不另開計畫／工具／報告輪。

臉與毛髮仍不可信時，每三個實際製作輪次至少兩輪直接處理主要可見缺陷。保護無關部件、已有效操作及人物連續性；被重雕、重拓撲或重梳的部件不必永遠保持原座標或控制拓撲。允許替換限制品質的基底，保留回退，不用更多遮蓋層維持錯誤構造。

## 2. 製作一個候選，先看結果再付驗證成本

**看完整人物 → 直接製作 → 實際便宜預覽 → 判退或保留 → 必要驗證 → 同一完整人物與引擎交付。**

- 預設一個候選。新增方法須有新證據且構造實質不同，單輪最多三種，不必做滿。色素、粗糙度、密度、半徑、權重、步數、剛度、阻尼或容差掃描不是新方法。測量只支持明示單位、尺度、範圍的一次校準，人口均值不是本人物真值。
- 用同鏡位、姿勢、光線與曝光的實際完整頭部／全身 A/B，補看必要缺陷角度。先大形、結構與髮束，再細絲、毛孔與著色。預覽必須看得清問題；稀疏導引、灰模、代理或實心形體只證明有限用途，不能算完成髮型或最終外觀。
- 方向失敗即判退，停止加密與廣泛測試，只留重現、重開、授權及回退必要資料。方向成立才補相關角度、第二照明及受影響操作／接觸。有用研究也要接回同一完整工作人物重開重看，不能永久停在單部件試驗。
- **初步搜尋、診斷和支援最多 10 分鐘。** 到點選能製作的依據與動作；依賴仍不可行就改可回退構造。另訂首次可看完整預覽期限，逾時記真實原因與整輪實際耗時。不可見支援最多連續兩個製作輪次，下一輪回到主要可見缺陷。
- 重用可用流程，工具只服務當前成果。不要把原生曲線 API、資料驗證器、腳本重寫當另一輪角色製作。受影響檢查通過且無新疑點即可交付；驗證器錯誤用獨立依據修正，保留原因，不為候選放寬標準。

採用分清：①完整人物可見外觀收益；②可重現、可回中性且未退步的完整操作；③僅限資料／局部研究用途；④判退。③和④不能改成①或②，不能重設外觀停滯。只保留③時應明說它對完整人物尚未產生收益。分層、開關、精確還原、毫米變化、像素差異、版本增加都不自動算寫實度或完整操作。

## 3. 失敗必須改變下一次製作

- 同一方法連續兩個製作輪次沒有實質收益即停用；只有新證據改變原失敗前提才重試。換名稱、版本、工具包裝或增加導引不算新構造。
- **連續三個實際製作輪次沒有採用完整人物的可見外觀改善，下一輪立即更換限制品質的基底／構造。** 從已有完整人物前後圖指出失敗假設，直接做有新依據的重雕、重拓撲、完整髮型重建或相容授權部件替換。不得先花一輪重設計報告，或沿原失敗路徑微調。
- 歷史窗口包含失敗、未登記與未封存試驗；提示詞更新、研究、功能、局部資料、來源修復、診斷及 Git 保存都不重設。每三個實際製作輪次回顧完整人物，併入當輪交付；保留真實既有計數，不補造未知歷史。
- 新構造也失敗就如實判退。無採用外觀改善寫「本輪沒有採用外觀改善」；也無新增完整可用操作時寫**「本輪未改善完整人物」**。不要用 progress、技術通過或研究保留淡化這個結論。

nextAction 是待核實建議，不是照做命令。尤其停滯已觸發時，先核對它是否真的改變失敗前提；否則改選製作依據。不靠再等三輪延後結構改變。

## 4. 四道品質門分開驗收

| 品質門 | 必須證明的範圍 |
| --- | --- |
| 外觀 | 實際完整頭部／全身，同鏡位、姿勢、光線、曝光 A/B；方向成立後補相關角度及第二照明。列收益、退步、最大剩餘缺陷；像素不同不等於更真。 |
| 功能 | .blend 獨立重開、資料有限；分層、拓撲、UV、權重、骨架、表情及編輯可用，操作可重現並回中性，來源可重建匯出。改動動態須實際片段；分組不等於蒙皮。 |
| 接觸 | 聲稱範圍內的實際顯示幾何、有限厚度、姿態／時間檢查及人工多角度檢視；列版本、配對、表示、距離定義、容差、失敗位置。未測或證據不足即未驗收。 |
| 引擎 | Aevrynd 場景實際載入材質、骨架、表情、動畫、毛髮、碰撞和 LOD。先定硬體、解析度、品質及預算，再量單角色近景、遊戲距離、多角色 CPU／GPU 時間與記憶體。 |

接觸／物理聲稱須符合證據：

- 核實曲線／曲面／體積、插值、世界姿態及厚度；導引、控制點、代理、髮片透明區不能代替全部顯示髮絲。作者假設與實際渲染表示未核實一致，不宣稱渲染幾何精確通過或被精確否證。
- 人體接觸、自碰撞、衣物分開；靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進。固定根部、剛體跟隨和數值穩定不證明自然飄動。
- 區分取樣最小值、保守下界和全域最短距離。包絡重疊不等於穿透，正間距不足不等於相交；凹面內外不能只憑最近面法線。弦長、粒子邊長、弧長與材料伸長不混稱。
- 解剖接合／包含須有結構及來源依據；禁止刪失敗髮絲、排除髮根、縮薄、移走或遮住問題來通過。改根部重驗依附、解剖、接觸；獨立藝術／解剖依據支持的重建或尺寸校準可以做，但須承認原接觸結論不再適用，重驗受影響範圍，不能以尺寸改小本身宣告通過。來源既有問題不豁免，沿用證據先核對版本／前提。
- 藝術製作先做便宜有效否證，無須每次先證全域；缺證也不得宣稱全通過。禁止放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋缺陷。診斷光照／材質可另列，不能替代固定曝光的外觀比較。

- **身體／服裝：** 裸體比例、手腳、關節、變形可信，不靠衣髮遮解剖。服裝有厚度、接縫、摺痕及活動空間。裸體、單層、多層，中性、走路、跑步、蹲下、轉身、抬手、眨眼、轉眼、張嘴、微笑均無塌陷、糖紙扭縮、可見穿模。
- **分層／整合：** 身體、眼部組件、口腔、上下牙齒、牙齦、舌頭、眉睫、頭皮、頭髮、內外衣、配件、骨架、控制器、碰撞代理明確命名、可獨立編輯／切換，記完成度、綁定、運行表示。網格、UV、貼圖、材質、骨架、morph、動畫、毛髮、碰撞、LOD、匯入程式可從 Blender 權威來源重建，實際引擎品質／效能達預算。
