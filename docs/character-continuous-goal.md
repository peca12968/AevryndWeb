## 製作：一個可見缺陷，一次完整預覽

先看實際完整頭／身與缺陷角度，最多列三個問題，選一個主缺陷；功能阻塞須在同一人物上展示預期動作。開工卡最多六行：來源與保護收益、主缺陷、參考及可轉用構造、直接 Blender 動作、可見判退條件、具體完整預覽截止及資源。

| 階段 | 必須做的事與轉換條件 |
| --- | --- |
| 參考與診斷 | 初始研究／診斷／支援合計最多10分鐘。參考要指出已觀察的三維構造、依附／變形與來源權利；他人作品不是本人物成果。到點停止擴工具，轉直接可回退製作。授權不明的來源限研究，改用權利已核實來源或自行 author，不用期限合理化匯入。 |
| 直接製作 | 預設一個候選，最多三種構造不同的方法，不必做滿；禁止參數掃描。先修大形、解剖、五官關係、髮型、依附與完整操作，保留有希望的形體，重建阻塞的拓撲、髮束、內壁、接合或控制，接回同一女人。座標／拓撲／控制可變，不為保住舊數值而保留壞構造。 |
| 完整預覽 | 首次完整預覽通常在原開工30分鐘內。同鏡位、光、曝光、姿勢，輸出實際頭部／全身 A/B 及主缺陷角度；動作改動加中間、終態、回中性。生成圖、灰模、髮殼、導引與孤立元件不能替代。必要延長須到期前報已有產物、理由、新截止；原期限與逾時照留。退出碼0還須核對完成標記與產物，純啟動修復不算新人物輪次。 |
| 先判畫面 | 判主缺陷、整體真人感與受保護外觀。有退步或無淨收益就停止該構造精修／變體／廣泛稽核，保留最低重現、重開、權利與回退，不請使用者批准已知失敗。方向成立才補第二照明及相關驗證；全域證明不足不能拖延預覽，較好畫面不能抹去失敗。 |
| 驗證與接回 | 獨立重開 .blend，操作實際顯示的求值後幾何並復原；控制值、is_bound、隱藏舊模型會動均不算通過。毛髮須看實際髮型轉頭、急停、風力與回穩，根部跟隨不是自然動態。只擴驗本輪主張／影響，未改區域核實版本及前提後引用舊證據。 |

## 決策：留住形體收益，停掉無效前提

外觀、功能、接觸、引擎分開判定，缺證／失敗未驗收。完整 A/B 有可辨識淨收益且保護外觀無退步，可限定採用靜態外觀，列受影響功能／接觸缺口與退步；不冒稱完整操作、正式 runtime 或使用者認可，也不因無關門未證就丟掉有希望的形體。新增完整操作須實際完成、復原，相關範圍無已知失敗／退步。研究／方向保留不算採用，發現反證就更正推斷。

- **兩輪停用：** 同方法兩個無效實際輪次即停用。重試要先有改變失敗前提的新證據並便宜否證；換名稱、來源標籤、公式或調密度、權重、半徑、阻尼、粗糙度、容差、平滑，不自動成為新方法。
- **三輪轉構造：** 三輪無採用完整外觀收益，下一製作輪須更換與主缺陷相關的基底／構造，再接回同一女人；不必丟掉整位人物。重接資料仍非外觀收益，只有採用完整外觀淨改善可重設外觀停滯。
- **製作占比與整體檢視：** 臉／髮不可信時，任意三個實際輪次至少兩輪直接製作主要可見缺陷，不可見支援不連續超過兩輪。每三輪檢視整位女人，含失敗／未登記試作。提案、元件快照及純啟動錯誤不冒充完成輪次；嘗試與成本照留。既有歷史立即計入，研究、保存、推送及提示詞維護不重設計數。

同時沒有採用外觀改善及新增完整可用操作，寫「本輪未改善完整人物」；只有功能收益仍寫「本輪沒有採用外觀改善」。

接觸結論必須與證據同範圍：

- 核實表示、插值、世界姿態和厚度；變形配對使用各自求值後的幾何。頂點離開表面不代表整個面片離開。控制點、導引、代理、髮片透明區不代表全部顯示髮絲；未證作者假設與渲染一致，不稱渲染占據精確通過／否證。
- 靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進；固定根部、數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱；封閉邊不證明無自交。
- 解剖接合／包含須有結構依據。禁刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過。有藝術／解剖依據的重建與尺度校準可以做，但原受影響結論失效，改根部重驗依附、解剖與接觸。來源問題不豁免，舊證據須核對版本與前提。
- 先便宜否證，不要求每輪先證全域；缺證不能說全通過。禁放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋失敗；診斷材質／光另列。

評分權重：解剖15%、臉部15%、眼睛10%、皮膚10%、毛髮15%、服裝與分層10%、骨架與動態10%、碰撞10%、引擎效能5%。先列缺陷，附確切版本、圖像／動作／量測、扣分理由與信心範圍。40＝明顯人偶／嚴重缺陷，60＝人工感強，80＝多角度可信但不足，90＝近景及動態可靠；屬審核估計。無新證據不升分，舊分不套新版；缺項未驗收，不算完整總分，自評不替代使用者認可。
