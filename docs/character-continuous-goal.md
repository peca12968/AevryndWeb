完成須全部成立：下表內容齊全；聲稱的靜態／動態範圍無可見穿模；.blend 可獨立重開及重建匯出；Aevrynd 實際材質、控制、動畫、物理、LOD 與效能通過；嚴格加權至少 85/100、每項至少 80/100；**使用者明確認可女性**。缺證或硬性失敗不能平均掉。此前目標保持 active，不標 complete，不開始男性。

## 接續時先做的事

1. 讀本檔、`engine/assets/characters/female-next/female-next.asset.json`、最新有效 evidence／continuation，以及 `Info/CharacterGoalPrompt-v30-update.json` 的 pendingWorkHandoff。只核對必要來源／雜湊、未登記成果、live job、停用方法與真實計數；不要重掃歷史。交接提案不是已實作、已採用或重試許可，須對照現存檔案。
2. 看實際完整頭部、全身及缺陷角度，最多列三個缺陷，選最損害可信度的一個連貫問題。可跨解剖、五官、髮型、依附及控制；不要讓局部數字掩蓋整體人偶感。
3. 一句話鎖定藝術目標：依哪個可信參考，正／側／背面哪些輪廓、比例或髮束走向要改變，用哪個 Blender 動作完成。優先重雕、重拓撲、完整重梳或部件重建；程序負責重現與必要綁定，少數公式產生大量曲線不等於藝術製作。使用藝術家資產前先看原作實際三維形體。
4. 開工說明最多六行：來源與保留範圍、主要缺陷、參考及動作、一個候選的可見判退條件、具體時間截止、現有 job 與資源上限。隨後直接製作。

始終分清**完整工作人物、不可變回退／未驗收研究、正式 runtime**。把保留收益接回同一女人，保護無關的身體、眼口、表情及控制；必要重建可以改座標、拓撲及控制並重新依附。不要無限疊遮蓋層，也不要因換來源或髮型丟掉有效部件。

## 一輪的執行順序

**完整基線 → 直接 Blender 修正 → 同條件完整頭部／全身 A/B → 保留或判退 → 必要驗證 → 接回同一人物並交付。**

- 預設一個候選，單輪最多三種實質不同構造，不必做滿。密度、半徑、色素、粗糙度、權重、步數、剛度、阻尼或容差掃描不算新方法。校準須有單位、尺度及依據，人口均值不是本人物真值。
- 初步搜尋、診斷及支援最多 **10 分鐘**；首次實際完整預覽通常須在開工後 **30 分鐘內**。先訂具體截止；確需更久須事先說明必要工作及新截止，不能事後改期限。到點仍在支援就停止工具擴充，改用可製作、可回退的構造；如實報逾時、原因與產物。先交出完整預覽再擴充支援。
- 先修大形、解剖、分區及髮束，再補毛孔、細絲與著色。A/B 使用同鏡位、姿勢、光線及曝光，另顯示主缺陷角度；完整人物不能由導引、代理、灰模、實心髮殼、生成圖或他人作品代替，引用者明示用途。
- 第一預覽若大形或結構失敗，立即判退並停止加密、完整動畫及廣泛稽核，只留重現、安全重開、授權及回退必要資料。方向成立才補相關角度、第二照明、受影響操作與接觸；便宜檢查已發現的失敗必須記錄。
- 動態先用靜態和短片判退，再擴展轉頭／急停／風力／回穩，讓實際顯示毛髮變形。穩定求解、導引運動或剛體跟隨不等於自然飄動。接觸修正也必須看外觀。
- 重用已有工具，只修阻塞當前交付的錯誤。API、求解器、驗證器、序列化及封存都不能取代模型製作；必要檢查通過且無新疑點就交付，不反覆查未改部分。

## 保留、淘汰與停滯

每輪說清楚：**看到了什麼、接回了什麼、證明了什麼、仍欠什麼。** 好形體可保留在完整工作人物中繼續修依附／接觸／操作，缺證仍明示未驗收；不能把保留方向或資料修復當成採用收益，也不能因別道門未完反覆丟掉它重找素材。

| 結果 | 聲稱界線 |
| --- | --- |
| 採用完整人物外觀改善 | 有實際完整 A/B、明確採用範圍及受影響門結果；關鍵失敗／缺證仍在不得聲稱此項。正式 runtime 推廣另須驗收。 |
| 新增完整可用操作 | 完整人物能重現操作、回中性且無退步。局部移點、分組切換、還原、像素差及存檔成功不自動成立，功能不能代替外觀。 |
| 保留方向／研究 | 明示價值和缺口，不重設外觀停滯，不包裝成已採用改善。 |
| 判退 | 記實際失敗及停用範圍，保留必要回退，不用更多版本或報告淡化。 |

同一方法兩個無效輪次即停用；重試須有新證據改變失敗前提，先便宜否證，改名、加導引／分區／步數、換外殼或重包裝求解器均不足。**三個實際製作輪次沒有採用完整外觀改善，下一輪立即改變相關基底／構造並交付可見完整預覽**：形體差就直接重建形體，依附／操作卡住就保護好形體並重建阻塞構造；下載或換來源名稱本身不算。

臉／毛髮仍不可信時，任意三個實際製作輪次至少兩輪直接製作主要可見缺陷；不可見支援最多連續兩輪，下一輪回到可見製作。每三個實際製作輪次檢視完整女人，併入當輪交付，失敗及未登記試驗都算。已有歷史立即生效；提示詞、研究、診斷、功能、來源修復或 Git 保存不重設計數，未知不捏造，僅快照／提案不算完成試驗。

無採用外觀收益寫「本輪沒有採用外觀改善」；也無新增完整可用操作，必須寫 **「本輪未改善完整人物」**。研究另列，不能以 progress 或資料通過替代結論。

## 四道品質門與接觸證據

| 門 | 必須證明的範圍 |
| --- | --- |
| 外觀 | 實際完整頭部／全身同條件 A/B；方向成立後補相關角度及第二照明。列收益、退步及最大剩餘缺陷，像素不同不等於更真。 |
| 功能 | .blend 獨立重開、資料有限，分層、拓撲、UV、權重、骨架、表情及編輯可用；重現操作並回中性、來源可重建匯出。動態改動交實際片段，分組不等於蒙皮。 |
| 接觸 | 實際顯示幾何及有限厚度的姿態／時間檢查，加人工多角度檢視；記版本、配對、表示、距離定義、容差及失敗位置。人體、自碰撞、衣物分記，未測不通過。 |
| 引擎 | Aevrynd 真實場景載入材質、控制、動畫、毛髮、碰撞及 LOD；先定硬體、解析度、品質與預算，再量單角色近景、遊戲距離及多角色 CPU／GPU 時間與記憶體。 |

四門分開，缺證即未驗收；不可把一門成功當全部通過。接觸尤其遵守：

- 核實表示、插值、世界姿態及厚度。控制點、導引、代理及髮片透明區不等於全部顯示髮絲；未證明作者假設與渲染表示一致，不宣稱渲染占據精確通過或精確否證。
- 靜態、離散影格、連續時間分開；連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進。固定根部或數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱，封閉邊也不證明無自交。
- 解剖接合／包含須有結構依據。禁止刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過；有藝術／解剖依據的重建與尺度校準可做，但原接觸結論失效，改根部重驗依附、解剖及接觸。來源問題不豁免，舊證據須核對版本與前提。
- 先做便宜有效否證，不要求每輪先證全域；缺證不得稱全通過。禁放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋失敗；診斷材質／光另列，不代替固定曝光比較。
