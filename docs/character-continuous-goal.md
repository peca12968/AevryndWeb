## 目標與進步的定義

以本機 Blender 持續完成同一位成年女性，讓完整形體、臉、皮膚、頭髮、裸體與衣著都可信，分層清楚、可編輯、可操作，活動與有限厚度接觸合理，禁止可見穿模。Blender 權威來源須可重建 Aevrynd 自研引擎的網格、骨架、表情、動畫、貼圖、材質、毛髮、碰撞、LOD 與匯入流程，能離線運行。保留原作者與授權，不冒稱第三方資產為獨占自有；不依賴 MetaHuman、Unreal、訂閱或持續收費執行服務，不另裝大型軟體。使用者明確認可女性後，才開始男性。

**人物進步只有兩種：同一完整人物已採用的可見淨改善；或在同一人物新增、完成並復原的完整可用操作。** 實驗、研究、診斷、綁定、版本、報告與 GitHub 保存如實記錄，不當作上述成果。外觀、功能、接觸、引擎分開驗收；只通過一項不代表全部完成。完整要求見後半品質契約。

## 製作：先設計可信構造，再讓完整畫面否證它

**開工卡最多六行：** 完整來源與保護收益；實際頭／身最多三個問題及唯一主缺陷；參考、權利及觀察到的三維構造；直接 Blender 動作與改變的失敗前提；完整畫面可見判退條件；具體預覽截止與資源。

1. **看完整女人，選唯一主缺陷。** 先看實際頭部、全身和缺陷角度；先修大形、解剖、五官關係、髮型與構造，再做微細節。功能阻塞需在同一女人展示預期操作。從原開工計，初始研究／診斷／工具支援合計最多10分鐘；工具能力用一次最小實作確認，到點轉可回退的直接製作，不反覆查來源、API 或求解器。
2. **在當前人物上直接製作。** 保留有希望的形體，重建阻塞的拓撲、內壁、根梢導引、髮束、接合或控制，再接回同一女人。原生雕塑、曲線雕梳、網格編輯和程式都可用；選可實際完成形體的工具，不強行沿用失敗的生成方式。先明確設計空間構造與解剖對應，再程序化或增密；更多點、線、纖維、控制或位移不自動產生真人感。預設一個候選，最多三種構造不同的方法，不必做滿，禁止掃參數。
3. **先交完整預覽，再擴驗。** 原開工起通常30分鐘內，產出與基線同鏡位／光／曝光／姿勢的實際完整頭部、全身 A/B 及主缺陷角度；操作改動加中間、終態、回中性。孤立零件、導引、代理、灰模、髮殼、生成圖或他人作品只能診斷／參考。自己實際查看輸出；退出碼0不等於產物完成。延長須在到期前報已有產物、理由與新截止，保留原期限及逾時；純啟動修復不算新人物輪次。
4. **決定保留什麼，停止什麼。** 同時比主缺陷、整體真人感與受保護外觀。無可辨識淨收益或有退步，停止該方向精修、變體與廣泛稽核，只留最低重現、獨立重開、權利及回退，不把已知失敗交給使用者替你判。方向成立才補第二照明、相關功能與接觸；不等全域證明才出圖，也不讓好看的局部抵銷完整人物的失敗。
5. **證明實際可操作。** 獨立重開 .blend，操作實際顯示的求值後幾何，完成動作並復原。屬性、導引、控制點變化或 is_bound 不是完成；確認輸出確實受控且相關範圍無已知失敗。毛髮看實際髮型轉頭、急停、風力及回穩，根部跟隨不等於自然動態。只擴驗本輪主張與受影響範圍，舊證據須核對版本與前提。

參考須落成具體製作選擇：觀察大形、根梢、頭皮／分線、三維髮束、依附、變形、材質與伴隨層。轉用前核實權利與來源原生操作，完整髮型不能用裝飾粒子層冒充。通用最近面投影、全域縮放、表面 UV 線或換來源標籤不自動成立根梢與解剖對應。權利不明限研究，改用已核實來源或自行製作；不能為趕期限繞過權利，也不能將工具學習無限延長為製作替代品。

## 採用與停滯：沿用真實結果，不靠新名稱重試

完整 A/B 有可辨識淨收益、受保護外觀無退步，可限定採用靜態外觀，明列受影響操作／接觸缺口；不因無關門缺證丟掉有希望形體，也不冒稱完整操作、正式 runtime 或使用者認可。新增完整操作須實際完成／復原，相關範圍無已知失敗或退步。研究保留不算採用，反證須更正原推斷。

- **同方法兩個無效實際輪次即停用。** 重試先給原失敗前提、改變它的新證據及便宜否證方式；換名稱、來源標籤、公式、密度、權重、半徑、阻尼、粗糙度、容差或平滑本身不是新方法。
- **三輪無採用完整外觀收益，下一輪必須更換相關基底／構造並接回同一女人。** 不必丟掉整位人物；重新綁定、換工具或重接資料不重設外觀停滯，只有已採用完整外觀淨改善可以。
- **臉／髮仍不可信時，任意三個實際輪次至少兩輪直接製作主要可見缺陷；不可見支援不得連續超過兩輪。** 每累積三個實際輪次檢視整位女人，包括失敗／未登記試作，不重做全歷史稽核或重算舊輪次。
- 既有停用、停滯與原成本立即生效；維護、研究、封存和推送不重設。提案、元件快照、純啟動錯誤不冒充完成輪次，實際嘗試與成本仍保留。

同時沒有採用外觀改善及新增完整可用操作，明寫「本輪未改善完整人物」；只有功能收益仍寫「本輪沒有採用外觀改善」。每輪優先交實際圖／動作、可重開來源及短決策，必要量測與重現留原位並引用，不擴成重複報告或封存工程。無法繼續某路徑時列已試證據、確切缺口、可繼續部分與解鎖條件；困難、逾時或單次失敗不是自行暫停整個目標的理由。
