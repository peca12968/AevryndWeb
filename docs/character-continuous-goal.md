## 可直接使用的提示詞

持續使用本機 Blender，為 Aevrynd 自研引擎製作仿真成年女性角色。目標是讓使用者看到越來越像真人、動作自然且不穿模的完整人物，最後交付可編輯、可重建、可商用的模型、材質、骨架、表情、毛髮、衣物、碰撞、動畫、LOD 與引擎實作。Blender 是製作工具；最終資料、載入、渲染、動畫與物理須能在 Aevrynd 運作，不依賴 MetaHuman、Unreal 或付費平台執行服務。先完成女性並取得使用者明確認可，才開始男性。

以「多角度看起來像真人、動作自然、不穿模、能在引擎可靠運作」判定成果。優先完成可觀看的完整頭部，再擴展全身及服裝。以真人參考和現代遊戲人物流程建立依據，先修比例、輪廓與大形，再做皮膚、毛髮和微細節。不得用調暗、遮擋、增密、過度平滑、修圖或生成圖冒充三維模型進步。

每輪先檢視目前完整人物及上輪成果，選一個最影響目前階段的問題，寫出原因假設、預期畫面或動作差異、最小試驗、判退條件及資源上限。先做最便宜的否證檢查，再做一個候選；只有不同且有依據的方案才增加，一輪最多三個。允許重建品質受限的部分，不受舊生成腳本限制。外觀、功能、碰撞、引擎四類結果分開判斷，不以其中一類通過冒充其他類進步。

每個製作輪次都交付完整頭部或全身的實際圖像；動態修改另交付可播放片段，局部放大只作補充。用相同鏡位、燈光、曝光與姿勢比較，並檢查其他角度或第二種照明。候選失敗也呈現失敗位置及原因。維持人物外觀主線與有限的支援研究，不能讓局部求解器、數字或測試無限佔據開發。證偽的方法立即停止；同方法連續兩輪無改善時改變架構，不靠換版本名稱繼續調參。依下列規則交付實際成果、可直接開啟的 .blend、限制及 GitHub 狀態。完整女性達標後展示並等待使用者認可，不自行認定完成、不提前開始男性。

## 3. 每輪工作契約與停止條件

開始時確認既有程序、輸出與任務狀態，接續未完成工作，避免重複啟動。發現尚未登記的產物，先核對來源、雜湊與完成狀態，不將最新檔名直接當成主線。只讀本文件、manifest、最新 continuation 及相關證據，不反覆載入全部歷史。

本輪最小契約必須包含：

- 來源版本與雜湊、目前里程碑、主要缺陷。
- 參考依據、原因假設、預期可見差異及明確判退條件。
- 最小試驗、受影響的驗證範圍、計算規模與資源上限。
- 結果如何回到完整人物；若是支援研究，寫明它解除哪個阻礙。

依序執行：先否證可行性，再製作候選，再驗證受影響部分，最後檢視實際渲染並決策。允許重建品質受限的拓撲、UV、形體、貼圖或毛髮結構，不受舊生成腳本限制。

對照固定相機、燈光、曝光、色彩管理、姿勢、解析度與裁切；另外用側光或第二種照明檢查穩健性。照明實驗獨立標記，不能算成模型改善。沿用與確切資產狀態相符的有效技術證據；只有新變更、失敗或未解疑義才擴大重測，不反覆跑無關全套檢查。

每輪分別記錄以下結果，缺項寫未測試：

| 類別 | 判斷問題 |
| --- | --- |
| 外觀 | 同條件 A/B 是否有可辨識改善，其他角度是否退步？ |
| 功能 | 控制器及動作是否實際可用、是否更自然？中性畫面不變的必要功能修復可保留，但不因此提高中性外觀分數。 |
| 碰撞 | 哪些實際幾何、配對、姿勢及時間範圍通過，哪些仍未通過？ |
| 引擎 | 是否可重建、載入及運行，實測效能如何？Blender 測試不能代替此項。 |

每輪以「採用於明確範圍／研究保留／判退」收束，保存改善與退步證據。只通過部分檢查的研究不取代完整工作來源。採用時指出改善與回歸風險。每輪完成前回看完整頭部或全身，不只交局部放大圖；外觀問題仍明顯時，不靠評分格式將其合理化。

停止規則：

- 方法被幾何、數值或視覺證據否證，立即停止同類掃參數；不靠放寬門檻、增加迭代、移開髮根或任意排除碰撞區域過關。
- 同方法連續兩輪無可見改善，改變根本方案；不得換版本名稱後重做同一方法。
- 一輪支援診斷後，下輪須實作其有依據的修復，或轉向能推進完整人物的獨立外觀工作。必要修復若仍需研究，寫出新架構的可行性依據與有限驗證範圍，不重複相同診斷。
- 連續兩輪只有支援診斷、沒有新的可觀看完整部位成果，下一輪必須重新排序主線。選擇能推進外觀的獨立工作，或提出有可行性證據的新架構後實作；不再執行第三輪同類診斷。
- 新架構先做小規模可行性試驗。早期失敗即停止高成本渲染及完整展開，保留失敗位置；不能將未通過的小規模試驗擴大成更多髮絲、影格或副機任務。

上述規則限制無效工作，不豁免碰撞或品質門檻。必要技術修復可作研究保留，但不得自行升擬真分數。

## 4. 角色品質與分層

- 解剖：成年人比例、頭骨、五官、耳頸肩、手腳及關節在多角度合理；自然不對稱有參考，先大形後細節，不以衣髮遮掩人體錯誤。
- 眼睛與口腔：角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線、牙齒、舌頭及口腔分層；深度、遮擋、反射與折射成立。光學近似須如實標記。
- 皮膚：有依據的區域色差、粗糙度、微法線及次表面反應；固定曝光核對膚色，禁止逐輪變黑。眉睫、唇面與髮際線不呈貼紙、實心塊或鋼絲。
- 毛髮：先髮型輪廓與分線，再稀疏導引、子髮、細絲材質、動態及引擎表示。大形、中型髮束、細絲、少量飛散髮層次可讀；髮根、鬢角、耳後及髮尾連續自然。先證明完整導引可行再展開子髮；導引無碰撞不保證插值無碰撞，最終細髮須重新驗證。
- 動態：髮根實際綁定頭皮，分區剛度、重力、慣性、阻尼及接觸反應合理；驗證轉頭、急停、風力與回穩。模擬參數、彎曲近似、扭轉、摩擦及氣動是否實作或校準須明示。數值穩定不等於動作自然。
- 明確命名並可分別編輯／切換：身體、眼部組件、口腔、牙齒、舌頭、眉毛、睫毛、頭皮、頭髮、內外衣物、配件、骨架、控制器及碰撞代理。衣物具有厚度、接縫、合理摺痕及材質。
- 骨架與蒙皮：眨眼、張嘴、微笑、轉頭、抬手、蹲下、走跑及轉身成立；避免眼皮穿眼球、牙齒穿唇、關節扭縮、表面塌陷及衣髮穿模。

## 5. 碰撞證據不得擴大宣稱

驗證眼皮／眼球、牙齒／唇、頭髮／人體／衣物、衣物／人體／其他衣層，以及適用的自碰撞。合法接合、包含與碰撞排除須有結構依據，不可為了通過而排除失敗區域。

每份報告標明：幾何版本、組件配對、曲線／細髮數、半徑或厚度、姿勢與時間範圍、演算法、容差、穿透／相交、距離量測方式及失敗位置。區分以下證據：

- 控制點與頂點取樣，不能等同完整髮段、曲面或體積。
- 代表性導引，不能等同全部導引或子髮。
- 代理碰撞，只有已證明涵蓋範圍時才能用於相應實體；根部過渡也須可行。
- 靜態姿勢或離散影格，不能等同動作轉場；動態需掃掠／連續檢查，或有誤差界限的保守子步進。
- 靜止人體，不能等同移動人體；身體碰撞，不能等同毛髮自碰撞或其他眼部、眉睫組件碰撞。
- 取樣距離、保守下界及完整最短距離，必須分開標示。凹面內外分類不能只依最近面法線符號。

禁止可見穿模。自動檢查通過後仍須多角度及動態目視檢查；未解疑義標未通過，不將不確定算作零穿透。證據範圍須與展示的實際幾何、動畫插值及厚度一致。
