## 要完成的成果

用本機 Blender 完成**同一位完整成年女性**，使近景、多角度、裸體、衣著與動作均可信，頭髮自然飄動，分層可編輯，規定範圍無可見穿模，並能在 Aevrynd 自研引擎離線重建與運行。交付網格、UV、貼圖、材質、骨架、表情、動畫、毛髮、服裝、碰撞、LOD、匯入程式及可獨立開啟的 .blend。不得依賴 MetaHuman、Unreal、訂閱或持續收費的執行服務，不另裝大型軟體；第三方權利與義務如實保留，不冒稱獨占自有。女性經使用者明確認可後才開始男性。

**衡量單位是完整人物的可見改善或完整可用操作。** 每輪回答：主要缺陷有何減輕、整位女人是否更可信、受保護成果有無退步。版本、程式、參數、診斷、報告、封存及推送不能充當人物改善。

## 製作閉環：直接製作，先看完整成果

1. **定義一個可見問題。** 從實際頭／身及缺陷視角列至多三個主要缺陷，選最損害真人感的一個。開工最多六行，寫清工作來源與受保護成果、主缺陷、可核實參考、Blender 製作動作、可見判退條件、首次完整預覽的具體截止與資源。先定判準再製作。
2. **改實際構造。** 優先大形、解剖、五官關係、髮型與完整操作，再做微細節。採用藝術家資產前先檢視原作三維表面、變形與權利；分清觀察與假設。保留有希望的完整形體，直接重建阻塞的表面、拓撲、髮束、依附、有限厚度接觸或控制，再重綁接回同一女人；可改座標、拓撲與控制，不為舊數值犧牲構造。參考圖、生成圖、代理或導引只能輔助，不能當自己的完整人物成果。
3. **限制探索與支援。** 預設一個候選，單輪最多三種構造不同的方法，無須做滿，不做參數掃描。加密、換公式／包裝、調環列、半徑、權重、粗糙度、步數、阻尼、容差或平滑，不自動構成新方法。初始研究／診斷／支援合計最多10分鐘，首次完整預覽通常開工後30分鐘內；到點停止擴工具，轉直接可回退製作。延長須到期前報已有產物、原因及新截止，原期限與逾時仍保留。退出碼0不代替完成標記與產物；必要啟動修復續原工作，不算新人物輪次。
4. **先判完整外觀。** 同鏡位、光、曝光、姿勢輸出實際完整頭部／全身 A/B 與缺陷角度；變形含中間態、終態及回中性。舊圖標基線，元件、灰模、髮殼或局部補片不算完整預覽。先看主缺陷、整體可信度和受保護部位。可見失敗立即停止該方向的加密、參數變體與廣泛稽核，保存最低重現、重開、權利和回退證據。方向成立才補相關角度、第二照明及受影響驗證；不以缺全域證明推遲看圖，也不以外觀收益豁免相關失敗。
5. **證明相關可用性並接回。** 獨立重開 .blend，操作實際顯示、求值後幾何並回中性；屬性送達、is_bound、資料或骨架存在均不等於可用。毛髮須看實際髮型的轉頭、急停、風力和回穩，剛體跟隨不算自然飄動。只做支持本輪主張的必要驗證，未變區域核對版本及前提後引用既有證據；收益必須接回同一完整人物，不停在不相容的元件。

## 採用、判退與停滯規則

外觀、功能、接觸、引擎四門分別下結論，缺證／失敗不算通過。完整外觀 A/B 有可辨識淨收益且無受保護外觀退步，才可採用**寫明範圍的外觀改善**；受影響功能／接觸結論與缺口必須明示，已知相關退步不得略過。靜態外觀採用不等於完整操作、正式 runtime 或使用者認可，也不必等待無關門的全域證明。

新增完整可用操作，須在同一完整人物實際完成、回中性，相關範圍無已知失敗／退步。它只算功能收益，不能重設外觀停滯。無法辨識完整外觀淨收益就判退或保留研究，寫清可用範圍、缺口、待接回位置、失敗前提與停用範圍；不請使用者批准明知失敗的結果來解除停滯。

| 觸發條件 | 下一步，歷史立即計入 |
| --- | --- |
| 同方法兩個無效實際輪次 | 立即停用；有改變失敗前提的新證據才可便宜否證後重試。 |
| 三個實際輪次無採用完整外觀收益 | 下一製作輪必須改與主缺陷相關的基底／構造；形體差修形體，接合／操作阻塞就重建該部分，不必拋棄全部成果。 |
| 臉或毛髮仍不可信 | 任意三個實際輪次至少兩輪直接製作主要可見缺陷；不可見支援不得連續超過兩輪。 |
| 每三個實際製作輪次 | 檢視整位女人，含失敗／未登記實作；提案、元件快照及純啟動錯誤不冒充完成輪次，嘗試與成本仍保留。 |

只有**有證據採用的完整外觀收益**重設外觀停滯。基底保留、局部研究／控制、資料修復、保存、推送及提示詞維護均不重設。無採用外觀收益寫「本輪沒有採用外觀改善」；同時無新增完整可用操作，必須寫「本輪未改善完整人物」，再列局部收益。不能以四門分開或局部保留掩蓋長期無完整收益。

接觸結論必須與證據同範圍：

- 核實表示、插值、世界姿態和厚度；變形配對使用各自求值後的幾何。頂點離開表面不代表整個面片離開。控制點、導引、代理、髮片透明區不代表全部顯示髮絲；未證作者假設與渲染一致，不稱渲染占據精確通過／否證。
- 靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進；固定根部、數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱；封閉邊不證明無自交。
- 解剖接合／包含須有結構依據。禁刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過。有藝術／解剖依據的重建與尺度校準可以做，但原受影響結論失效，改根部重驗依附、解剖與接觸。來源問題不豁免，舊證據須核對版本與前提。
- 先便宜否證，不要求每輪先證全域；缺證不能說全通過。禁放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋失敗；診斷材質／光另列。

評分權重：解剖15%、臉部15%、眼睛10%、皮膚10%、毛髮15%、服裝與分層10%、骨架與動態10%、碰撞10%、引擎效能5%。先列缺陷，附確切版本、圖像／動作／量測、扣分理由與信心範圍。40＝明顯人偶／嚴重缺陷，60＝人工感強，80＝多角度可信但不足，90＝近景及動態可靠；屬審核估計。無新證據不升分，舊分不套新版；缺項未驗收，不算完整總分，自評不替代使用者認可。

**完成須全部成立：上述內容齊全；聲稱的靜態／動態範圍無可見穿模；.blend 可獨立重開並重建匯出；實際引擎材質、控制、動畫、物理、LOD、效能通過；嚴格加權至少85/100且每項至少80/100；使用者明確認可女性。** 硬性失敗不能平均掉；此前目標保持 active，不標 complete，不開始男性。

## 交付、交接與狀態

交付先說完整女人實際改善了什麼，沒有就明說。附實際頭／身 A/B、必要缺陷角度與動態、可獨立重開 .blend 的絕對路徑、四門證據與缺口、採用／保留範圍、下一個 Blender 動作、核實 GitHub 狀態及實際時間／資源成本。沒有新完整候選，不拿舊圖充成果。

continuation 只留必要來源／雜湊、有效證據、未登記產物、採用範圍、主缺陷、待接回操作、停用方法、live job、資源、原始時間與真實計數。完整歷史留原位，不反覆複製。新證據推翻原因就撤回推斷；提案不是實作或採用。

缺資訊時列已試路徑、證據、缺口、仍能做的部分與解鎖條件；blocked 遵循工具規則，困難、逾時或一次失敗不是自行停止理由。已授權離線製作、可回退開發整合及歷史保存自主完成，不反覆詢問。

提示詞維護只改本檔、兩處 AGENTS 入口、鏡像及最小維護／pending handoff。不啟動、完成、重算模型輪次或補候選驗收；模型、manifest、評分、採用、女性認可、計數和歷史發現不變，pending／staged 生產 blob 原樣保留且不混入提示詞提交。提示詞與 `sites-engine-journey/docs/character-continuous-goal.md` 逐位元組相同，兩處入口指向 v38 handoff。

目標保持 active；現有工具不能原地改寫 active objective，這次維護的是專案執行提示詞，不聲稱 stored objective 已替換，不清除／重建目標或新增排程。只有使用者明確要求才暫停；提示詞完成不等於人物完成。
