1. **先把參考轉成可編輯構造。** 實際查看相關多角度真人／可靠藝術來源，說明需要改的輪廓、體積、表面、內壁、接合或依附關係；未看過的圖不聲稱已核對。頭髮先做當前頭皮上的分線、髮際線、根到梢導引、前側後髮束層級與連續流向，再加細絲和動態。來源名稱、連通片或端點不自動代表毛囊、完整髮束、父子延續或伴隨層；重用須核實原生依賴與空間角色。權利未知只作參考，採用已核實來源或原創製作。
2. **直接用 Blender 改實際人物。** 原生雕塑、曲線雕梳、網格編輯與程式皆可，工具服從造型。先做能改變主要可見缺陷的形體，不用全頭公式、更多點／細絲或材質掩蓋尚未成立的構造。原開工起初始研究／診斷／工具支援合計最多10分鐘；一次最小實作確認能力後製作，不反覆巡查來源、API、求解器。最多三種構造不同的方法，不必做滿，不掃參數。
3. **通常原開工30分鐘內產出完整預覽。** 與基線同鏡位、光、曝光、姿勢，交完整頭／身 A/B 及缺陷角度；操作改動加實際中間、終態及回中性。自己查看實際圖片／動作，不以退出碼0判完成。孤立零件、導引、代理、灰模、髮殼、生成圖和他人作品只作診斷／參考。需延期就在期限前記已有產物、理由及新截止，保留原期限和逾時；啟動修復不是新人物輪次。
4. **完整結果先決定去留。** 主缺陷無可辨識淨改善，或完整真人感／受保護外觀退步，就停止該方向的精修、變體及廣泛稽核，只保留最低重現、獨立重開、權利與回退。構造失敗不能靠顏色、密度、半徑、曝光、遮蓋或縮小動作求通過，也不請使用者替判已知失敗。方向成立才補第二照明、相關操作和接觸；漂亮局部不能抵銷完整失敗，不要求每輪先證全域。
5. **驗證當前顯示結果，完成並復原。** 獨立重開 .blend，操作真正控制和求值後可見幾何。導引、屬性、is_bound、單點編輯只證元件能力。頭髮須看實際髮型轉頭、急停、風力和回穩，根部跟隨不等於自然飄動。只驗本輪主張及受影響範圍，舊證據先核對版本／前提。驗證失敗保留原反證；區分量測／表示問題與真實幾何失敗，不能為過測改門檻或隱去失敗。
