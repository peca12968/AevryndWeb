## 1. 製作循環與停損

開工記錄最多六行：完整來源／雜湊及現有 job；完整畫面前三缺陷與本輪選擇；預期畫面或可用操作；參考對應的具體製作動作；最便宜判退試驗與整合終點；首次預覽、成本上限及檢查點。

參考板涵蓋正面、斜角、側面、完整髮型與表面反應，記作者、來源及僅供觀察或可作資產。說出要改的輪廓、結構、反光或動作；不同鏡頭／光線只能定性比較。允許有依據、可比較的藝術調整，不把還原來源或高解析資料當成美術製作。

| 觸發 | 行動 |
| --- | --- |
| 便宜試驗已否證，或完整預覽不符合主要交付 | 立即停該方法，只留來源、安全重開、授權、重現失敗與回退所需證據。 |
| 同一方法連續兩輪無實質收益 | 改構造、依據或製作方式；改名及密度、半徑、剛度、阻尼、步數、容差掃描不算新方法。 |
| 不可見依賴／支援診斷已連續兩輪 | 下一輪回完整人物的主要製作／整合。無法整合的層保留未驗收，採安全回退或換依賴方案，不再無限展開同一局部問題。 |
| 三輪未解決主要缺陷或增加完整可用能力 | 指出共同失敗原因，改變製作依據、構造或拆題方式；只換 nextAction 不算。 |
| 有用研究尚未整合 | 記用途、目標部件及最小整合動作；未整合只算研究，不能繼承完整角色通過。 |

完整外觀尚未可信時，每個三輪窗口至少兩輪直接製作主要可見缺陷。依賴阻擋整合而超出上限，保存現狀與失敗，選能推進完整人物的製作；不得靠隱藏、豁免碰撞或降低標準解套。按歷史實際工作計數，不能改標籤繞過。

預設一個候選；新證據支持不同構造才增加，單輪最多三種方法。診斷足以選製作動作就結束診斷。驗證有錯用獨立依據修正並記原因，不改測試迎合候選。必要檢查通過且無新風險即交付，不擴張無關檢查。三輪回顧併入實際製作，不另開報告輪；失敗試驗也計數。

## 2. 完整角色與四項驗收

| 里程碑 | 實際成果 |
| --- | --- |
| 可信完整人物 | 頭臉與身體解剖、比例、完整髮型、主要材質在多角度可信；孤立眼睛或牙齒近照不足。 |
| 可操作完整人物 | 分層可編輯；身體、表情、衣髮操作與對應接觸成立，可保存、重開、回中性。 |
| 自研引擎角色 | 同一來源可重建並載入 Aevrynd，材質、動畫、毛髮、碰撞、LOD、效能及女性認可成立。 |

可交錯製作，不要求物理與引擎全部完成才改善外觀。完整工作人物可包含明示未驗收層；具限定證據的基礎、完整工作來源、回退點、研究與正式 runtime 分開。未登記產物先核實來源、證據和用途，不能因 manifest 過期重做或直接採用。

| 項目 | 通過依據 |
| --- | --- |
| 外觀 | 實際三維完整頭部／全身，固定鏡位、姿勢、光線、曝光 A/B，必要角度及第二照明；明列可見收益、退步、最大剩餘缺陷。像素不同不等於更真。 |
| 功能 | .blend 可獨立重開，資料有限，分層可編輯，拓撲／權重／骨架／控制有效，操作可重現並回中性，來源與匯出可重建。選取分組不是蒙皮。 |
| 接觸 | 聲稱範圍內實際顯示幾何無可見穿模，記版本、配對、姿勢／時間、厚度／半徑、方法、容差、距離定義和失敗位置。未測或無法證明者未驗收。 |
| 引擎 | Aevrynd 實際場景的載入、材質、骨架、動畫、毛髮、碰撞及 LOD；事前定硬體、解析度、預算，量單角色近景、遊戲距離、多角色 CPU／GPU 時間與記憶體。 |

技術通過不代表外觀可信；Blender 流暢或匯出成功不代表引擎通過。可見改善且受影響檢查通過，或完整操作可用且外觀未退步，才納入已證明的工作範圍。局部功能不提高外觀分數、不消除整體停滯，完整未通過不提升正式資產。

接觸聲稱必須遵守：

- 檢查實際曲線／曲面／體積、插值、世界姿態及有限厚度。導引、控制點、代理、髮片、透明區不能代替全部顯示髮絲；零穿透點仍須目視。髮片與髮絲碰撞表示及限制要明說。
- 人體、自碰撞、衣物分開；靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或具誤差界限的保守子步進。穩定、根部跟隨和剛體轉動不等於自然動態。
- 取樣最小值、保守下界、真正全域最短距離分開；凹面內外不能只用最近面法線。寬階段重疊不等於穿透，低於數值門檻的正間距也不是相交；弦長、粒子邊長、弧長及材料伸長不得混稱。
- 合法解剖接合／包含需來源與結構依據；不能任意排除失敗髮根或移走問題區。改髮根要重驗依附、解剖及接觸。來源原有問題不豁免採用檢查。
- 先做最便宜有效否證，再補採用證據。缺全域證明不能成為永不製作的理由，也不能宣稱全部通過。舊證據僅在版本、幾何、運動及其他前提核實相符後沿用。

## 3. 完整品質與完成條件

- **頭臉、表情：** 成年頭骨、五官、耳頸肩多角度合理並有自然不對稱。眼部含角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線、睫毛，深度、折射、高光、接觸可信；近似明示。口腔含上下牙齒、牙齦、舌頭、必要內壁及正確下頜控制。驗證眨眼、轉眼、張嘴、微笑、轉頭。
- **皮膚：** 有依據的區域色差、粗糙度、微法線、次表面反應與自然不對稱。固定曝光追蹤膚色，防止逐輪變黑、蠟像、面具感。
- **毛髮：** 髮際線、分線、鬢角、耳後、後腦、髮尾連續，有大形、中束、細絲及少量飛散髮；拒絕帽殼、片簾、漏斗、切齊與鋼絲感。真實頭皮依附、分區剛度、重力、慣性、阻尼、接觸反應；驗證轉頭、急停、風力、回穩，明示彎曲、扭轉、摩擦、氣動校準程度。
- **身體、衣服：** 裸體比例、手腳、關節及變形合理，不以衣髮遮解剖。衣物有厚度、接縫、摺痕及活動空間。中性、抬手、蹲下、走路、跑步、轉身無塌陷、扭縮及可見穿模。
- **分層：** 身體、眼部組件、口腔、上下牙齒、牙齦、舌頭、眉毛、睫毛、頭皮、頭髮、內外衣、配件、骨架、控制器、碰撞代理清楚命名，可獨立編輯／切換，記完成度、綁定與運行表示。
- **引擎：** 網格、UV、貼圖、材質、骨架、morph、動畫、毛髮、碰撞、LOD、匯入程式成為 Aevrynd 一部分，從 Blender 權威來源可重建，真實場景畫面及效能達預定預算。

先看實際畫面列缺陷，再給附版本、證據、扣分原因、信心範圍的審核估計。40 為明顯人偶／嚴重缺陷，60 人工感強，80 多角度可信但不足，90 近景與動態可靠；不是客觀真人相似度。缺項標未驗收、不計完整總分；無新增證據不改分，舊版分數不能套新版。

權重保留：解剖 15%、臉部 15%、眼睛 10%、皮膚 10%、毛髮 15%、服裝與分層 10%、骨架與動態 10%、碰撞 10%、引擎效能 5%。

**女性完成須同時成立：** 加權至少 85/100、每項至少 80/100；完整分層及指定動作齊全；靜態、動態無可見穿模；引擎品質／效能通過；來源可獨立開啟及重建；使用者明確認可。硬性失敗不能以平均分抵銷。此前不宣告完成、不開始男性。
