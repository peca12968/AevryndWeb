## 3. 每輪執行協議

1. 先讀本文件、manifest 與最新 continuation；僅按其中指向的證據讀取必要片段，不反覆載入全部歷史和巨大報告。確認既有工作是否仍在執行，不重複啟動。辨認「正式來源／目前保留的工作來源／判退研究」後，從保留來源開始，選一個對當前里程碑最有影響的問題。
2. 寫清假設、預期畫面差異及失敗條件；先做能區分原因的最小診斷，必要時查原始文件。不要未查明原因就掃描大量參數。
3. 建立 1 個候選；只有存在不同且可解釋的方案時才增加，單輪最多 3 個。允許重建限制品質的拓撲、雕刻形體、重做 UV／貼圖／毛髮結構，不局限於既有生成腳本的小幅調參。
4. 固定對照組的相機、曝光、色彩管理、燈光、姿勢、解析度與裁切。另用側光或第二種光照檢查穩健性；光照實驗需獨立標記，不能算成模型改善。圖片須來自交付的三維資產，並實際打開檢視。
5. 只執行受本次變更影響的技術檢查；其餘沿用與確切資產雜湊相符的有效證據。只有新變更、失敗或新風險才擴大或重跑。幾何不變的材質實驗不必反覆重算完整碰撞。
6. 分別記錄外觀、結構、碰撞及效能結果。採用、研究保留、判退三者明確區分；技術通過但沒有可辨識外觀改善，不得當作擬真品質提升或升分。必要的結構修正可保留為研究來源，仍須往可見成果推進。
7. 保存並展示最能說明結論的同鏡位前後圖，指出改善處、退步處與下一個主要缺陷。更新狀態、精確提交並確認推送結果，接續下一個有價值的工作。

連續兩輪同方法無可見改善：記錄失效方法，停止同類微調，改查根本形體、材質光學、拓撲或動態架構。診斷必須排除具體原因或導出下一項可執行修改；不得連續只產生報告、版本號或相同測試。每完成一項主要部位，重新評估整體人物並交付可見里程碑。

## 4. 品質與碰撞硬性要求

- 解剖：成人比例、頭骨與五官結構、多角度輪廓、耳頸肩、手腳及關節合理。自然不對稱有依據，不靠任意雜訊。裸體基礎不得靠衣髮掩蓋錯誤。
- 眼睛與口腔：角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線、睫毛及口腔結構明確；反射、折射、深度與遮擋成立。不得用錯誤光學模型消除瑕疵後宣稱物理正確。
- 皮膚：以參考建立區域膚色、粗糙度、微法線與次表面反應，先修大形再加細節；禁止人物逐輪變黑或以曝光補償掩蓋問題。
- 毛髮：髮型大形、中型髮束、細絲及少量飛散髮分層；髮根、分線、髮際線、耳後及髮尾連續自然。動態包含根部約束、分區剛度、重力、慣性、阻尼與碰撞；檢查轉頭、急停、風力與回穩過程，不僅展示靜態曲線。
- 毛髮製作依序驗證輪廓和分線、稀疏導引、子髮插值、細絲材質、動態及引擎表示。先以可靠的頭部／耳頸外圍路徑處理導引，保持實際頭皮髮根約束；完整導引的含半徑髮段通過碰撞後才展開子髮。無碰撞導引不保證插值後無碰撞，最終子髮仍須重檢完整髮段與半徑。只檢查控制點、只增加密度、反覆將最近點推離皮膚，皆不能作為完整碰撞解法。外圍代理需驗證涵蓋範圍，代理通過不能自動等同實際人體通過。
- 資產分層：身體、眼部各組件、口腔、牙齒、舌頭、眉毛、睫毛、頭皮、頭髮、內外衣、配件、骨架、控制器及碰撞代理分別命名、可編輯及可切換。衣物有厚度、接縫和合理摺痕。
- 不可見穿模：檢查眼皮／眼球、牙齒／唇、頭髮／人體／衣物、身體／衣物及衣物各層。按組件定義合法接合、包含與碰撞排除；不得為通過檢查任意排除有問題的區域。
- 碰撞報告寫明組件配對、幾何版本、姿勢或影格、演算法、容差、穿透與相交數、距離量測方式及失敗位置。閉合實體內外分類須可靠；最近面法線的符號不能單獨作為凹面穿透結論。報告最小距離時須明確區分頂點取樣距離與完整表面最短距離。
- 靜態零相交只證明已測姿勢；動態須檢查轉場和足夠時間取樣，快速動作採掃掠／連續檢查或有依據的保守子步進。缺少這些證據不得宣稱所有動畫零穿模。可見穿模、結構破壞或未解決的檢查疑義皆不得通過相應驗收。
- 效能報告記錄硬體、解析度、渲染設定、角色數、LOD、頂點／三角形、骨骼、morph、材質、貼圖、毛髮規模、檔案大小、CPU／GPU 時間與記憶體。先確立目標場景與預算，再依實測判定；未量測不宣稱可用。
