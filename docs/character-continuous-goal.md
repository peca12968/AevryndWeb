## 成果契約

以角色美術與技術美術的標準，用本機 Blender 持續完成**同一位完整成年女性**：近景、多角度、裸體、衣著及動作均可信，頭髮自然飄動，分層可編輯，規定範圍無可見穿模，可在 Aevrynd 自研引擎離線重建及運行。交付包含網格、UV、貼圖、材質、骨架、表情、動畫、毛髮、衣物、碰撞、LOD、匯入程式及可獨立開啟的 .blend。不得依賴 MetaHuman、Unreal、訂閱或持續收費的執行服務，不另裝大型軟體；保留第三方權利與義務，不冒稱獨占自有。女性須經使用者明確認可，才開始男性。

每輪要回答：**這位女人哪個主要缺陷被改善，完整畫面及操作怎麼證明？** 版本增加、元件重建、程式量、診斷、報告、保存與推送各有用途，但不能充當人物收益。

## 唯一接續入口

永久規則在本檔；當前工作人物、採用範圍、評分與計數以 asset manifest 及最新有效 audit／continuation 為準；未完成工作看 `Info/CharacterGoalPrompt-v37-update.json` 的 `pendingWorkHandoff`。較新的實際產物與證據優先於交接快照及提案，矛盾先核對，不改寫歷史。正式來源、工作基底、未驗收候選、局部研究與回退分清，保留一個明確工作人物。

接續只讀本檔、manifest、最新有效 audit／continuation、最小 handoff 及當前必要來源／圖像／log，不重掃全部歷史。**已有完整候選先判讀已有預覽；已有診斷直接接用；已有 job 沿原 handle 觀察。** 觀察逾時不等於工作失敗，不重啟 job。中斷、壓縮、啟動錯誤及提示詞維護均保留原開始時間、期限、嘗試、失敗與成本，不另開同輪、不覆寫候選、不重算計數。

## 製作閉環

**找主要缺陷 → 參考與構造 → Blender 直接製作 → 完整 A/B → 範圍決策 → 必要驗證與接回。** 優先大形、解剖、五官關係、髮型和完整操作，再做微細節。臉或頭髮不可信時，不以不可見支援取代主要可見缺陷。

1. **定義這輪。** 從實際頭部、全身、缺陷角度列至多三個主要問題，選最損害真人感且可直接製作的一個。開工說明最多六行：來源／受保護成果、主缺陷、可核實參考、直接 Blender 動作、可見判退條件、首次完整預覽的具體截止與資源。判準事前定義，不看完結果才改目標。
2. **先做實際構造。** 核對解剖或藝術參考；採藝術家資料先看原作三維表面、變形和權利。分清觀察、假設及否證。參考圖、生成圖、導引及代理明示用途，不能替代自己的完整人物。直接修實際表面、髮束或操作；保留有希望的完整形體。若阻塞在拓撲、依附、有限接觸或控制，重建阻塞部分並重綁、接回同一人物，保留原來源／回退。必要時可改座標、拓撲及控制，不為舊數值犧牲人體構造。
3. **限制探索。** 預設一個候選，單輪最多三種構造不同的方法，不必做滿；不得參數掃描。先查停用方法的失敗前提。換名稱／參考／演算法包裝、加密／環列／方程式，或掃半徑、權重、粗糙度、步數、阻尼、容差及平滑，均不自動成新方法；須指出改變的失敗前提。
4. **盡早看完整人物。** 初始研究／診斷／支援最多10分鐘，首次完整預覽通常開工後30分鐘內。到點停止擴工具，轉直接可回退製作；不擴成泛用 API／求解器／驗證框架。需延長時到期前報已有產物、原因與新截止，原期限／逾時照記。退出碼0、無解、警告、缺變數或缺完成標記不算成功；只修必要執行錯誤，續原工作。
5. **先判可見成敗。** 同鏡位、光、曝光、姿勢輸出工作人物／候選的實際完整頭部與全身 A/B、主缺陷角度；變形須有實際中間態、終態、回中性。局部補片、白模、髮殼、導引與元件 .blend 不算完整預覽；舊圖標基線。回答主缺陷是否減輕、完整女人是否更可信、受保護部位是否退步。已可見失敗就停止該方向加密、參數變體、全面動作與廣泛稽核，保存最低重現／重開／權利／回退證據。方向成立才補相關角度、第二照明及受影響門；不以全域證明尚缺推遲看圖，不以外觀較好豁免相關失敗。
6. **證明可用並接回。** 只做支撐本輪結論的必要驗證；未變區域核對版本及前提後引用既有證據。候選獨立重開，操作必須作用在實際顯示、求值後的幾何並回中性；屬性送達、is_bound、資料或骨架存在不等於操作可用。頭髮要看實際髮型的轉頭、急停、風力、回穩，剛體跟隨不算自然飄動。保留的收益接回同一完整人物，不能停在互不相容的元件。

## 決策與停滯

| 決策 | 必要證據與限制 |
| --- | --- |
| 採用完整外觀改善 | 完整 A/B 有可辨識淨收益、無受保護外觀退步；受影響功能／接觸有相關證據，退步及缺證明示。寫明採用版本／範圍，接回工作人物；不等於完整功能、正式 runtime 或女性認可。 |
| 新增完整可用操作 | 同一完整人物實際完成操作、回中性，相關範圍無已知失敗或退步；僅記功能收益，不能重設外觀停滯。 |
| 保留基底／局部研究 | 寫明理由、可用範圍、缺口、待接回位置；換基底、局部收益及方向保留均不算完整外觀採用。 |
| 判退 | 保存實際失敗、失敗前提、停用範圍與回退；不污染正式資產，不請使用者批准明知失敗的結果來解除停滯。 |

四門分開，結論限於證據範圍：當輪外觀採用不必等無關引擎／全域證明完成，但相關失敗／缺證不能算通過，也不能稱完整驗收。無法辨識完整淨收益就保留研究，不硬採用。沒有採用外觀收益，寫「本輪沒有採用外觀改善」；也沒有新增完整可用操作，必須寫「本輪未改善完整人物」，再列局部收益。

- 同方法兩個無效實際輪次立即停用；重試須有改變失敗前提的新證據，先便宜否證。三個實際輪次無採用完整外觀收益，下一輪必須改與主要缺陷相關的基底／構造。形體差修形體，形體有希望但接合／操作失敗則重建阻塞部分，不必拋棄全部成果；歷史立即計入。
- 臉／毛髮不可信時，任意三個實際輪次至少兩輪直接製作主要可見缺陷，不可見支援不得連續超過兩輪。每三輪檢視整位女人，失敗／未登記實作照算；純啟動錯誤、提案與元件快照不是已完成模型輪次，嘗試／成本仍保留，未知計數不捏造。
- 診斷、研究、局部控制、基底保留、資料修復、保存、推送與提示詞維護不重設外觀停滯；只有有證據採用的完整外觀收益可以重設。四門分開與局部保留不得成為掩蓋長期無完整收益的理由。

接觸結論必須與證據同範圍：

- 核實表示、插值、世界姿態和厚度；變形配對使用各自求值後的幾何。頂點離開表面不代表整個面片離開。控制點、導引、代理、髮片透明區不代表全部顯示髮絲；未證作者假設與渲染一致，不稱渲染占據精確通過／否證。
- 靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進；固定根部、數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱；封閉邊不證明無自交。
- 解剖接合／包含須有結構依據。禁刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過。有藝術／解剖依據的重建與尺度校準可以做，但原受影響結論失效，改根部重驗依附、解剖與接觸。來源問題不豁免，舊證據須核對版本與前提。
- 先便宜否證，不要求每輪先證全域；缺證不能說全通過。禁放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋失敗；診斷材質／光另列。

評分權重：解剖15%、臉部15%、眼睛10%、皮膚10%、毛髮15%、服裝與分層10%、骨架與動態10%、碰撞10%、引擎效能5%。先列缺陷，附確切版本、圖像／動作／量測、扣分理由與信心範圍。40＝明顯人偶／嚴重缺陷，60＝人工感強，80＝多角度可信但不足，90＝近景及動態可靠；屬審核估計。無新證據不升分，舊分不套新版；缺項未驗收，不算完整總分，自評不替代使用者認可。

**完成須全部成立：上述內容齊全；聲稱的靜態／動態範圍無可見穿模；.blend 可獨立重開並重建匯出；實際引擎材質、控制、動畫、物理、LOD、效能通過；嚴格加權至少85/100且每項至少80/100；使用者明確認可女性。** 硬性失敗不能平均掉；此前目標保持 active，不標 complete，不開始男性。

## 交付、交接與目標狀態

交付先說完整女人改善了什麼，沒有就明說。附實際頭／身 A/B、必要缺陷角度與動態、可獨立重開 .blend 的絕對路徑、四門證據／缺口、採用或保留範圍、下一個 Blender 動作、核實 GitHub 狀態及實際時間／資源成本。沒有新完整候選，不拿舊圖充成果。

continuation 只留必要來源／雜湊、有效證據、未登記產物、採用範圍、主缺陷、待接回操作、停用方法、live job、資源、原始時間與真實計數；完整歷史留原位，不反覆複製。已有診斷不重跑；新證據推翻原因就撤回推斷，提案不是實作或採用。

真缺資訊時列已試路徑、證據、缺口、仍能做的部分與解鎖條件；blocked 依工具規則，不因困難、逾時或一次失敗停止。已授權離線製作、可回退開發整合及歷史保存自主完成，不反覆詢問。

提示詞維護只改本檔、兩處 AGENTS 入口、鏡像及最小維護／pending handoff。不啟動、完成或重算模型輪次，不補候選驗收，不改模型、manifest、評分、採用、女性認可、計數及歷史發現；pending／staged 生產 blob 原樣保留，不混入提示詞提交。本檔與 `sites-engine-journey/docs/character-continuous-goal.md` 逐位元組相同，兩處入口指向 v37 handoff。

目標保持 active；現有工具不能原地改寫 active objective，只維護專案執行提示詞，不聲稱 stored objective 已替換，不清除／重建目標或新增排程。只有使用者明確要求才暫停；提示詞完成不等於人物完成。
