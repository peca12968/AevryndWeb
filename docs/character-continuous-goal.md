## 主提示詞

用本機 Blender 持續完成**同一位寫實成年女性**，並把可重建的角色資料與必要程式整合到 Aevrynd 自研引擎。交付的是可看、可動、可編輯、可離線運作的完整人物：頭臉、皮膚、毛髮、裸體身體、服裝、明確分層、骨架、表情、自然動態、碰撞與 LOD。最終在多角度、不同照明及指定動作下可信，無可見穿模。全部品質門通過且使用者明確認可女性後，才開始男性。

每次製作先讀本文件、資產 manifest 與最新有效證據，核實完整工作來源、未登記成果和現有工作程序，再看實際完整頭部與全身。從最明顯的三個缺陷中選**一個主要成果**；說清楚畫面應如何改善，或哪項完整操作應變得可用。先前 nextAction 只是建議，須按新證據重選。

用有來源的真人解剖與專業角色參考決定具體製作動作。先處理大形、結構、髮型與表面反應；必要時重新雕塑、重拓撲、梳理可編輯導引或重建限制品質的部件。預設一個候選，先做便宜的完整頭部／全身預覽和最可能揭露失敗的檢查。有效才繼續；失敗就停止該方法。不要以微調參數、增加細絲、還原來源預設值或堆疊修補代替製作判斷。

每輪先回答：**完整人物的哪個主要缺陷改善了，或哪項完整操作現在真的可用？** 再分別報告外觀、功能、接觸、引擎的證據與缺口。局部改善可以保留，但不能冒充完整人物進展。診斷、驗證工具、版號、報告與提交本身不提高品質；接觸失敗不能因外觀變好而豁免。

同一方法連續兩輪無實質收益就換構造或製作依據。每三個實際製作輪次比較窗口前後的完整人物；若仍未解決主要缺陷或增加完整可用能力，必須改變做法。臉和頭髮仍像人偶時，三輪中至少兩輪直接製作主要可見缺陷。局部研究、封存及提示詞更新不重設停滯計數。

交付實際 .blend、固定條件的完整頭部／全身 A/B，及支持採用所需的角度、第二照明與真實動態片段。先展示完整成果，再提供局部證據。保持膚色、解剖、分層與原有可用操作；禁止靠變暗、遮擋、換光、縮小動作或放寬標準掩蓋問題。直接完成已授權、可回退的製作、隔離整合與歷史保存；全部完成條件成立前，目標保持未完成。

## 1. 每輪如何決定與停止

開工紀錄最多六行：來源／雜湊及 live job；完整畫面前三缺陷與選擇；預期成果；參考對應的 Blender 操作；最便宜判退試驗及整合終點；首次預覽與資源上限。既有畫面在來源、鏡位、姿勢和渲染條件核實一致時可重用，不為開工重渲染同一基線。

1. **看完整人物。** 以真實三維結果選問題，不按最容易寫腳本或證明的局部選題。參考涵蓋正面、斜角、側面、完整髮型及表面反應，記作者、來源與用途；鏡頭／光線不同僅能定性比較。
2. **做一個有依據的改變。** 說明失敗原因及新構造如何處理它，再花重型計算。預設一個候選；只有新證據支持不同構造才增加，單輪最多三種方法。改名或掃描密度、半徑、色素、粗糙度、剛度、阻尼、步數與容差不算新方法。
3. **先判退，再補採用證據。** 便宜預覽或有效幾何檢查已否證，即停止該方法的昂貴擴測。驗證器有錯就用獨立依據修正、留下原因，不能改測試迎合候選。受影響檢查通過且無新疑點後交付，不擴張無關檢查。
4. **把有效部分接回完整人物。** 研究必須記用途、目標層及最小整合動作；未整合只是研究。可將有外觀收益的研究留在明示未驗收的完整工作檔中，但接觸／動態失敗的改動不得列為已通過能力或正式資產。
5. **保留失敗，改變行動。** 一次診斷只回答阻擋交付的具體問題；得到足以選製作動作的答案就結束。不可見依賴與支援診斷最多連續兩個製作輪次；到期保留有效部分和失敗，改用可回退層或不同依賴方案，回到完整人物交付。不得隱藏問題或排除失敗區來解套。

每三輪回顧併入製作，不另開報告輪。按實際工作計數，失敗試驗也計入；不能把診斷改名為製作，或把局部證明改名為完整能力。回顧須指出共同失敗原因及下一個實質不同的製作動作；只換 nextAction 或增加提示詞不算改變。

## 2. 四道品質門與採用範圍

同一完整角色分三階段推進：多角度可信的完整外觀、可操作且可回到中性的完整人物、在 Aevrynd 實際場景運行的角色。階段可交錯；物理與引擎尚未齊備時仍要改善外觀，也可做可回退的隔離引擎試驗。

| 品質門 | 需要的證據 |
| --- | --- |
| 外觀 | 實際完整頭部／全身；相同鏡位、姿勢、光線、曝光 A/B。方向成立後補必要角度及第二照明。明列可見收益、退步與最大剩餘缺陷；像素不同不等於更真。 |
| 功能 | .blend 可獨立重開；資料有限；分層可編輯；拓撲、UV、權重、骨架、控制與操作成立，可重現並回中性；可從來源重建匯出。選取分組不等於蒙皮。改動動態必須有實際播放片段。 |
| 接觸 | 聲稱範圍內的實際顯示幾何、有限厚度與姿態／時間檢查；記版本、配對、方法、容差、距離定義及失敗位置。人工多角度檢視不可省；未測或證據不足標未驗收。 |
| 引擎 | Aevrynd 實際場景的載入、材質、骨架、動畫、毛髮、碰撞、LOD 與效能。事前定硬體、解析度和預算；量單角色近景、遊戲距離、多角色 CPU／GPU 時間及記憶體。 |

外觀改善且受影響檢查成立，或完整操作可用且外觀未退步，才增加**已證明的工作範圍**。技術通過不代表外觀可信；Blender 流暢、匯出成功不代表引擎通過。部分通過不能提升正式資產。來源、完整工作人物、限定證據的基礎、回退、研究與正式 runtime 必須分開標示；原有未驗收層不因此取得資格。

接觸證據必須守住以下邊界：

- 對應實際曲線／曲面／體積、插值、世界姿態和有限厚度。導引、控制點、代理、髮片及透明區不能代替全部顯示髮絲。作者假設的曲線模型與實際渲染表示未核實一致時，不能宣稱渲染幾何已通過或已被精確否證。
- 人體接觸、自碰撞、衣物分開；靜態、離散影格、連續時間分開。連續聲稱要有掃掠／連續檢查或帶誤差界限的保守子步進。剛體跟隨、穩定或根部固定不等於自然動態。
- 取樣最小值、保守下界及真正全域最短距離分開。寬階段包絡重疊不等於實際穿透；正間距低於數值門檻不等於相交；凹面內外不能只用最近面法線。弦長、粒子邊長、弧長和材料伸長不得混稱。
- 合法解剖接合／包含需要結構與來源依據，不能任意排除失敗髮根或移走問題區。改根部要重驗依附、解剖及接觸；來源既有問題不豁免採用檢查。
- 先做便宜有效否證，再補採用證據；不要求全域證明先於每次藝術製作，也不能以缺全域證明宣稱全部通過。沿用舊證據前核實版本、幾何、運動及其他前提。

## 3. 完整角色的交付標準

- **頭臉與表情：** 成年頭骨、五官、耳頸肩解剖多角度合理，有自然不對稱。眼部包括角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線與睫毛，深度、折射、高光及接觸可信；近似表示要明示。口腔包括上下牙齒、牙齦、舌頭、必要內壁與正確下頜控制。驗證眨眼、轉眼、張嘴、微笑、轉頭。
- **皮膚：** 有依據的區域色差、粗糙度、微法線與次表面反應；固定曝光追蹤膚色。避免逐輪變黑、蠟像、面具及過度平滑。
- **毛髮：** 髮際線、分線、鬢角、耳後、後腦、髮尾連續，具大形、中束、細絲與少量飛散髮；拒絕帽殼、片簾、漏斗、切齊與鋼絲感。真實頭皮依附、分區剛度、重力、慣性、阻尼和接觸反應；驗證轉頭、急停、風力、回穩，明示彎曲、扭轉、摩擦及氣動校準程度。
- **身體與衣服：** 裸體比例、手腳、關節與變形合理，不靠衣髮遮解剖。服裝有厚度、接縫、摺痕及活動空間。中性、抬手、蹲下、走路、跑步、轉身無塌陷、扭縮與可見穿模；裸體、單層及多層服裝均須檢查。
- **分層：** 身體、眼部組件、口腔、上下牙齒、牙齦、舌頭、眉毛、睫毛、頭皮、頭髮、內外衣、配件、骨架、控制器、碰撞代理清楚命名，可獨立編輯／切換，記完成度、綁定及運行表示。
- **引擎：** 網格、UV、貼圖、材質、骨架、morph、動畫、毛髮、碰撞、LOD 與匯入程式成為 Aevrynd 的一部分，可由 Blender 權威來源重建，實際場景畫面與效能達預定預算。

評分先看畫面列缺陷，再附版本、證據、扣分原因與信心範圍。40 為明顯人偶／嚴重缺陷，60 人工感強，80 多角度可信但不足，90 近景與動態可靠；這是審核估計，不是客觀真人相似度。缺項標未驗收、不計完整總分；無新增證據不改分，舊版分數不得套到新版，局部功能不得提高外觀分數。

權重：解剖 15%、臉部 15%、眼睛 10%、皮膚 10%、毛髮 15%、服裝與分層 10%、骨架與動態 10%、碰撞 10%、引擎效能 5%。

**完成必須同時成立：** 加權至少 85/100、每項至少 80/100；完整分層與指定動作齊全；靜態、動態無可見穿模；引擎品質／效能通過；來源可獨立開啟與重建；使用者明確認可女性。硬性失敗不能被平均分抵銷。在此之前不宣告完成、不開始男性。

## 5. 交付、接手與生效

交付順序：實際結果；完整人物 A/B／必要角度／變更動態；可開啟 .blend 絕對路徑；四門結果與缺口；採用範圍或判退；下一個具體製作動作；核實 GitHub 狀態。沒有新完整候選就明說，不能把重複基線、生成參考圖或他人作品當作新成果。

continuation 只留接手必需資訊：完整來源／雜湊、未登記成果、有效證據與採用範圍、主要缺陷是否解決、整合缺口、停用方法及原因、live job、資源與下一建議。分開記外觀、完整功能、局部研究及整體進展；沿用真實三輪窗口與停滯計數，包含已做但尚未封存的失敗試驗，不改名歸零。

使用者要求提示詞維護時，更新規則與接手入口即可交付，不順帶啟動模型輪次、不改 manifest、分數、採用、女性認可或計數。核實並保留先前工作；後續製作先做必要最小接手，不把待封存工作擴大成另一輪診斷。
