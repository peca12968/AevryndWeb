## 主提示詞

持續用本機 Blender 完成一位可在 Aevrynd 自研引擎離線運行的寫實成年女性。交付的是同一位能編輯、能動作、能匯入引擎的完整人物：頭臉、皮膚、完整髮型、身體、明確分層、表情、骨架、服裝、自然毛髮動態、碰撞和 LOD。裸體與穿衣、多角度及指定動作都要成立。女性通過全部驗收且使用者明確認可後，才開始男性。

先處理使用者最新要求。製作續跑先讀本文件、資產 manifest 及最新有效證據，核實完整工作來源、未登記產物和現有 job，直接看完整頭部與全身。continuation 的 nextAction 是建議，須依實際畫面重新判斷。提示詞維護不啟動模型輪次，不改採用、分數或停滯紀錄。

每輪先從完整畫面列出三個最大問題，只選一個有分量的交付：解決一個可清楚辨識的主要外觀缺陷，或使同一完整角色真正多出一項可用操作。先修比例、解剖、髮型大形、髮際線與主要材質，再做微細節；必要的綁定、接觸與引擎依賴可提前。不要把一個問題拆成永遠不回到完整人物的小研究，也不要為了避開困難不停換子系統。

用真人解剖及第一手角色製作參考，寫明要改的輪廓、結構、表面反應或動作，以及具體 Blender 操作。預設製作一個完整候選，先用便宜的完整頭部／全身預覽或有效否證檢查方向。診斷足以決定製作動作就停止診斷；接著實際雕塑、重拓撲、整理髮束、繪製材質、綁定或整合。來源還原和高解析資料只能提供依據，不能代替美術製作；允許有依據、可比較的調整，不以保留作者預設值為品質目標。

方向成立後，把修改整合回同一完整女人物，再驗證受影響範圍。交付可直接開啟的 .blend、同條件完整頭部／全身 A/B、必要角度和第二照明；改動動態就交實際播放片段。先看完整人物，再用近照說明。外觀、功能、接觸、引擎分開判定；改暗膚色、遮擋、換光、平滑、縮小動作或放寬門檻不能算修復。生成圖及他人模型圖只可作參考。

只把有證據的改善納入完整工作角色，保留已證明的成果與回退點。每項有用研究都要有用途、整合目標及最小整合步驟；不強迫採用無效研究，也不讓研究繼承碰撞、動態或引擎通過。工作人物、具限定證據的基礎與正式資產各自清楚標示。

每輪誠實回答：「完整人物哪裡變好，或哪項操作現在真的可用？」兩者都沒有就記未改善，不因節點、貼圖、通過數、版號、研究否證或 GitHub 提交升分。同一方法連續兩輪無實質收益就停；每三輪與窗口前的完整人物比較，仍未解決主缺陷或增加完整可用能力，就改變製作依據、構造或必要依賴，不能只更換 nextAction 或繼續局部參數試驗。

直接完成已授權、可回退的離線製作與整合。便宜試驗已失敗就停止該方法，保存足以重現的失敗證據，不再替它跑昂貴的全面驗證。把時間用於人物製作與畫面判斷，重用有效檢查和保存流程。到資源檢查點就核對成本與剩餘工作，不能把到點或寫完報告當作完成。全部門檻及女性認可成立前，整體目標維持未完成。

## 1. 製作循環與停損

開工契約最多六行：①完整工作來源／雜湊、採用範圍、未登記產物與 live job；②完整畫面前三缺陷及本輪主缺陷；③預期可見改善或完整操作及必要依賴；④參考如何轉成具體製作決策；⑤最便宜試驗、判退條件及完整角色整合終點；⑥資源上限、首次預覽與檢查點。可辨識改善要說出具體位置和表現；像素差異或「感覺更自然」不足。功能要能實際操作、重開、回到中性，列出適用範圍，不能只新增控制器名稱。

建立可重用的成年真人／專業角色參考板，涵蓋正面、斜角、側面、完整髮型及主要表面反應；標明來源與只供觀察或可作資產的用途。每輪把本輪主缺陷對應到其中具體結構，既與舊版 A/B，也核對是否更接近可信的人體。不同鏡頭或光線的參考只能作定性判斷，不能假裝為精密量測。若基底比例、面部結構或髮型大形仍不成立，直接雕塑、重建或核實更適合的基底，不以微細節連續裝飾錯誤大形；保留已證明的部件，必要時重新綁定並驗證相依關係。

預設一個候選；只有新證據提供明確、不同的構造理由才增加，單輪最多三種方法。禁止用密度、半徑、剛度、阻尼、步數、容差、粗糙度或色素的批次掃描冒充製作方向；有參考、有預期差異的必要調整仍可做。方法一經證偽就停。驗證有錯時用獨立依據修正驗證，保留原因；不得改測試使候選假通過。

| 觸發條件 | 必須執行的動作 |
| --- | --- |
| 便宜試驗已證偽 | 停該方法，保存失敗位置、原因與回退點；更換構造或依據。 |
| 同一方法連續兩輪無實質收益 | 停用該方法；改名、版號或密度／半徑／剛度／阻尼／步數／容差掃描不算新方法。 |
| 同類支援診斷已連續兩輪 | 下一輪實際製作／整合，或改選能推進完整人物的缺陷；不能再以同類診斷延長。 |
| 不同試驗持續只重建來源、換資料精度或改局部參數 | 回到完整畫面的缺陷與參考，選擇直接改變結構、表面設計或完整操作的製作；不能靠研究名稱不同繞過停損。 |
| 三輪未解決完整主缺陷、未增加完整可用能力 | 停止現有拆題方式，指出共同失敗原因，據此重選主缺陷、依賴結構或製作依據；不得只改 nextAction。 |
| 僅有局部、代理或格式通過 | 按預定步驟整合到完整角色；未整合只算研究結果。 |

三輪回顧使用既有有效證據，不另開只寫回顧的製作輪次，不為湊圖重跑判退方案。所有實際製作試驗都計入窗口，不能把失敗輪改稱維護來歸零。局部收益、研究排除與完整人物進展分開記；誠實失敗不強迫採用，也不算品質收益。

工作身份始終分開：完整工作人物是目前編輯／展示來源，可含明示未驗收層；已驗證基礎記確切版本、雜湊及證據範圍；正式引擎資產按全部門檻提升。新增層只沿用前提仍相符的舊證據。未登記研究先核對，再決定用途，不能直接採用或因 manifest 過期重做。

## 3. 四項驗收

| 項目 | 通過依據 |
| --- | --- |
| 外觀 | 實際三維角色的完整頭部／全身固定鏡位、姿勢、光線及曝光 A/B，必要多角度和第二照明；寫出可見收益、退步與最大剩餘缺陷。 |
| 功能 | .blend 可獨立重開、資料有限、分層能編輯、拓撲／權重／骨架／控制有效，來源與匯出可重建；選取分組不是蒙皮。 |
| 接觸 | 實際顯示幾何在聲稱的姿勢／時間範圍無可見穿模，記版本、配對、厚度／半徑、方法、容差、距離定義及失敗位置；未測或無法證明者未驗收。 |
| 引擎 | Aevrynd 實際場景的載入、材質、骨架、動畫、毛髮、碰撞與 LOD；事前定硬體、解析度、預算，量單角色近景、遊戲距離及多角色 CPU／GPU 時間與記憶體。 |

只補測變更與採用聲稱影響的範圍，版本及前提相符的證據可沿用。必要檢查通過且無新風險即交付；不擴張無關檢查。技術通過不代表外觀可信，Blender 流暢或匯出成功不代表引擎通過。

採用檢查的深度隨聲稱而定：完整候選先證明畫面／操作值得保留，再補必要獨立驗證。已判退者只保留安全重開、依賴、授權及重現失敗所需的檢查；若某項來源資料值得保留，僅驗證其明示用途。不要為每個失敗候選重建全面驗證工具或重跑不相關的姿勢、引擎與效能測試。

接觸驗證必須保留以下邊界：

- 控制點不等於完整曲線／曲面／體積，導引不代表全部子髮，代理不代表顯示幾何；測試須符合實際插值、世界姿態及有限厚度並目視核對。控制多邊形弦長、求解粒子邊長、曲線弧長與材料伸長不得混稱。
- 人體、自碰撞、衣物分開；靜態、離散影格、連續時間分開。連續聲稱須有掃掠／連續檢查或具誤差界限的保守子步進，數值穩定不等於自然動態。
- 取樣最小值、保守下界、實際全域最短距離分開；凹面內外不能只用最近面法線。寬階段重疊不是已證實穿透，低於數值門檻的正間距也不是實體相交。
- 合法解剖接合／包含須有來源與結構依據，不能任意排除失敗髮根。髮根重建需依附、解剖及新接觸證據，不能移走失敗區來掩蓋。
- 髮片、透明區及個別髮絲的碰撞表示與限制要明說；髮片通過不推論全部髮絲物理成立。來源原有問題不能豁免本輪採用所需檢查。

先做聲稱範圍內最便宜的有效否證，再補足採用證據；不能以尚無全域證明為由永遠不製作。未驗收層可保留為研究，不能宣稱接觸已通過。

## 4. 完整品質與完成條件

- **頭臉與表情：** 成年頭骨、五官、耳頸肩多角度合理，有自然不對稱。眼部具角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線及睫毛；深度、折射、高光與接觸可信，近似要明示。口腔具上下牙齒、牙齦、舌頭及必要內壁，下頜／下牙控制正確。驗證眨眼、轉眼、張嘴、微笑、轉頭。
- **皮膚：** 有依據的區域色差、粗糙度、微法線、次表面反應及自然不對稱；固定曝光追蹤膚色，防止逐輪變黑、蠟像與面具感。
- **毛髮：** 完整髮際線、分線、鬢角、耳後、後腦與髮尾，有大形、中型束、細絲、少量飛散髮；拒絕帽殼、片簾、漏斗、切齊邊與鋼絲感。真實頭皮依附、分區剛度、重力、慣性、阻尼及接觸反應，驗證轉頭、急停、風力、回穩；明示彎曲、扭轉、摩擦及氣動的校準程度。
- **身體與衣服：** 裸體比例、手腳、關節及變形合理，不以衣髮遮掩解剖。衣物有厚度、接縫、摺痕與活動空間；中性、抬手、蹲下、走路、跑步、轉身無塌陷、扭縮及可見穿模。
- **明確分層：** 身體、眼部組件、口腔、上下牙齒、牙齦、舌頭、眉毛、睫毛、頭皮、頭髮、內外衣、配件、骨架、控制器、碰撞代理清楚命名，能獨立編輯／切換，記完成程度、綁定與運行表示。
- **引擎：** 網格、UV、貼圖、材質、骨架、morph、動畫、毛髮、碰撞、LOD 及匯入實作成為 Aevrynd 的一部分，從 Blender 權威來源可重建；真實場景畫面及效能達預定預算。

先看實際畫面並列缺陷，再給附版本、證據、扣分原因及信心範圍的審核估計。40 代表明顯人偶／嚴重缺陷，60 人工感強，80 多角度可信但仍不足，90 近景與動態可靠；這不是客觀真人相似度。缺項標未驗收，不計完整總分；功能通過不提高外觀分數，無新增證據不改分。

權重：解剖 15%、臉部 15%、眼睛 10%、皮膚 10%、毛髮 15%、服裝與分層 10%、骨架與動態 10%、碰撞 10%、引擎效能 5%。

**女性完成必須同時滿足：** 加權至少 85/100、每項至少 80/100、完整分層與指定動作齊全、靜態及動態無可見穿模、引擎品質／效能通過、來源可獨立開啟及重建、使用者明確認可。硬性失敗不能用平均分抵銷；此前不宣告整體完成、不開始男性。

可見改善且受影響檢查通過，或必要功能實際可用且外觀未退步，才納入已證明的工作範圍；有用但未整合／證據不足／授權待核實者列研究，寫用途及最小整合動作；無收益、被證偽、結構失敗或明顯退步者判退，保留原因與回退點。
