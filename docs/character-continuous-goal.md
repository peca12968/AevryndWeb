更新：2026-10-20，依使用者「重新設計持續目標提示詞」。v19 用短主提示詞統一完整人物交付，補上工作來源與已驗證基礎的區分、診斷轉製作的停止條件。取代 v18 工作流程，保留完整品質門檻、持續女性目標及女性認可後才開始男性的要求。

## 主提示詞

用本機 Blender 持續完成一位可在 Aevrynd 自研引擎離線運行的寫實成年女性。交付同一位完整人物，包含可信的頭臉、皮膚、完整髮型、身體、明確分層、骨架、表情、服裝、自然毛髮動態、碰撞、LOD 及可重建的匯入實作。裸體、穿衣、多角度及指定動作都要成立；女性全部門檻通過且使用者明確認可後，才開始男性。

先完成使用者最新要求。製作續跑先讀本文件、manifest 與最新證據，核對實際完整來源、未登記產物及現有 job，直接看完整頭部和全身。舊 nextAction 只供參考。提示詞維護不啟動模型輪次，也不算人物進步。

每輪列完整人物最嚴重的三個問題，只選一個主要交付：實質改善完整畫面中的主缺陷，或讓同一人物增加一項真正可操作的能力。寫清預期差異、第一手參考如何轉成 Blender 製作決策、最小整合終點及判退條件。優先解決比例、解剖、完整髮型與變形結構，再做微細節。

預設只做一個候選，先用便宜的構形預覽判斷方向，失敗立即停止；每輪最多三種真正不同的方法。有效成果回到同一完整工作人物。診斷只做到足以選擇下一個製作動作，已有答案就製作或整合，不擴張工具與報告來替代人物成果。

用相同鏡位、姿勢、光線與曝光交付實際三維人物的完整頭部／全身 A/B、必要角度與第二照明；動態改動交實際播放片段。外觀、功能、接觸、引擎分別驗收。有用的完整外觀研究可在明示未驗收範圍下保留，不能因此繼承碰撞、動態或引擎通過，也不能發布為正式人物。禁止改暗膚色、遮擋、換光、平滑或放寬門檻掩蓋失敗。

同一方法兩輪沒有實質收益就停止。每三個製作輪次和三輪前的完整人物比較：有沒有解決完整主缺陷或增加完整可用能力？沒有就改主缺陷、必要依賴或製作依據。局部小修、通過數、版號與提示詞更新不能重置停滯紀錄。

持續完成已授權且可回退的製作與整合，不反覆要求確認。用資源檢查點控制成本，時間到不等於完成。每次先讓使用者看到真實人物與能直接開啟的 .blend；全部品質門檻及女性認可成立之前，目標保持未完成。

### 工作來源與製作依賴

里程碑是交付條件，不是禁止交錯的瀑布流程。可提早建立骨架、做隔離引擎載入或驗證碰撞以解除必要依賴；須指出它使同一人物的哪個操作可用。不得要求整個引擎或所有動態先完成才准做外觀預覽，也不得以外觀好看豁免採用聲稱所需的檢查。

- **完整工作人物：** 目前實際製作及展示的完整 .blend，可含明示未驗收的研究層。記哪些外觀／功能已保留、哪些仍失敗；不能因一項未完成就丟失其他已證明的完整外觀收益。
- **已驗證基礎與回退來源：** 保存確切版本、雜湊和通過範圍。只沿用前提仍相符的證據；加入新髮型不能自動沿用它的接觸或動態驗收。
- **正式引擎資產：** 按完整品質門檻及使用者授權提升。研究層、輸出成功和局部通過不能冒充正式採用。

尚未登記的研究先核對來源、既有完整圖片和實際檢查，再決定工作用途。不能直接採用，也不能只看過期 manifest 就重做已完成試驗。來源欄位須分開記完整外觀工作來源與最後通過的技術基礎。

## 一、每輪工作契約

開工最多六行，且在本輪結束前不以支援工作偷換交付物：

1. 完整工作來源／雜湊、採用範圍、未登記產物與現有 job。
2. 完整畫面前三個缺陷、本輪主缺陷及選擇理由。
3. 可見改善或可操作功能，及必要依賴。
4. 製作參考與具體形體、拓撲、梳理、材質、綁定或動態決策。
5. 最便宜的判斷試驗、通過／判退條件、整合終點。
6. 資源上限、首次預覽與檢查點。

功能修復須指出解除哪個角色製作阻礙，整合到哪個完整來源、讓什麼操作實際可用；不自動提高外觀分數。研究用途、有效範圍、整合阻礙與最小整合動作要具體，不能只寫「供未來使用」。

支援診斷已有足夠依據選擇製作動作，就停止擴張診斷，先做該動作的完整整合預覽。不要追加一串檢查器、代理、格式或報告來延後製作。新證據若否定原方法，直接判退或換依賴，不能為完成工具而維持錯誤路線。

### 生產順序

- **先得到可信完整人物。** 先看頭骨與五官、身體比例、完整髮型大形、頭皮過渡和主要材質。局部能看不能代表完整能看。
- **讓該人物實際可用。** 將保留成果整合，補足分層、控制、變形、自然動態及接觸。完整可用能力須能在同一來源中重現。
- **在自研引擎驗證。** 及早進行可回退的隔離載入，發現資料／材質／動畫不相容；採用與正式發布仍遵守全部門檻及授權。

以上可以交錯。碰撞、綁定等必要依賴不能省略，但每項支援工作必須指向當輪角色交付；不能因選了小範圍而刪除最終完整要求。

每三輪的完整回顧直接使用有效既有證據，與三輪開始前的同條件頭部／全身比較。它是製作決策的一部分，不另開一輪只寫報告，也不為湊圖重跑已判退方法。

## 三、四項驗收各自成立

| 驗收 | 必要證據 |
| --- | --- |
| 外觀 | 自己實際三維角色的完整頭部／全身同條件 A/B、多角度、第二照明；指出可見收益、退步與最大缺陷。生成圖、修圖、他人模型圖不得當本人成果。 |
| 功能 | .blend 可重開、資料有限、分層可編輯、拓撲／權重／骨架／控制實際有效，來源與匯出可重建。選取分組不能冒充骨架與蒙皮。 |
| 接觸 | 實際顯示幾何在聲稱的靜態與動態範圍無可見穿模，記版本、配對、姿勢／時間、厚度／半徑、方法、容差、距離定義與失敗位置；未測或無法證明者未驗收。 |
| 引擎 | 在 Aevrynd 真實場景驗證載入、材質、骨架、動畫、毛髮、碰撞與 LOD；事前寫硬體、解析度與預算，量近景、遊戲距離、多角色的 CPU／GPU 時間及記憶體。 |

技術通過不等於外觀可信，Blender 流暢或匯出成功不等於引擎通過。僅補測改動及採用聲稱影響的範圍；版本、前提相符的舊證據可沿用。必要檢查通過且無新風險就交付，有明確失敗就修復或判退，不無限擴大與採用無關的檢查。

### 接觸證據的邊界

- 控制點不代表完整線段／曲面／體積；代表導引不代表全部子髮；代理不代表實際顯示幾何。渲染半徑、厚度、世界姿態與插值必須和測試相符，並目視核對。
- 人體接觸、自碰撞、衣物接觸分開；靜態、離散影格與連續時間分開。只測幾個姿勢不能宣稱整段無穿模。
- 連續動作使用掃掠／連續檢查，或有誤差界限的保守子步進。數值穩定不等於動態自然，離散零穿透不等於連續通過。
- 區分取樣值、保守下界與實際最短距離，不能把取樣最小值稱為全域最小值；凹面內外不能只看最近面法線。
- 寬階段疑似重疊不等於已證實穿透；正間距但低於數值門檻也不能直接寫成實體相交。必要細查後如實判定，不放寬門檻。
- 合法解剖接合／包含須有來源與結構依據，不能任意排除失敗區。髮根重建須有解剖、依附與新接觸證據，不能移走失敗髮根來藏問題。
- 髮片、透明區域與個別髮絲的碰撞表示及限制須明說；髮片通過不能推論全部髮絲物理成立。

接觸是必要品質門檻，但先做本輪聲稱範圍最便宜的有效否證，再補足採用所需驗證。不要在明顯失敗的造型上無限計算，也不能以尚未完成全域證明作為永遠不製作下一步的理由。未驗收層可清楚標記後留在完整工作研究中；這不構成接觸採用或正式提升。

## 四、完整角色不能缺少的範圍

1. **頭臉與表情：** 成年頭骨、五官、耳頸肩多角度合理，有自然不對稱，避免平均臉、面具與蠟像感。眼部具角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線、睫毛，深度、折射、高光與接觸合理；光學近似須標明。口腔具上下牙齒、牙齦、舌頭、必要內壁，下頜／下牙跟隨正確控制。驗證眨眼、轉眼、張嘴、微笑、轉頭。
2. **皮膚：** 有依據的區域色差、粗糙度、微法線、次表面反應及自然不對稱。固定曝光追蹤膚色，避免逐輪變黑，衣髮不得遮掩解剖錯誤。
3. **完整髮型：** 髮際線、分線、鬢角、耳後、後腦、髮尾連續，具有大形、中型髮束、細絲及少量飛散髮。先證明完整輪廓與頭皮過渡，再加細節；拒絕帽殼、片簾、漏斗、切齊邊及鋼絲感。
4. **毛髮動態：** 真實頭皮依附、分區剛度、重力、慣性、阻尼及接觸反應。驗證轉頭、急停、風力、回穩；明示彎曲、扭轉、摩擦、氣動的實作與校準程度，不能把穩定髮束當自然完整髮型。
5. **身體與服裝：** 裸體比例、手腳、關節、變形表面合理；內外衣物有厚度、接縫、摺痕及運動空間。驗證中性、抬手、蹲下、走路、跑步、轉身，無塌陷、扭縮與可見穿模。
6. **明確分層：** 身體、眼部組件、口腔、上下牙齒、牙齦、舌頭、眉毛、睫毛、頭皮、頭髮、內外衣物、配件、骨架、控制器、碰撞代理具清楚名稱，能獨立編輯／切換，記完成程度、綁定及運行表示。
7. **引擎資產：** 網格、UV、貼圖、材質、骨架、morph、動畫、毛髮、碰撞、LOD 與匯入實作成為 Aevrynd 的一部分，從 Blender 權威來源可重建；真實引擎畫面與效能達到事前預算。
