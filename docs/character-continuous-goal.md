# Aevrynd 仿真人物持續目標 v24

更新：2026-10-20。取代 v23 的執行方式。先完成使用者當前要求；提示詞維護不啟動模型輪次。

## 主提示詞

持續用本機 Blender 完成**同一位可信、可編輯、可動的寫實成年女性**，把網格、骨架、表情、材質、貼圖、毛髮、服裝、碰撞、LOD 與可重建的匯入流程整合進 Aevrynd 自研引擎。裸體與穿衣、多角度與不同照明、靜止與指定動作均要成立，無可見穿模。全部品質門通過且使用者明確認可女性後，才開始男性。

每輪從實際完整人物選一個最值得解決的缺陷，依可靠參考做具體雕塑、拓撲、梳理、材質或控制修改。先做便宜但足以判斷的完整頭部／全身預覽，再決定是否補驗收證據。有效部分接回同一完整人物；失敗方法停止，改變製作依據或構造。目標追求人物品質與完整可用能力，診斷、技術指標、版本、文件及提交不能代替它。

## 1. 接手與選題

1. **當前要求優先。** 要求修改提示詞、查路徑或解釋問題時，先完成該要求，不順帶開新模型試驗。
2. **核實來源再動手。** 讀本文件、資產 manifest、其指向的最新有效證據與 continuation；核實完整工作來源／雜湊、未登記成果、live job 和既有程序。不因登記落後重做成果，不把最新試驗自動當最佳或正式來源。
3. **先看完整人物。** 看實際完整頭部、全身和暴露缺陷的角度，列前三個主要問題，選一個本輪成果；nextAction 僅供核實。條件相符的既有畫面可重用。孤立部件指標不能決定完整人物是否改善。
4. **整合有效研究。** 已有可見收益的研究，優先評估接回完整工作檔的最小動作；不要無限開獨立研究。未通過接觸／動態的完整研究可保留，但明示未驗收，不能列為正式資產或已通過能力。

開工說明最多六行：來源與 job；主要缺陷；預期可見或可操作的改變；參考對應的 Blender 操作；最便宜判退及整合終點；預覽與資源上限。不要為開工另寫研究報告。

## 2. 製作、判退與停滯

**選缺陷 → 實際製作 → 完整預覽與便宜判退 → 有效才補檢查及整合 → 保存並交付。**

- **以製作解決形體。** 依真人解剖及專業角色的正面、側面、斜角、完整髮型和表面反應，記作者、來源、用途。先做大形、結構與髮束，再做微細節。必要時重雕、重拓撲、重梳可編輯導引或更換限制品質的部件，不以細絲、遮蓋層及反覆配準代替。來源／照明不同只能定性比較，還原原作不保證適合目前人物。
- **預設一個候選。** 新證據支持實質不同構造才增加，單輪最多三種方法。密度、半徑、色素、粗糙度、剛度、阻尼、步數和容差掃描不算不同方法，也不是必跑流程。
- **先判退再付驗收成本。** 優先完整頭部／全身、缺陷角度低成本預覽與最可能揭露失敗的有效檢查。已被否證就停止該方法，不補無關角度、全面物理、引擎效能或完整驗收包。驗證器有錯以獨立依據修正並記原因，不能為候選改標準。受影響檢查通過且無新疑點即可交付，不無限擴測。
- **診斷導向動作。** 只回答阻擋下一製作動作的問題，答案足夠就結束。初步支援診斷限 10 分鐘；到點交代製作依據或具體否證，不延伸成無限搜尋／工具開發。不可見依賴及支援診斷最多連續兩個製作輪次，之後以可回退層或不同依賴方案回到完整人物。
- **停用無效方法。** 同一方法連續兩輪無實質收益即停用；只有新證據指出原失敗前提已改變才可重試。每三個實際製作輪次比較窗口前後完整人物；主要缺陷未解決且無新增完整可用能力，必須改變製作方法。臉與毛髮仍像人偶時，三輪至少兩輪直接製作主要可見缺陷。失敗及未封存試驗照計；局部證明、來源修復、研究、診斷、封存和提示詞修改不重設計數。回顧併入製作，不另開報告輪。

每輪明答：**完整女人的哪個主要缺陷改善了，或哪項完整操作現在真的可用？** 若都沒有，寫「本輪未改善完整人物」，保留必要失敗證據，提出下一個實質不同動作；不以 progress 標籤或局部數字淡化結果。

## 3. 四道品質門與採用

同一人物逐步取得可信完整外觀、可操作且能回中性的角色、Aevrynd 實際場景可用性。可交錯推進；物理未完成仍須改善外觀，外觀變好也不豁免穿模。

| 品質門 | 所需證據 |
| --- | --- |
| 外觀 | 真實完整頭部／全身，同鏡位、姿勢、光線、曝光 A/B；方向成立後補必要角度與第二照明。列可見收益、退步、最大剩餘缺陷；像素不同不等於更真。 |
| 功能 | .blend 獨立重開、資料有限；分層、拓撲、UV、權重、骨架、表情和編輯成立，操作可重現並回中性；來源可重建匯出。改動動態須實際播放片段，選取分組不等於蒙皮。 |
| 接觸 | 聲稱範圍內的實際顯示幾何、有限厚度、姿態／時間檢查及人工多角度檢視；記版本、配對、方法、距離定義、容差與失敗位置。未測或證據不足即未驗收。 |
| 引擎 | Aevrynd 場景載入、材質、骨架、動畫、毛髮、碰撞、LOD；事前定硬體、解析度和預算，量單角色近景、遊戲距離、多角色 CPU／GPU 時間及記憶體。 |

外觀改善且受影響檢查成立，或完整操作可用且外觀未退步，才增加已證明工作範圍。技術通過不提升外觀分數；Blender 流暢或成功匯出不代表引擎通過。完整工作檔、限定用途基礎、回退、未驗收研究、正式 runtime 分開，部分通過不提升正式資產，也不替其他未驗收層取得資格。

接觸判斷須守住：

- 核實實際曲線／曲面／體積、插值、世界姿態與厚度；導引、控制點、代理、髮片及透明區不能代替全部顯示髮絲。作者假設與實際渲染表示未核實一致，不宣稱渲染幾何已精確通過或被精確否證。
- 人體接觸、自碰撞、衣物分開；靜態、離散影格、連續時間分開。連續聲稱須掃掠／連續檢查或有誤差界限的保守子步進。固定髮根、剛體跟隨和穩定不等於自然動態。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距低於門檻不等於相交，凹面內外不能只看最近面法線。弦長、粒子邊長、弧長和材料伸長不混稱。
- 解剖接合／包含須有結構及來源依據，不能排除失敗髮根、刪除問題髮絲、縮薄、移走或遮住失敗區來通過。改根部重驗依附、解剖、接觸；來源既有問題不豁免。沿用證據先核實版本與前提。
- 先做便宜有效否證，不要求每次藝術製作前完成全域證明；缺全域證明也不能宣稱全部通過。禁止放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋缺陷。

## 4. 完整人物驗收

- **頭臉／皮膚：** 成年解剖、五官、耳頸肩及自然不對稱多角度合理。角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線、睫毛，以及上下牙齒、牙齦、舌頭、必要口腔內壁與下頜控制齊備，近似表示明示。皮膚區域色差、粗糙度、微法線、次表面反應有依據；固定曝光追蹤膚色，拒絕變黑、蠟像、面具及過度平滑。
- **毛髮：** 髮際線、分線、鬢角、耳後、後腦、髮尾連續；大形、中束、細絲和少量飛散髮可讀，無帽殼、片簾、漏斗、切齊及鋼絲感。真實頭皮依附，合理分區剛度、重力、慣性、阻尼及接觸；驗證轉頭、急停、風力、回穩，明示彎曲、扭轉、摩擦及氣動校準範圍。
- **身體／服裝：** 裸體比例、手腳、關節、變形可信，不靠衣髮遮解剖。服裝有厚度、接縫、摺痕及活動空間。裸體、單層、多層均檢查；中性、走路、跑步、蹲下、轉身、抬手、眨眼、轉眼、張嘴、微笑無塌陷、糖紙扭縮或可見穿模。
- **分層／引擎：** 身體、眼部組件、口腔、上下牙齒、牙齦、舌頭、眉睫、頭皮、頭髮、內外衣、配件、骨架、控制器、碰撞代理明確命名，可獨立編輯／切換，記完成度、綁定及運行表示。網格、UV、貼圖、材質、骨架、morph、動畫、毛髮、碰撞、LOD 與匯入程式可由 Blender 權威來源重建，實際引擎品質／效能達預算。

評分先列可見缺陷，再附版本、證據、扣分理由和信心範圍。40 為明顯人偶／嚴重缺陷，60 人工感強，80 多角度可信但不足，90 近景與動態可靠；這是審核估計，不是客觀真人相似度。無新證據不升分，不把舊版分數套新版；缺項標未驗收，不計完整總分。

權重：解剖 15%、臉部 15%、眼睛 10%、皮膚 10%、毛髮 15%、服裝與分層 10%、骨架與動態 10%、碰撞 10%、引擎效能 5%。**完成須全部同時成立：加權至少 85、每項至少 80；完整層與指定動作齊全；靜態／動態無可見穿模；引擎品質／效能通過；來源獨立開啟並可重建；使用者明確認可女性。** 硬性失敗不被平均分抵銷，之前不標 complete、不開始男性。

## 6. 交付與持續生效

交付依序：完整人物的實際收益或明確未改善；真實頭部／全身 A/B、必要缺陷角度及變更動態；可開啟 .blend 絕對路徑；外觀／功能／接觸／引擎各自結果和缺口；採用或判退範圍；下一個具體製作動作；核實 GitHub 狀態。沒有新完整候選就明說，不把重複基線、生成參考圖或他人作品當新成果。

continuation 只記接手所需：來源／雜湊、未登記成果、有效證據、已通過範圍、主要缺陷是否解決、整合缺口、停用方法及原因、live job、資源、下一建議。完整人物進展、局部收益、診斷分開；保留真實三輪窗口與停滯計數。

**提示詞維護只更新本文件與接手入口。** 不開模型輪次，不改模型、manifest、分數、採用、女性認可、計數或既有失敗結論；待封存工作最小接手即可，不擴大成新診斷。本文件與歷史庫 `docs/character-continuous-goal.md` 逐位元組一致，兩處 AGENTS.md 指向 v24。

目標保持 active。目前工具能讀 objective、更新狀態，沒有原地改寫 active objective 的介面；本次更新的是專案執行提示詞，不宣稱工具內舊 objective 已替換，不清除／重建目標、不新增排程。舊 objective 的強制多候選及逐候選全面檢查依本文修正，女性目標與品質標準保留。使用者最新要求及更高優先規則優先。只有使用者明確要求才暫停；真正阻塞按目標工具規則處理，交代證據及必要輸入，不因困難自行停目標。
