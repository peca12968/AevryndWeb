## 2. 每次接續：看真實人物，選一個能交付的修正

先讀本文、`engine/assets/characters/female-next/female-next.asset.json`、最新有效 evidence／continuation 及 `Info/CharacterGoalPrompt-v29-update.json` 的 pendingWorkHandoff。核對必要的來源／雜湊、未登記成果、live job、停用方法、真實三輪窗口與停滯計數即可；不重掃歷史、不重建已有成果。交接提案及 nextAction 都須對照實物，不能當成已實作、已採用或重試失敗方法的許可。

先看實際完整頭部、全身及缺陷角度。最多列三項缺陷，選對可信度影響最大的**一個連貫問題**；可跨頭骨、五官、頭皮、髮型、蒙皮與接觸。依解剖／藝術參考選直接 Blender 動作：重雕、重拓撲、完整髮型重梳、部件重建或控制修正。說明參考中的結構如何落到本人物；搜尋、下載、引用正常人物圖片不算已做出 3D 人物。

製作前用一句話鎖定藝術目標，指明參考中的輪廓、比例或髮束走向，以及本人物正面／側面／背面應改變的可見結構。先建立能在實際畫面中判斷的完整形體；程序只負責重現、綁定及必要驗證，不能把由少數公式產生的大量曲線稱為已完成藝術製作。相容的藝術家資產也須先看原作實際空間形體，再決定接入方式。

始終分清：**完整工作人物、不可變回退／未驗收參考、正式 runtime**。在同一完整人物接回收益；保護無關的身體、眼口、表情與控制。新版不自動更好，也不因換髮型而丟掉有效部件。被重建部件可以改座標、拓撲及控制，必要時更換限制品質的基底，不得無限疊遮蓋層。

開工說明最多六行，隨後直接製作：來源與保留範圍；圖中主缺陷；參考及 Blender 動作；一個候選的可見判退條件；支援／首次完整預覽／資源檢查截止；既有 job 與資源上限。重試停用方法必須先指出新證據改變的失敗前提。

## 3. 製作循環：一個候選，先看完整預覽

**完整基線 → 直接修正 → 同條件完整頭部／全身 A/B → 保留或判退 → 必要的受影響驗證 → 接回同一人物並交付。**

- 預設一個候選，單輪最多三種實質不同構造，無須做滿。色素、粗糙度、密度、半徑、權重、步數、剛度、阻尼、容差掃描不是新方法。校準須有單位、尺度及依據，人口均值不是本人物真值。
- 初步搜尋、診斷與支援最多 **10 分鐘**；首次實際完整預覽通常在開工後 **30 分鐘內**。先訂具體截止；確有必要更久，事先說明最低必要工作與新截止。到點還在支援就停止擴充工具，改用能製作、可回退的構造。逾時記原因、實際耗時及現有產物，不事後改期限。觀察原 job，不重複啟動；期限不是丟棄成果或暫停目標的理由。
- 先修大形、解剖、分區及髮束，再補毛孔、細絲與著色。A/B 必須是實際完整人物，同鏡位、姿勢、光線及曝光，另顯示主缺陷角度。稀疏導引、代理、灰模、實心髮殼、生成圖與他人作品須明示用途，不能冒充完成髮型或本人物成果。
- 第一預覽若大形／結構失敗，立即判退該方向，停止加密、完整動畫與廣泛稽核；只留重現、安全重開、授權及回退必要資料。方向成立才補相關角度、第二照明與受影響操作／接觸。便宜檢查已發現的碰撞／功能失敗必須記錄，不等美化後才承認。
- 動態先用靜態及短片判退，再擴展轉頭／急停／風力／回穩；讓**實際顯示毛髮**變形。穩定求解、導引運動或剛體跟隨不能代替完整髮型自然飄動。接觸修正也要同時看外觀，不能只改善數字。
- 重用可用匯入、曲線、渲染及讀回流程；只修阻塞當前交付的工具錯誤。API、求解器、驗證器、序列化及封存不得取代製作。必要檢查通過且無新疑點就交付，不反覆查未改部分。

接觸／物理的證據不可越界：

- 核實表示、插值、世界姿態及厚度。控制點、導引、代理、髮片透明區不能代替全部顯示髮絲；未證明作者假設與渲染表示一致，不宣稱渲染占據精確通過或精確否證。

- 取樣最小值、保守下界、全域最短距離分開。包絡重疊不等於穿透，正間距不足不等於相交；凹面內外不能只憑最近面法線。弦長、粒子邊長、弧長及材料伸長不混稱。
- 解剖接合／包含有結構與來源依據；禁止刪失敗髮絲、排除髮根、縮薄、移走或遮住問題來通過。藝術／解剖依據支持的重建或尺寸校準可做，但原接觸結論不再直接適用；改根部須重驗依附、解剖及接觸，不能以尺寸改小宣告通過。來源既有問題不豁免，沿用證據先核對版本與前提。
