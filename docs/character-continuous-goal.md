## 可直接使用的持續目標提示詞

使用本機 Blender，持續製作可整合進 Aevrynd 自研引擎的仿真成年女性人物。交付可以直接打開、編輯、重建與運行的三維資產及引擎實作。先完成女性，取得使用者明確認可後，才開始男性。Blender 是製作工具；最終運行不得依賴 MetaHuman、Unreal、付費服務或其他平台。第三方資產須有相容授權與來源紀錄，不宣稱第三方作品為自製。

先讓完整頭部在正面、側面、斜角和動態中像真人，再擴展到全身、服裝及引擎。以真人參考和現代人物製作流程為依據，依序處理比例與輪廓、可變形結構、材質與微細節。頭髮必須具有自然分線、髮束、髮際線及髮尾，並能合理飄動。裸體、衣物和各組件須明確分層；靜態與動態都禁止可見穿模。

每輪先打開或渲染目前保留的完整工作模型，閱讀最新證據，選出最影響觀感或阻礙必要動作的一個缺陷。寫下原因假設、預期畫面或動作差異、最小試驗、判退條件及資源上限。通常只做一個候選；最多三個，且每個須有不同依據。先用低成本試驗否證可行性，再展開製作。允許重建拓撲、形體、UV、毛髮或控制架構，不受舊腳本限制。

把外觀、功能、碰撞與引擎結果分開判斷。外觀改善必須在同鏡位、同燈光、同曝光、同姿勢的實際三維 A/B 圖可辨識，且其他角度沒有不可接受的退步。功能修復可以保留，但不能因此提高外觀分數。局部測試通過不等於完整角色通過。每個製作輪次都要回到完整頭部或全身展示；動態修改另附實際模型產生的可播放片段。局部放大與報告只作補充。

方法被證偽就停止。同一方法連續兩輪沒有實質改善，必須換根本方案；不得換版本號繼續調參。支援診斷必須在下一輪轉成有依據的修復，或轉向能改善完整人物的獨立工作，不能連續第三輪只做同類診斷。小試驗失敗，不擴大成更多髮絲、影格或副機任務。不得靠調暗、遮擋、增密、過度平滑、放寬碰撞門檻或生成圖片冒充模型進步。

自主完成已授權的製作、研究、隔離引擎驗證與指定 GitHub 歷史保存。每輪用繁體中文簡潔交代實際改善、證據、未通過項目，附完整人物對照、必要動態片段、可直接開啟的 .blend 路徑與推送狀態。完整驗收通過後展示給使用者，等待女性認可；不得自行宣布女性完成，也不得提前開始男性。

## 3. 一輪只解決一個主要問題

每輪開始用一份短契約鎖定：

1. 完整工作來源及雜湊、里程碑、目前主要缺陷。
2. 參考依據、原因假設、預期可見或可操作差異。
3. 最小試驗、採用／判退條件，以及不同於已失敗方法之處。
4. 會受影響的幾何、綁定、動作與驗證範圍。
5. 候選數、時間、曲線／網格／影格規模及計算上限。
6. 本輪如何回到完整人物；支援研究要解除哪個具體阻礙。

依序執行：低成本否證 → 一個候選 → 受影響驗證 → 完整畫面審查 → 明確決策。

預設一輪以 45 分鐘作檢查點，支援診斷先設 10 分鐘上限；這是單輪資源檢查點，不是整個目標的完成期限。到點保存現況、檢視可見產出，停止無效分支。已有明確進展的必要長工作，可記錄原因與新上限後續作，不反覆盲目延長。不因尚未完成就宣稱通過，也不僅為到點而停止整個持續目標。

候選決策：

| 結果 | 處置 |
| --- | --- |
| 可見改善，受影響的檢查通過 | 採用於已證明範圍，更新完整工作來源並列出仍未驗收項目。 |
| 必要功能改善，外觀沒有退步 | 可保留功能修復；不提高外觀分數，不擴大碰撞或運行聲明。 |
| 有價值但證據不足 | 研究保留，列明缺口，不取代完整工作來源。 |
| 無可辨識改善、結構失敗或明顯退步 | 判退，保留失敗證據，停止相同無效做法。 |

沿用有效證據前，確認資產雜湊、幾何、材質、姿勢和算法前提仍成立。改到依賴範圍才重測；不能為省事沿用已失效結果，也不能因規則冗長而每輪重跑所有測試。

同一方法連續兩輪無改善須換架構；證偽立即停，不必等滿兩輪。最多連續兩輪支援診斷，第三輪必須回到新的完整部位成果，或以已有可行性證據實作新方案。不得用細分版本、提高迭代、增密、放寬容差或任意排除失敗區域繞過停損。

## 5. 人物品質與明確分層

- 解剖：成年人頭骨、五官、耳頸肩、全身比例、手腳與關節在多角度合理。自然不對稱須有參考，先大形後細節；衣髮不能遮掩解剖缺陷。
- 眼部：分離角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線與睫毛；深度、遮擋、高光、折射與眼皮接觸合理。光學近似如實標明。
- 口腔：牙齒、牙齦、舌頭及必要內壁具有真實深度與分層；上下牙隨合理控制運動，不能把所有口腔組件靜態掛在頭上冒充下頜動作。
- 皮膚：區域色差、粗糙度、微法線與次表面反應有依據。固定曝光核對膚色，防止逐輪變黑；不得靠磨皮、噪點或過強高光冒充細節。
- 毛髮：先輪廓、分線與少量可控導引，再做大形、中型髮束、細絲與少量飛散髮。髮際線、鬢角、耳後、後腦及髮尾連續自然，避免帽殼、實心塊、整齊切邊與鋼絲感。
- 毛髮動態：真實頭皮綁定、分區剛度、重力、慣性、阻尼與接觸反應；驗證轉頭、急停、風力和回穩。彎曲、扭轉、摩擦、氣動及校準是否實作須明示；數值穩定不等於自然。
- 衣物：內外層獨立可編輯，具有厚度、接縫、合理摺痕、材質與運動空間。
- 骨架：比例、關節軸與蒙皮合理；眨眼、張嘴、微笑、轉頭、抬手、蹲下、走跑與轉身成立，避免扭縮、塌陷及衣髮穿模。

明確命名並可分別編輯／切換：身體、眼部組件、口腔、上下牙齒、牙齦、舌頭、眉毛、睫毛、頭皮、頭髮、內外衣物、配件、骨架、控制器及碰撞代理。每層是否完成、綁定到哪裡、採用哪種運行表示都須可查。

## 6. 碰撞與動態證據

禁止可見穿模。檢查眼皮／眼球、牙齒／唇、舌頭／牙齒／口腔、頭髮／人體／衣物、衣物／人體／其他衣層及適用的自碰撞。合法解剖接合、包含與排除須有結構依據，不能為了過關任意略過失敗區域。

每份報告標示幾何版本、配對、數量、半徑或厚度、姿勢／時間、算法、容差、失敗位置，以及穿透與距離的量測定義。無法確定就是未驗收，不能填零。

以下證據不可混用：

- 控制點／頂點取樣不等於完整線段、曲面或體積。
- 代表導引不等於全部導引；導引通過不等於插值子髮通過。
- 代理通過不等於實體通過，除非已證明其涵蓋範圍，包括根部過渡。
- 靜態或離散影格不等於連續動作。轉場需掃掠／連續檢查，或有誤差界限的保守子步進。
- 靜止人體不等於移動人體；人體接觸通過不等於毛髮自碰撞或其他組件通過。
- 取樣距離、保守下界與完整最短距離分開標示。凹面內外不能只靠最近面法線符號。

自動結果須與展示模型、厚度及動畫插值一致，並經多角度與動態目視檢查。只修測試數字、放寬門檻、把髮根移離頭皮或遮住相交處都不算解決。
