## 目標與進步的定義

用本機 Blender 完成**同一位完整成年女性**：近景、多角度、裸體、衣著與動作均可信，頭髮自然飄動，分層可編輯，規定範圍無可見穿模；網格、UV、貼圖、材質、骨架、表情、動畫、毛髮、服裝、碰撞、LOD、匯入程式與可獨立開啟的 .blend 都能在 Aevrynd 自研引擎離線重建及運行。不得依賴 MetaHuman、Unreal、訂閱或持續收費的執行服務，不另裝大型軟體；保留第三方權利與義務，不冒稱獨占自有。女性經使用者明確認可後才開始男性。

**每輪以完整人物的可見淨改善或新增完整可用操作交代進度。** 外觀要能從實際頭／身 A/B 指出「哪個人偶感減輕、整體如何更像真人、哪裡仍差」。像素改變、精密位移、資料連通、基底保留、版本、診斷、報告和 Git 推送本身都不算外觀收益。可用操作必須在同一完整女人實際完成並回中性，不能只證明控制值送達。

- **有原 job：** 沿原 handle 核對程序、完成標記與產物；逾時不授權重啟。沒有活程序但已有產物時先核對產物，不重建。

## 每輪製作：一個主缺陷，一個完整結果

1. **看圖選缺陷。** 從實際完整頭／身與缺陷角度找至多三個主要問題，選最損害真人感的一個。開工最多六行：工作來源／受保護收益、主缺陷、可核實參考、直接 Blender 動作、可見判退條件、完整預覽具體截止與資源。說清預期可見變化，不能只說改善資料結構。
2. **直接改構造。** 優先大形、解剖、五官關係、髮型及完整操作，再做微細節。參考藝術家資產須先看原作三維形體、變形及權利，分清觀察和假設。保留有希望的整體，重建阻塞的表面、拓撲、髮束、依附、有限厚度接觸或控制，再接回同一女人。可改座標、拓撲及控制，不為保住舊數值而保留壞構造。參考／生成圖、灰模、髮殼、導引或獨立元件不能冒充完整成果。
3. **限制試法與支援。** 預設一個候選，每輪最多三種構造不同的方法，無須做滿，禁止參數掃描。換名稱、公式、來源標籤、加密、半徑、權重、粗糙度、阻尼、容差或平滑變體不自動構成新方法。初始研究／診斷／支援合計最多10分鐘，首次完整預覽通常在原開工後30分鐘內；到點停止擴工具，轉直接可回退製作。延長須到期前報已有產物、原因與新截止，保留原期限及逾時。退出碼0不能代替完成標記與產物；純啟動修復不算新人物輪次。
4. **先看完整外觀再決定投入。** 實際完整頭／全身以同鏡位、光、曝光、姿勢 A/B，附缺陷角度；受影響動作含中間、終態及回中性。先判主缺陷、整體真人感與受保護部位。若看不出淨收益、變形或退步，停止該方向的精修、參數變體與廣泛稽核，只保留最低重現、重開、權利及回退。方向成立才補相關角度、第二照明與受影響驗證；不以全域證明尚缺延後看圖，不以外觀較好豁免已知相關失敗。
5. **證明操作，接回並交付。** 獨立重開 .blend，操作實際顯示的求值後幾何並回中性，確認編輯確實改變成品；屬性、is_bound、骨架或資料存在不算操作通過。毛髮須看實際髮型轉頭、急停、風力、回穩，剛體跟隨不算自然飄動。只驗證本輪主張及其影響；未改區域核對版本／前提後引用既有證據。收益必須留在同一完整女人，不能停在無法接回的研究件。

## 去留與停滯：按實際收益決定下一步

外觀、功能、接觸、引擎分別下結論，缺證／失敗不算通過。完整 A/B 有可辨識淨收益、受保護外觀無退步，才可採用**明確範圍的外觀改善**；同步明示受影響功能／接觸的結論、缺口及已知退步。靜態採用不等於完整操作、正式 runtime 或使用者認可，也不必等無關門的全域證明。新增完整可用操作須在同一女人實際完成、復原，相關範圍無已知失敗／退步；功能收益不重設外觀停滯。

無可辨識完整外觀淨收益則判退或保留研究，寫清局部用途、失敗前提、待接回處與停用範圍；不請使用者批准明知失敗的結果。已有證據推翻原因就撤回推斷。

接觸結論必須與證據同範圍：

- 靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進；固定根部、數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱；封閉邊不證明無自交。
- 解剖接合／包含須有結構依據。禁刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過。有藝術／解剖依據的重建與尺度校準可以做，但原受影響結論失效，改根部重驗依附、解剖與接觸。來源問題不豁免，舊證據須核對版本與前提。

## 交付與最小交接

先說整位女人實際改善什麼，沒有就明說。附實際頭／身 A/B、必要缺陷角度／動態、可獨立重開 .blend 的絕對路徑、四門證據與缺口、採用／保留範圍、下一個 Blender 動作、核實 GitHub 狀態、原始時間及實際資源成本。舊圖標基線，沒有新完整候選就不拿舊圖充成果。

continuation 只留必要來源／雜湊、有效證據、未登記產物、採用範圍、主缺陷、待接回操作、停用方法、原 job、資源、原始時間與真實計數；完整歷史留原位，不反覆複製。不清除失敗或把研究／提案寫成採用。
