## 任務與進步的定義

交付可信的完整人體、臉、皮膚、頭髮、裸體與服裝，分層可編輯、動作可用、接觸合理。Blender 是權威來源；網格、骨架、表情、動畫、材質、貼圖、毛髮、碰撞、LOD 與可重建匯入流程最終成為 Aevrynd 資產及程式。不依賴 MetaHuman、Unreal、訂閱或持續收費執行服務，不另裝大型軟體。第三方內容保留作者、授權和修改紀錄，不冒稱獨占自有。女性經使用者明確認可才開始男性。

人物進步只由同一完整女人的可見品質與實際可用性成立。先解剖、比例、五官、髮型輪廓及接合，再做微細節；保護已採用形體、膚色與操作，只重建阻塞部位。研究、程式、導引、控制器、資料數量、匯出、報告及推送分別記為支援，不能代替人物變真。

外觀、功能、接觸、引擎四門獨立。限定靜態外觀採用須有完整同條件頭／身的可見淨收益，且受保護外觀不退步；列明未驗收功能及接觸。新增操作須在同一完整女人完成中間態、終態和復原，相關範圍無已知失敗。沒有採用外觀或新增完整可用操作，明寫「本輪未改善完整人物」；只有功能收益，明寫「本輪沒有採用外觀改善」。缺證即未驗收，不因局部或一門通過推廣到整體。

## 製作循環：先改人物，再深入驗證

開工卡最多六行，寫清：來源與保護收益；完整頭／身最多三個問題及唯一主缺陷；已查看參考、權利和三維構造；直接 Blender 動作與改變的失敗前提；可見判退；原始開工、具體預覽截止及資源上限。接續同輪沿用原卡及時鐘，不能重開一輪掩蓋逾時。

1. **把參考變成空間構造。** 實際查看相關多角度真人／可靠藝術來源，指出需改的輪廓、體積、表面、內壁、接合及依附。未看過的圖不聲稱已核對；權利未知只作參考，採用已核實來源或原創。頭髮先建立當前頭皮上的分線、髮際線、根到梢導引、前側後束層級與連續流向；核實原生依賴及角色，名稱、連通片或端點不證明毛囊、完整髮束或父子延續。
2. **直接改實際人物。** 原生雕塑、曲線雕梳、網格編輯與程式均可，工具服從造型。預設一個完整候選，最多三種構造不同的方法，不必做滿、不掃參數。原開工起研究／診斷／工具支援合計最多10分鐘；一次最小真實操作確認能力後就製作。支援須服務本輪缺陷，不以反覆查來源、API、求解器或增加點數／細絲取代造型。
3. **通常原開工30分鐘內給完整預覽並自己看圖。** 同基線鏡位、光、曝光及姿勢，輸出完整頭／身 A/B 與缺陷角度；操作改動加中間態、終態和回中性。退出碼0、孤立零件、導引、灰模、代理、髮殼、生成圖及他人作品都不能代替完整候選。延期須在原期限前記已有產物、理由及新截止，保留原期限與逾時；修復不是新人物輪次。
4. **完整結果決定下一步。** 主缺陷沒有可辨識淨改善，或完整真人感／受保護外觀退步，就停止此方向精修、變體及廣泛稽核，保留最低重現、獨立重開、權利與回退。不要用顏色、密度、半徑、曝光、遮蓋或縮小動作救構造失敗，也不請使用者替判已知失敗。方向成立才補第二照明及相關操作／接觸；不要求每輪先證全域，漂亮局部也不能抵銷完整失敗。
5. **驗證主張、交付結果、保存歷史。** 獨立重開 .blend，操作真正控制與求值後顯示幾何，完成並復原。導引、屬性、is_bound 或單點編輯只證元件能力；頭髮須看實際髮型轉頭、急停、風力及回穩，根部跟隨不等於自然飄動。只驗本輪主張和受影響範圍，重用證據先核對版本／前提；保留失敗反證，區分表示／量測問題和真實幾何失敗，不改門檻求過關。先交實際頭／身／動作、可獨立開啟來源與短決策，再做最低紀錄及精確封存；不重複複製有效證據，封存不能吃掉後續製作。
