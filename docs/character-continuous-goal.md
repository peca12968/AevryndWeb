## 每輪的工作順序

**完整基線 → 一個直接 Blender 修正 → 相同條件完整頭部／全身 A/B → 看外觀決定保留或判退 → 驗證受影響部分並接回人物 → 交付與保存。**

- 預設一個候選，單輪至多三種真正不同的構造，不必做滿。密度、半徑、色素、粗糙度、權重、步數、剛度、阻尼與容差掃描不算新方法。程式可輔助製作，公式曲線不能代替造形與梳髮。
- 初步搜尋、診斷與支援最多 **10 分鐘**；第一實際完整預覽通常在開工後 **30 分鐘內**，先訂具體截止。必要延長須到期前說明工作與新截止。到點仍在支援就停止擴充工具，改用直接且可回退的製作構造；不能換輪次洗掉成本。
- 診斷須能改變下一個製作動作。分清「看見的現象」「尚待區分的原因」「否證結果」；一次做能區分主要原因的最小測試。不能從灰模正常、UV 範圍有限或改屬性成功直接猜定病因。因果診斷可暫時替換材質，但診斷圖另列，不能當完成外觀。
- 重用 Blender 及現有工具。完整預覽前不擴成泛用 API、求解器、驗證器或封存框架。小型材質／資料診斷先在未存檔副本做，保留可重現腳本與結果；確認有必要保留的候選才另存完整 `.blend`，避免每次診斷都新增大型相同場景。
- A/B 固定鏡位、曝光、燈光與姿勢，交實際完整頭部、全身及主缺陷角度，也對照受保護的較好歷史特徵。白模、局部、導引、代理、髮殼、生成圖與他人作品不能代替完整候選。
- 第一完整預覽若大形或構造失敗，立即停止該方向的加密、全面動畫及廣泛稽核，只保留重現、安全重開、授權與回退必需資料。已有便宜的失敗證據照實記。方向成立才補相關角度、第二照明與受影響驗證；嚴格品質不能成為延後預覽的理由。
- 涉及操作，先讓**實際顯示的人物幾何**完成一個最小完整動作並回中性，再擴大。控制器／骨架／導引存在不代表已連接；輸入送達控制器仍須檢查求值後表面。頭髮需看實際顯示髮型的轉頭、急停、風力與回穩，不能只看根點或剛體跟隨。

## 同一人物的保留、採用與判退

保留有希望的完整形體，修掉阻塞其表面、依附、接觸或操作的構造；必要時可改拓撲、座標與控制並重新綁定。不要為保舊資料犧牲形體，也不要每輪重建另一個不相連人物。既有有用頭身、眼口、表情、髮型與控制應接回同一工作人物。

工作人物、不可變回退／未驗收研究、正式 runtime 分開。當前工作人物只能指向一個清楚來源；其他來源列為參考及待接回項目。保留好形體可以繼續製作，不等於完整人物已採用，靜態好形體也不等於可用角色。

每輪分開記錄：**可見收益與退步、實際接回範圍、已證明範圍、未驗收範圍**。

| 決策 | 必要證據 |
| --- | --- |
| 採用完整人物外觀改善 | 實際完整 A/B 可辨識改善，採用範圍明確，受影響門有結果；關鍵失敗或缺證仍在不得聲稱。正式 runtime 另須驗收。 |
| 新增完整可用操作 | 完整人物可重現操作與回中性且無退步。局部移點、切換、還原、像素差或存檔成功不能代替；功能不能代替外觀。 |

- 同一方法兩個無效輪次立即停用。重試須有新證據改變失敗前提，先便宜否證。改名、加導引／分區／步數、換殼或重包求解器不足。歷史停用立即生效。
- 三個實際製作輪次沒有採用完整外觀收益，下一輪必須改變與主缺陷相關的基底／構造並交完整預覽。形體差就重建形體；形體好而依附／操作阻塞就重建阻塞構造。下載、換來源名稱、提案或資料修復本身不算採用收益。
- 臉／毛髮仍不可信時，任意三個實際製作輪次至少兩輪直接製作主要可見缺陷；不可見支援最多連續兩輪，下一輪回到可見製作。每三個實際輪次檢視整位女人，併入當輪交付。失敗與未登記實作照算，快照／提案不算完成試驗；未知計數不捏造。
- 外觀、功能、接觸、引擎分開決策。提示詞、診斷、研究、功能與 Git 保存都不重設外觀停滯。無採用外觀收益寫「本輪沒有採用外觀改善」；也無新增完整可用操作時，必須寫 **「本輪未改善完整人物」**，再列局部收益。progress 分類不能代替這個結論。

接觸結論必須與證據同範圍：

- 核實表示、插值、世界姿態和厚度；變形配對使用各自求值後的幾何。頂點離開表面不代表整個面片離開。控制點、導引、代理、髮片透明區不代表全部顯示髮絲；未證作者假設與渲染一致，不稱渲染占據精確通過／否證。
- 靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進；固定根部、數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱；封閉邊不證明無自交。
- 解剖接合／包含須有結構依據。禁刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過。有藝術／解剖依據的重建與尺度校準可以做，但原受影響結論失效，改根部重驗依附、解剖與接觸。來源問題不豁免，舊證據須核對版本與前提。
- 先便宜否證，不要求每輪先證全域；缺證不能說全通過。禁放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋失敗；診斷材質／光另列。

評分權重：解剖15%、臉部15%、眼睛10%、皮膚10%、毛髮15%、服裝與分層10%、骨架與動態10%、碰撞10%、引擎效能5%。先列缺陷，附確切版本、圖像／動作／量測、扣分理由與信心範圍。40＝明顯人偶／嚴重缺陷，60＝人工感強，80＝多角度可信但不足，90＝近景及動態可靠；屬審核估計。無新證據不升分，舊分不套新版；缺項未驗收，不算完整總分，自評不替代使用者認可。

## 交付與接續

依序交付：**完整人物收益或明確未改善 → 實際頭部／全身 A/B、缺陷角度與必要動態 → 可獨立打開的 `.blend` 絕對路徑 → 四門結果與缺口 → 保留／採用範圍 → 下一個具體 Blender 動作 → 核實 GitHub 狀態、實際耗時及成本。** 沒新完整候選就明說，不能拿舊圖或他人作品充成果，也不要求使用者批准判退成果來解除停滯。

continuation 只留下一輪確實需要的來源／雜湊、證據、未登記成果、採用範圍、缺陷、待接回操作、停用方法、live job、資源、真實三輪窗口／停滯計數與下一動作。沿用有效診斷；新證據改變原因時撤回舊推斷，不能把推斷滾成歷史事實。保留完整來源與證據在原位置，不把所有歷史角色欄位複製進新交接。

真正缺資訊時，交代已嘗試路徑、證據、具體所缺及可繼續部分；blocked 依工具規則，不因困難、逾時或一輪判退自行停止。已授權離線製作、可回退開發整合與指定歷史保存自主完成，不反覆詢問同一授權。
