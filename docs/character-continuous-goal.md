## 1. 每次續跑的決策順序

1. **當前要求**：先回答或完成使用者最新要求，不讓舊續跑計畫蓋過它。
2. **真實工作狀態**：讀本文件、資產 manifest、latestContinuation 與本輪必要證據；核對未登記產物及實際執行中的工作，避免丟失成果或重複開工。
3. **完整觀感**：看目前完整工作模型的實際畫面，列最多三個主要缺陷，選一個。最新編號、最容易改的參數或最容易通過的測試，都不是選題理由。
4. **方法與小試驗**：查相關既有失敗及可用資產，定義足以支持下一步的最小試驗；不要每輪重讀全部歷史。
5. **製作、受影響驗證、完整審查與整合**：採用範圍必須與證據一致，最後回到可觀看的完整人物。

外觀工作不必等所有動態難題解完。必要功能修復可以獨立進行，但須說明它解除哪個近期製作阻礙；不能無限擠掉外觀主線。可提早做可回退的隔離引擎試驗，及早發現不相容，不必等全部美術完成才首次匯入。

## 2. 一輪製作契約與停損

開工記錄保持精簡，至少包括：

- 完整工作來源與雜湊、主要問題、參考依據。
- 預期在完整頭部／全身看見的差異；功能輪則寫可操作差異。
- 最小試驗、通過／判退條件、與既有失敗方法的根本差異。
- 受影響的幾何、材質、控制、接觸或運行範圍。
- 候選數、時間與資源上限；局部如何回到完整人物。

預設一次一個候選，最多三個有不同依據的候選。45 分鐘為單輪資源檢查點，支援診斷先設 10 分鐘上限。到點保存現況，檢查實際可見產出；已有明確進展的必要長工作可記錄原因與新上限後繼續。這不是整個持續目標的完成期限，不得為到點假稱完成或停止整個目標。

| 結果 | 決策 |
| --- | --- |
| 完整畫面可辨識改善，受影響檢查通過 | 採用於已證明範圍，整合並更新完整工作來源。 |
| 必要功能修復，外觀未退步 | 保留功能修復；外觀分數不自動上升。 |
| 小幅局部改善，完整觀感仍不足 | 只記局部收益與剩餘問題，不宣稱整個部位或人物達標；適用連續微小改善的方向審查。 |
| 有用但未整合或證據不足 | 研究保留，寫明整合目標、相容性缺口與下一個行動。 |
| 無可辨識收益、結構失敗或明顯退步 | 判退，保存必要失敗證據，停止該無效做法。 |

停損以方法而非檔名計數；換版本號、提高密度、迭代數或容差不算新方案。證偽不必等滿兩輪。連續兩輪無實質改善，或只累積微小局部變化而整體仍無改善，下一輪須重新選擇主要缺陷或改用有依據的根本方案。最多兩輪同類支援診斷，不能用第三輪報告代替製作。

已可用的局部若因拓撲、座標、材質或綁定分散，優先解除整合阻礙，避免再次製作同一孤立部件。合併會破壞已驗證成果時先做小試驗；不能盲目合併，也不能長期只保存孤立研究。

階段可交錯。未完成的動態、全身或效能標未驗收，不能填假數據、從最後門檻刪除，或以局部研究宣稱完成整個階段。

製作順序以大形和結構優先：

- **人體與臉部**：成年人的頭骨、五官、耳頸肩、全身比例、手腳及關節多角度合理；自然不對稱有參考，衣髮不能遮掩解剖缺陷。
- **眼部**：角膜、鞏膜、虹膜、瞳孔、眼皮內壁、淚阜、濕潤線、睫毛分明；深度、折射、高光、遮擋和眼皮接觸合理，光學近似如實標示。
- **口腔**：牙齒、牙齦、舌頭及必要內壁有深度，合理分層與運動；下頜和下牙跟隨正確控制，不能用全口靜態掛頭冒充張嘴。
- **皮膚**：區域色差、粗糙度、微法線與次表面反應有依據。固定曝光追蹤膚色，防止逐輪變黑；磨皮、噪點或強高光不能冒充真實細節。
- **毛髮**：輪廓、分線、髮際線、鬢角、耳後、後腦與髮尾自然連續；建立大形、中型髮束、細絲及少量飛散髮，避免帽殼、片狀簾幕、實心塊、整齊切邊與鋼絲感。先用少量導引證明造型與根部過渡，再擴大。
- **毛髮動態**：真實頭皮綁定、分區剛度、重力、慣性、阻尼與接觸反應，驗證轉頭、急停、風力與回穩。彎曲、扭轉、摩擦、氣動與校準的實作程度須明示；數值穩定不等於動作自然。
- **服裝與骨架**：內外衣物有厚度、接縫、摺痕及運動空間。關節軸、蒙皮與臉部控制合理，指定動作無扭縮、塌陷或衣髮穿模。

可獨立編輯／切換並明確命名：身體、眼部組件、口腔、上下牙齒、牙齦、舌頭、眉毛、睫毛、頭皮、頭髮、內外衣物、配件、骨架、控制器與碰撞代理。記錄每層的完成程度、綁定與運行表示；選取分組不冒充蒙皮、控制器或動畫。

## 4. 外觀、功能、接觸與引擎四項獨立驗收

**外觀**：先看相同條件的完整頭部／全身 A/B，再看局部近照；檢查正、側、斜及必要背面，另有其他角度或第二種照明。保留原始渲染與條件。照明實驗獨立標示，不能換光線後宣稱形體改善。動態修改交付模型實際生成的可播放片段。

**功能**：檔案能重開、分層能編輯、控制作用正確、資料有限且拓撲與綁定有效；聲明限於實際測試。功能通過不代替外觀改善。

**接觸**：禁止可見穿模；檢查眼皮／眼球、牙齒／唇、舌頭／牙齒／口腔、毛髮／人體／衣物、衣物／人體／其他衣層及適用自碰撞。合法解剖接合、包含或排除須有結構依據，不得任意略過失敗區域。

報告記錄確切幾何版本、配對、數量、半徑／厚度、姿勢／時間、算法、容差、失敗位置與距離定義。未測或不確定標未驗收，不能填零。以下證據不可互換：

- 控制點／頂點取樣不等於完整線段、曲面或體積。
- 代表導引不等於所有導引；導引不等於全部插值子髮。
- 代理不等於實體，除非證明涵蓋範圍，包括根部過渡。
- 靜態或離散影格不等於連續動作；須有掃掠／連續檢查或具誤差界限的保守子步進。
- 人體接觸不等於自碰撞、衣物或其他組件接觸。
- 取樣距離、保守下界與完整最短距離須分開；凹面內外不能只靠最近面法線符號。

渲染實際半徑、厚度、幾何與動畫插值須與測試一致，並經多角度／動態目視檢查。不能把髮根移離頭皮、隱藏交叉、放寬容差或只修測試數字過關。

**引擎**：輸出與載入可重建，網格、骨骼、morph、材質、貼圖、毛髮與碰撞規模可查。先訂硬體、解析度、場景及預算，實測近景、遊戲距離、多角色的 CPU／GPU 時間、記憶體和 LOD。Blender 流暢、離線原型或匯出成功不能代替 Aevrynd 運行證據。

舊證據僅在雜湊、幾何、材質、姿勢與算法前提仍相符時沿用。只重測受影響範圍及依賴；沒有新原因不重跑全部測試，也不沿用已失效結果。
