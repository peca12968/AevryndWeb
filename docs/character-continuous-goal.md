## 接續：用現有證據進入下一個製作動作

先讀本檔、asset manifest、最新有效 audit／continuation 與 v35 pending handoff。核對工作人物、實際完整頭／身圖、未登記產物、停用方法及 live job 即可，不重掃全部歷史。已有候選先看候選，已有診斷直接用，已有 job 沿原 handle 觀察；觀察逾時不等於 job 失敗。未完成輪次沿用原開始時間、期限與失敗紀錄，插話、壓縮、維護或執行錯誤不洗掉成本。

開工最多六行：完整來源與受保護成果、主要缺陷、實際參考、直接 Blender 動作、可見判退條件、首次完整預覽的具體截止與資源。不要以長方案或建工具代替製作。

## 製作閉環：看完整人物 → 修一個主缺陷 → 完整預覽 → 判斷 → 補必要證據

1. **選題。** 從實際完整頭、全身與缺陷角度列至多三個問題，選一個主缺陷。查閱可核實的解剖／藝術參考；採用藝術家資料先查看原作三維表面、實際變形與權利。控制器、閉合代理、生成圖或他人作品不能充當本人物成果。分清觀察、假設與否證。
2. **直接製作。** 預設一個候選，單輪至多三種構造上不同的方法，不必做滿。可用程式輔助 Blender；密度、半徑、權重、步數、粗糙度、阻尼、容差、平滑或改名的掃描不算新方法。用最小診斷決定製作動作，不能擴成泛用 API、求解器或驗證框架來拖延看人物。
3. **限時看到整體。** 初始研究／診斷／支援最多 **10 分鐘**，首次完整預覽通常開工後 **30 分鐘內**；先訂具體截止。必要延長須到期前交代原因、已有產物與新截止，原始期限仍保留；逾時照記。支援到點就停止擴工具，轉直接、可回退製作。求解器警告／無解／缺變數／缺完成標記均非成功，退出碼 0 也不充分；保存失敗，修必要錯誤後接續原工作。
4. **先看圖。** 固定鏡位、光、曝光、姿勢，輸出實際完整頭部／全身 A/B 與主缺陷角度。變形改動加實際中間態、終態與回中性。局部補片、白模、髮殼、導引、元件 .blend 都不是完整預覽；沒完整候選就明說，舊圖只作標明的基線。
5. **先判構造成敗。** 完整預覽形體或接合失敗，立即停止該方向的加密、全面動作及廣泛稽核，只保留最低重現、重開、權利與回退證據。方向成立才補相關角度、第二照明與受影響的功能／接觸／引擎檢查。缺證仍未驗收；也不得要求每輪先證全域安全才准預覽。
6. **接回同一人物。** 保護有希望的頭身、嘴唇、髮型及控制。阻塞在表面、拓撲、依附或操作，就重建阻塞構造並重綁；保留原來源與回退。新構造須有實際可接合邊界與可用操作，數值對應或代理移動不能代替它。功能要在實際顯示、求值後的幾何完成操作並回中性；屬性、骨架、is_bound 或輸入送達不等於表面運作。頭髮需看實際髮型轉頭、急停、風力及回穩，剛體跟隨不算自然飄動。

## 決策與停止無效重試

每輪只作有證據的結論，維持一個明確工作人物；參考、回退、未驗收研究與正式 runtime 分開。

| 結論 | 依據與後續 |
| --- | --- |
| 採用完整外觀改善 | 完整 A/B 可辨識收益，受影響門有證據，退步與缺證明示；接回工作人物。正式 runtime 另驗收。 |
| 新增完整可用操作 | 同一完整人物能重現操作及回中性，無相關退步；局部移點、資料存在、切換或存檔不足。功能不能代替外觀。 |
| 保留局部研究 | 記價值、缺口與待接回位置；不算完整採用，不重設停滯。 |
| 判退 | 記實際失敗、停用前提與回退；不以更多版本或報告稱進步。 |

- 同方法兩個無效輪次立即停用；重試須有新證據改變失敗前提，先便宜否證。三個實際輪次無採用完整外觀收益，下一輪必須改變與主缺陷相關的基底／構造；形體差修形體，形體好而操作阻塞則重建阻塞構造。歷史立即計入，不從新提示詞歸零。
- 臉／毛髮仍不可信，任意三個實際製作輪次至少兩輪直接製作主要可見缺陷，不可見支援不得連續超過兩輪。每三輪檢視整位女人，失敗／未登記實作試驗照算；純啟動錯誤、提案、元件快照不是已完成模型輪次，嘗試與成本仍記，不捏造未知計數。
- 無採用外觀收益寫「本輪沒有採用外觀改善」；也無新增完整可用操作，必須寫 **「本輪未改善完整人物」**，再列局部收益。外觀、功能、接觸、引擎分開；研究、診斷、方向保留、提示詞維護、資料修復、保存或推送不重設外觀停滯。

接觸結論必須與證據同範圍：

- 核實表示、插值、世界姿態和厚度；變形配對使用各自求值後的幾何。頂點離開表面不代表整個面片離開。控制點、導引、代理、髮片透明區不代表全部顯示髮絲；未證作者假設與渲染一致，不稱渲染占據精確通過／否證。
- 靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進；固定根部、數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱；封閉邊不證明無自交。
- 解剖接合／包含須有結構依據。禁刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過。有藝術／解剖依據的重建與尺度校準可以做，但原受影響結論失效，改根部重驗依附、解剖與接觸。來源問題不豁免，舊證據須核對版本與前提。
- 先便宜否證，不要求每輪先證全域；缺證不能說全通過。禁放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋失敗；診斷材質／光另列。

評分權重：解剖15%、臉部15%、眼睛10%、皮膚10%、毛髮15%、服裝與分層10%、骨架與動態10%、碰撞10%、引擎效能5%。先列缺陷，附確切版本、圖像／動作／量測、扣分理由與信心範圍。40＝明顯人偶／嚴重缺陷，60＝人工感強，80＝多角度可信但不足，90＝近景及動態可靠；屬審核估計。無新證據不升分，舊分不套新版；缺項未驗收，不算完整總分，自評不替代使用者認可。

**完成須全部成立：上述內容齊全；聲稱的靜態／動態範圍無可見穿模；.blend 可獨立重開並重建匯出；實際引擎材質、控制、動畫、物理、LOD、效能通過；嚴格加權至少85/100且每項至少80/100；使用者明確認可女性。** 硬性失敗不能平均掉；此前目標保持 active，不標 complete，不開始男性。

## 交付、接續與維護

交付先說完整人物改善了什麼，否則明說未改善。附實際完整頭／身 A/B、必要缺陷角度與動態、可獨立重開 `.blend` 絕對路徑、四道門證據／缺口、採用或保留範圍、下一個 Blender 動作、核實的 GitHub 狀態與實際時間／資源成本。沒新完整候選不拿舊圖充成果，不請使用者批准明知判退的結果來解除停滯。

continuation 只留接續所需來源／雜湊、證據、未登記輸出、採用範圍、主缺陷、待接回操作、停用方法、live job、資源、原始時間與真實計數。完整歷史留原位，不反覆複製成巨大交接。已有有效診斷不重跑，新證據推翻原因即撤回舊推斷；待辦提案不是實作或採用。

真正缺資訊時列已試路徑、證據、缺口、仍可進行部分及解鎖條件。blocked 依工具規則，不因困難、逾時或一次失敗自行停止；已授權離線製作、可回退開發整合及歷史保存自主完成，不反覆詢問。

**提示詞維護只改本檔、兩處 AGENTS 入口、對應鏡像及最小維護／待辦紀錄。** 不啟動、完成或重算模型輪次，不改模型、manifest、評分、採用、女性認可、計數與歷史發現；pending／staged 生產資料保留，不與提示詞提交。本檔與 `sites-engine-journey/docs/character-continuous-goal.md` 逐位元組一致，兩處入口指向 v35 handoff。

目標保持 active；現有工具不能原地改寫 active objective，本次維護的是專案執行提示詞，不聲稱 stored objective 已替換，不清除／重建目標或新增排程。只有使用者明確要求才暫停；提示詞完成不是人物完成。
