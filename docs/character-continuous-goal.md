## 3. 保留收益、處理停滯，不讓驗收變成循環研究

每輪分別記錄**看到了什麼、接回了什麼、證明了什麼、仍欠什麼**。外觀方向可保留於完整工作人物接續修正，另明示接觸／動態／引擎未驗收；不能只因另一道門未完成，就丟掉有價值形體改找下一份素材。也不能把「看起來較好」冒充已採用的完整人物改善、通過接觸或正式發布。

決策只用以下範圍：①已採用的完整人物外觀收益；②可重現、可回中性且未退步的新增完整操作；③保留的外觀方向／資料／局部研究，仍未驗收；④判退。①需說明實際採用範圍、完整人物 A/B 與受影響門的結果；有關鍵缺陷或缺證就維持③。③④不重設外觀停滯；功能②也不能代替外觀①。分組、開關、精確還原、毫米差、像素差和版本增加不自動成為①②。

- 同一方法連續兩輪沒有實質收益即停用。重試須有新證據改變原失敗前提，並先做便宜否證；改名稱、增加步數／導引、重包裝求解器或換來源外殼不算改前提。
- **連續三個實際製作輪次沒有採用完整人物外觀改善，下一輪立即做有依據的基底／構造改變。** 從現有圖像與失敗證據指出限制；選重雕、重拓撲、完整髮型重建、解剖依附／接觸構造或相容授權部件替換，並交付實際完整預覽。缺的是依附、接觸或操作，就改阻塞它的構造，保護已有可用形體；缺的是大形，就直接重建大形。不得以另一份來源、另一篇文章或另一套工具代替構造改變。
- 臉／毛髮仍不可信時，任意連續三個實際製作輪次中至少兩輪直接製作主要可見缺陷。不可見支援最多連續兩輪，下一輪必須回到完整可見成果；將物理／資料研究稱作製作不能規避此條。
- 每三個實際製作輪次看完整人物，回顧併入當輪交付。失敗、未登記、未封存試驗都計入；提示詞、研究、功能、來源修復、診斷及 Git 保存不重設歷史。既有窗口立即有效，不再等三輪。未知計數不補造，也不能把只有開工快照的工作自動算成完成試驗。
- 無採用外觀改善寫「本輪沒有採用外觀改善」；也沒有新增完整可用操作時，明寫**「本輪未改善完整人物」**。可以另列有價值的研究／方向，但不能以 progress、技術通過、成功存檔淡化這個結論。新構造失敗也如實判退，下一步須由失敗證據決定。

接觸／物理聲稱須符合證據：

- 核實曲線／曲面／體積、插值、世界姿態及厚度；導引、控制點、代理、髮片透明區不能代替全部顯示髮絲。作者假設與實際渲染表示未核實一致，不宣稱渲染幾何精確通過或被精確否證。
- 人體接觸、自碰撞、衣物分開；靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進。固定根部、剛體跟隨和數值穩定不證明自然飄動。
- 區分取樣最小值、保守下界和全域最短距離。包絡重疊不等於穿透，正間距不足不等於相交；凹面內外不能只憑最近面法線。弦長、粒子邊長、弧長與材料伸長不混稱。
- 解剖接合／包含須有結構及來源依據；禁止刪失敗髮絲、排除髮根、縮薄、移走或遮住問題來通過。改根部重驗依附、解剖、接觸；獨立藝術／解剖依據支持的重建或尺寸校準可以做，但須承認原接觸結論不再適用，重驗受影響範圍，不能以尺寸改小本身宣告通過。來源既有問題不豁免，沿用證據先核對版本／前提。
- 藝術製作先做便宜有效否證，無須每次先證全域；缺證也不得宣稱全通過。禁止放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋缺陷。診斷光照／材質可另列，不能替代固定曝光的外觀比較。
