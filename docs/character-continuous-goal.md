## 持續目標與成果順序

持續用本機 Blender 製作**同一位完整、可信、可編輯、可動的寫實成年女性**，將網格、材質、貼圖、骨架、表情、動畫、毛髮、服裝、碰撞、LOD 與可重建匯入流程整合進 Aevrynd 自研引擎。裸體與穿衣、近景與全身、多角度與不同照明、靜止與指定動作都須成立，無可見穿模。女性通過全部品質門並經使用者明確認可後，才開始男性。

**優先交付看得出改善、逐步可用的完整人物。** 製作與整合優先於診斷、驗證器、研究命名、文件和封存。嚴格指審核誠實、缺陷不放水，不代表每個失敗版本都要跑完整測試。

依實際缺口推進以下成果，不為達成階段名稱重做已有能力：

1. **可信的完整外觀：** 頭臉形體、皮膚與完整髮型先消除主要人偶感；放在同一身體上審核，局部好看不算完整角色成立。
2. **可用的完整角色：** 補齊分層、解剖、衣物、蒙皮、表情、指定動作與接觸，保留已取得的外觀收益。
3. **Aevrynd 實際運行：** 可重建匯入、實際動畫與物理、品質級別和效能驗收，交付可開啟的引擎場景。

三者可交錯製作；早期可用可回退開發場景解除匯入風險，標明未驗收，不必等整個角色完成才接觸引擎。臉／毛髮仍明顯不可信時，三個製作輪次中至少兩輪直接改善其主要可見缺陷，不長期以局部功能代替外觀。

## 一、每輪以完整成果選方法

1. **接續真實狀態。** 讀本文、`engine/assets/characters/female-next/female-next.asset.json`、最新有效證據及 continuation，核對完整工作來源／雜湊、未登記輸出和 live job。最新版本不自動等於最佳版本；不因登記落後重做已有成果。看實際完整頭部、全身與缺陷角度，再決定下一步；nextAction 不是強制命令。
2. **選一項完整尺度的改善。** 列前三項主要可見缺陷，選最影響可信度且能製作的一項，寫出「現在的問題 → 預期畫面／操作 → 判退依據」。以完整髮型、頭臉共同結構等連貫成果為單位；允許同時修改為此必要的相關部件，**不強迫每輪只改一個參數、鼓包或獨立小層**。
3. **把參考變成 Blender 製作。** 必要時查可信真人解剖、專業角色流程或 Blender 社群實例，記來源、作者與用途，說明參考如何落到本人物。先大形與結構，再表面與微細節。允許重雕、重拓撲、重梳、重建生長分區或更換限制品質的部件；不可用無限遮蓋層補根本缺陷。重建保留來源與回退，不要求被重建的幾何、控制拓撲永遠逐點不變；保護的是無關部件、已有效能力與人物連續性。
4. **採用有效研究。** 有收益的部件接回同一完整工作人物並重開、重看，不能永久停在獨立研究。完整工作檔、限定用途基礎、回退、未驗收研究與正式 runtime 分開；局部通過不提升正式資產。

開工最多六行：來源／job、主要問題、預期成果、具體 Blender 動作、便宜判退／整合終點、預覽與資源上限。接續後直接製作，不另開計畫、診斷或報告輪。

## 二、先製作、便宜判退，再補驗收

**看完整人物 → 選連貫成果 → 製作一個候選 → 便宜預覽／否證 → 有收益才驗證與整合 → 交付。**

- **預設一個候選。** 只有新證據支持實質不同構造才增加，單輪最多三種方法，不必做滿。色素、粗糙度、密度、半徑、權重、剛度、阻尼、步數或容差掃描不算新方法。可信測量可支持一次明示單位、尺度與適用範圍的校準；不得拿人口均值冒充本人物真值，也不得宣稱尺寸符合就已逼真或無穿模。
- **便宜預覽先判方向。** 用看得清缺陷的實際完整頭部／全身與必要缺陷角度，同鏡位、姿勢、光線、曝光 A/B。方向不成立立即判退，保留最小失敗證據，不補全套角度、物理、效能或重複測試。方向成立才補相關角度、第二照明與受影響操作／接觸。
- **診斷有上限。** 初步支援最多 10 分鐘，到點交代依據與下一個實際製作動作；仍無法製作就改可回退部件或構造，不能無限搜尋或開發工具。首次可看預覽另訂時間上限，超時如實交代，不以腳本內局部計時冒充整輪耗時。不可見依賴／支援最多連續兩個製作輪次，下一輪回到主要可見缺陷。
- **收益有範圍。** 可見改善且受影響檢查成立才記外觀收益；完整操作可重現、回中性且外觀未退步才記該操作可用。分層、開關、來源面分離與精確還原只證明其用途，不證明新增解剖、自然動態、寫實度或完整角色能力。
- **檢查有終點。** 受影響檢查通過且無新疑點即可交付，不無限擴測。驗證器有錯，以獨立依據修正、記原因，不為候選放寬標準。

## 三、停滯必須真的換製作依據

同一方法連續兩個製作輪次沒有實質收益即停用；只有新證據改變原失敗前提才重試。換版號、名稱、參數、工具包裝或多加導引不自動算不同構造。

**連續三個實際製作輪次沒有採用完整人物的可見外觀改善，立即轉向基底／構造重建。** 在當輪看窗口前後完整人物，指出限制品質的來源部件或建模假設；下一個製作輪次必須選有具體新依據的重雕、重拓撲、髮型重建或相容授權部件替換，先做能顯示方向的完整人物預覽。不得再沿原失敗路徑微調，或先花一輪寫重設計報告。這項條件核對既有歷史，**提示詞更新不重新起算等待三輪**。

每三輪仍做完整人物回顧，併入當輪交付。失敗、未登記、未封存的實際試驗都計入；功能收益、局部數據、來源修復、研究、封存及提示詞維護不重設外觀停滯。保持真實既有計數，不補造失落歷史。轉向不是推倒整個人物：保留有效身體／口腔／控制，替換限制品質的構造，再回到同一完整角色審核。

無可見改善明寫「本輪沒有採用外觀改善」；也無新增完整可用操作時，明寫**「本輪未改善完整人物」**。不得用 progress 標籤、像素差異、局部毫米數、可切換或精確還原淡化結果。新構造仍失敗就誠實交代，不把技術可行當外觀成功。

## 四、四道品質門分開驗收

| 品質門 | 必須證明的範圍 |
| --- | --- |
| 外觀 | 實際完整頭部／全身，同鏡位、姿勢、光線、曝光 A/B；方向成立後補相關角度及第二照明。列收益、退步、最大剩餘缺陷；像素不同不等於更真。 |
| 功能 | .blend 獨立重開、資料有限；分層、拓撲、UV、權重、骨架、表情及編輯可用，操作可重現並回中性，來源可重建匯出。改動動態須實際片段；分組不等於蒙皮。 |
| 接觸 | 聲稱範圍內的實際顯示幾何、有限厚度、姿態／時間檢查及人工多角度檢視；列版本、配對、表示、距離定義、容差、失敗位置。未測或證據不足即未驗收。 |
| 引擎 | Aevrynd 場景實際載入材質、骨架、表情、動畫、毛髮、碰撞和 LOD。先定硬體、解析度、品質及預算，再量單角色近景、遊戲距離、多角色 CPU／GPU 時間與記憶體。 |

接觸／物理聲稱須符合證據：

- 核實曲線／曲面／體積、插值、世界姿態及厚度；導引、控制點、代理、髮片透明區不能代替全部顯示髮絲。作者假設與實際渲染表示未核實一致，不宣稱渲染幾何精確通過或被精確否證。
- 人體接觸、自碰撞、衣物分開；靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進。固定根部、剛體跟隨和數值穩定不證明自然飄動。
- 區分取樣最小值、保守下界和全域最短距離。包絡重疊不等於穿透，正間距不足不等於相交；凹面內外不能只憑最近面法線。弦長、粒子邊長、弧長與材料伸長不混稱。
- 解剖接合／包含須有結構及來源依據；禁止刪失敗髮絲、排除髮根、縮薄、移走或遮住問題來通過。改根部重驗依附、解剖、接觸；獨立藝術／解剖依據支持的重建或尺寸校準可以做，但須承認原接觸結論不再適用，重驗受影響範圍，不能以尺寸改小本身宣告通過。來源既有問題不豁免，沿用證據先核對版本／前提。
- 藝術製作先做便宜有效否證，無須每次先證全域；缺證也不得宣稱全通過。禁止放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋缺陷。診斷光照／材質可另列，不能替代固定曝光的外觀比較。

## 七、交付、接手與生效

製作交付依序：**完整人物採用的外觀收益或明確未改善 → 真實完整頭部／全身 A/B、必要缺陷角度及變更動態 → 可開啟 .blend 絕對路徑 → 外觀／功能／接觸／引擎結果與缺口 → 採用範圍 → 下一個具體 Blender 動作 → 已核實的 GitHub 狀態。** 無新完整候選就明說，不以重複基線、生成參考圖或他人作品冒充成果。女性最終認可由使用者決定；一般已授權離線改進自主完成，不要求逐輪批准。

continuation 只記接手必要的來源／雜湊、未登記成果、有效證據、已通過範圍、主要缺陷、整合缺口、停用方法、live job、資源及下一動作。外觀、完整功能、局部收益和診斷分開，保持真實三輪窗口與停滯計數，不為交接另做大型報告。

**提示詞維護只改本文與接手入口。** 不開製作輪次，不改模型、manifest、分數、採用、女性認可、計數或既有失敗結論；未封存工作只記最小接手，不擴成製作／診斷。本文與歷史庫 `docs/character-continuous-goal.md` 逐位元組一致，兩處 AGENTS.md 指向 v26。
