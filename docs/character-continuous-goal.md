## 成果與每次接續的第一件事

用本機 Blender 完成**同一位完整成年女性**：頭部近景與全身像真人，裸體與衣著合理，分層能編輯，表情與肢體可操作，頭髮自然飄動，規定動作無可見穿模。最後在 Aevrynd 自研引擎離線重建與運行。只有使用者明確認可女性，才開始男性。

網格、UV、材質、貼圖、骨架、表情、動畫、毛髮、衣物、碰撞、LOD 與可重建匯入流程留在專案。不依賴 MetaHuman、Unreal、訂閱或持續收費的執行服務，不另裝大型軟體；合法第三方資產保留原授權，不冒稱獨占持有。

接續先讀本檔、asset manifest、最新有效 audit／continuation，以及 `Info/CharacterGoalPrompt-v34-update.json` 的 `pendingWorkHandoff`。核對一個工作人物、實際完整頭／身預覽、未登記輸出、live job 與停用方法即可，不重掃全部歷史。已有 job 觀察原 handle；已有候選先看候選；已有診斷直接用。延續未完成輪次與原始時間，插話、失敗、壓縮、提示詞維護都不重置期限或計數。

開工最多六行交代：完整來源與受保護形體、最主要缺陷、實際參考、直接 Blender 動作、可見判退條件、首次完整預覽的具體截止與資源。不要把長方案或新工具當成開工。

## 製作閉環：先讓人物改變，再擴驗證

**看完整女人 → 選一個主要可見缺陷 → 直接製作 → 同條件完整頭／身 A/B 與受影響動作 → 看圖判斷 → 必要驗證與接回 → 保存交付。**

1. 從實際頭部、全身和缺陷角度列至多三個問題，選最損害可信度的一個。優先大形、解剖、五官關係、髮束與可操作性，再做毛孔細絲。保留較好歷史特徵，避免修眼皮卻退步嘴唇、頭身或髮型。
2. 引用可核實的解剖／藝術參考。採用藝術家資產先查看原作實際三維形體、變形和權利；控制器、閉合代理或生成圖不能充當實際閉眼表面或可採用模型。清楚區分觀察、原因假設、否證結果；不要把推斷沿用成歷史事實。
3. 預設一個候選，單輪最多三種結構上不同的方法，不必做滿。程式可輔助 Blender 製作；更多公式、曲線、密度、半徑、權重、步數、粗糙度、阻尼、容差或改名不算新構造。選擇失敗的前提要改哪個，不要自動重試同一族參數。
4. 初始研究／診斷／支援最多 **10 分鐘**；首次實際完整預覽通常開工後 **30 分鐘內**，先訂具體截止。必要延長須到期前說明原因、已做產物與新截止，原始期限仍保留。逾時如實記錄，不換輪次洗掉成本。到點仍在支援，停止擴工具，轉向直接、可回退的製作。
5. 一次最小診斷須能改變下一個製作動作。盡量用未存檔副本與現有腳本，不反覆另存大型相同場景。求解器警告、無解、缺變數或未出完成標記都屬失敗；程序退出碼 0、元件 .blend、控制點移動不能冒充有效完整候選。保留失敗，修必要執行錯誤後繼續原工作；不能為掩蓋失敗擴成泛用 API／求解器／驗證框架。
6. A/B 固定鏡位、燈光、曝光與姿勢，至少實際完整頭部、全身及主缺陷角度；變形改動加實際中間態、終態與回中性。完整是同一人物的可見集合，不是局部補片、白模、導引、髮殼、他人作品或生成圖。沒有完整候選就明說，先前圖像只作明示基線。
7. 第一預覽若形體或構造失敗，停止該方向的加密、全面動作及廣泛稽核；只做重現、安全重開、權利與回退所需最低保存。方向成立才補相關角度、第二照明及受影響驗證。不得讓先證全域安全成為延後看人物的理由，也不得將缺證稱為通過。
8. 功能先在**實際顯示、求值後的人物幾何**完成一個完整操作並回中性。骨架／屬性／導引存在、is_bound 或輸入送達不等於表面真的運作。頭髮要看顯示髮型的轉頭、急停、風力與回穩；根點不動或剛體跟隨不能證自然飄動。

## 保留、採用與停滯的處理

保留有希望的完整形體，修掉阻塞其表面、依附、接觸或操作的構造。可改拓撲、座標與控制，但要重綁並留回退；不要為舊資料犧牲形體，也不要每輪產生另一個不相連的人物。將有用的眼口、身體、髮型與控制接回**一個明確的工作人物**，其他來源分為參考、回退、未驗收研究及正式 runtime。

每輪只需清楚決定：

| 結論 | 必要依據 |
| --- | --- |
| 採用完整外觀改善 | 實際完整 A/B 有可辨識收益，採用範圍與受影響門有證據；關鍵失敗或缺證不得隱去。正式 runtime 另行驗收。 |
| 新增完整可用操作 | 同一完整人物可重現操作與回中性，無相關退步；局部移點、切換、存檔或像素差不足。功能不能代替外觀。 |
| 保留局部方向／研究 | 列明價值、缺口及待接回位置；不算完整採用，不重設停滯。 |
| 判退 | 寫實際失敗、停用前提與回退。失敗資料仍保留；不靠版本或報告數稱進步。 |

- 同一方法兩個無效輪次立即停用；重試必須有新證據改變其失敗前提，先便宜否證。歷史失敗立即生效，不從新版提示詞重新累計。三個實際輪次沒有採用完整外觀收益，下一輪必須改變與主缺陷相關的基底／構造：形體差就重建形體，形體好而操作阻塞就重建阻塞構造。
- 臉／毛髮仍不可信時，任意三個實際製作輪次至少兩輪直接製作主要可見缺陷；不可見支援不得超過連續兩輪。每三個實際輪次檢視整位女人，失敗／未登記的實作試驗照算。單純腳本啟動失敗、提案或快照不是已完成模型輪次，所有嘗試與成本照記，未知計數不捏造。
- 外觀、功能、接觸、引擎分開。沒有採用外觀收益寫「本輪沒有採用外觀改善」；也無新增完整可用操作時必須寫 **「本輪未改善完整人物」**，再列局部收益。progress、提示詞維護、研究、資料修復、保存或推送不能重設外觀停滯。

| 引擎 | Aevrynd 真實場景載入材質、控制、動畫、毛髮、碰撞及 LOD。先定硬體、解析度、品質與預算，再量單角色近景、遊戲距離及多角色 CPU／GPU 時間和記憶體；記檔案、幾何、骨骼、morph、材質、貼圖與毛髮規模。 |

接觸結論必須與證據同範圍：

- 核實表示、插值、世界姿態和厚度；變形配對使用各自求值後的幾何。頂點離開表面不代表整個面片離開。控制點、導引、代理、髮片透明區不代表全部顯示髮絲；未證作者假設與渲染一致，不稱渲染占據精確通過／否證。
- 靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進；固定根部、數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱；封閉邊不證明無自交。
- 解剖接合／包含須有結構依據。禁刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過。有藝術／解剖依據的重建與尺度校準可以做，但原受影響結論失效，改根部重驗依附、解剖與接觸。來源問題不豁免，舊證據須核對版本與前提。
- 先便宜否證，不要求每輪先證全域；缺證不能說全通過。禁放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋失敗；診斷材質／光另列。

評分權重：解剖15%、臉部15%、眼睛10%、皮膚10%、毛髮15%、服裝與分層10%、骨架與動態10%、碰撞10%、引擎效能5%。先列缺陷，附確切版本、圖像／動作／量測、扣分理由與信心範圍。40＝明顯人偶／嚴重缺陷，60＝人工感強，80＝多角度可信但不足，90＝近景及動態可靠；屬審核估計。無新證據不升分，舊分不套新版；缺項未驗收，不算完整總分，自評不替代使用者認可。

**完成須全部成立：上述內容齊全；聲稱的靜態／動態範圍無可見穿模；.blend 可獨立重開並重建匯出；實際引擎材質、控制、動畫、物理、LOD、效能通過；嚴格加權至少85/100且每項至少80/100；使用者明確認可女性。** 硬性失敗不能平均掉；此前目標保持 active，不標 complete，不開始男性。

## 交付與下一次接續

先說完整人物改善了什麼，或明說未改善；接著交實際頭／身 A/B、必要缺陷角度與動態、可獨立打開的 `.blend` 絕對路徑、外觀／功能／接觸／引擎各門證據與缺口、保留或採用範圍、下一個具體 Blender 動作、核實 GitHub 狀態及實際時間／資源成本。沒新完整候選不拿舊圖充成果，不請使用者批准明知判退的結果來解除停滯。

continuation 只留接續需要的來源／雜湊、證據、未登記產物、採用範圍、主要缺陷、待接回操作、停用方法、live job、資源、原始時間與真實計數。已有有效診斷不重跑；新證據推翻原因要撤回舊推斷。完整歷史與原始資料留原位，不反覆複製成巨大交接。

真正缺資訊時說明已試路徑、證據、具體缺口與仍可進行部分；blocked 依工具規則，不因困難、逾時或一次失敗自行停止。已授權離線製作、可回退開發整合及指定歷史保存自主完成，不反覆索取相同授權。
