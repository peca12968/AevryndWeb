# Aevrynd 仿真人物持續目標 v36

更新：2026-10-21。先完成使用者當前要求，再續人物製作。本檔是執行契約，取代 v35 與舊 stored objective 的製作流程；品質與完成要求保留。**一位完整女人、可見收益、可操作來源、真實證據**是主交付。

## 目標與證據的權威

用本機 Blender 持續做好同一位完整成年女性，讓臉、身體、裸體與衣著在近景、多角度及動作中可信；頭髮自然飄動，分層可編輯，規定動作無可見穿模，最後可在 Aevrynd 自研引擎離線重建與運行。網格、UV、貼圖、材質、骨架、表情、動畫、毛髮、衣物、碰撞、LOD 和匯入流程留在專案。不得依賴 MetaHuman、Unreal、訂閱或持續收費的執行服務，不另裝大型軟體；保留第三方權利與義務，不冒稱獨占自有。使用者明確認可女性後才開始男性。

永久規則只放本檔；目前人物、採用與計數看 asset manifest 及最新有效 audit／continuation；未完成工作看 `Info/CharacterGoalPrompt-v36-update.json` 的 `pendingWorkHandoff`。**較新的實際產物與證據優先於交接快照或提案**，不因檔名新就推翻原始證據。先核對矛盾，不自行改歷史。保留一個明確工作人物；正式來源、工作基底、研究與回退分開，換工作基底不等於外觀採用。

## 每次接續先做什麼

1. 讀本檔、manifest、最新有效 audit／continuation、pending handoff。只核對當前來源、必要頭／身圖、未登記產物、停用方法及 live job，不重掃全部歷史。
2. **已有候選先看實際完整預覽；已有診斷直接用；已有 job 沿原 handle 觀察。** 觀察逾時不等於失敗。插話、壓縮、提示詞維護、啟動錯誤不洗掉原開始時間、期限、失敗和成本，不重開同輪或覆寫舊候選。
3. 從實際頭部、全身及缺陷角度列至多三個主要問題，選一個最損害真人感、且能直接製作的缺陷。優先大形、解剖、五官關係、髮型與完整操作，之後才是微細節。
4. 開工說明最多六行：完整來源與受保護成果、主要缺陷、可核實的參考、直接 Blender 動作、可見判退條件、首次完整預覽的具體截止與資源。判準在製作前定義，不能看完結果才換目標。

## 一輪的製作與決策

**觀察 → 直接製作 → 完整預覽 → 判斷 → 必要驗證 → 接回同一人物。** 程式與診斷服務於這個閉環，不能代替人物製作。

- **參考與構造。** 查真實解剖／藝術參考；採用藝術家資料先看其原作三維表面、實際變形及權利。分清觀察、假設與否證。控制器、支撐體、生成圖或他人作品只作標明的參考。直接製作實際表面、髮束或操作；阻塞在拓撲、依附、有限接觸或控制，就重建該構造並重綁，保留有希望的完整形體、原來源與回退。座標、拓撲與控制可因必要重建改變，不能只為保住舊數值犧牲人物。
- **候選與方法。** 預設一個候選，單輪最多三種構造不同的方法，不必做滿。先查方法譜系與失敗前提；換名稱、參考、演算法包裝，或掃密度、半徑、權重、步數、粗糙度、阻尼、容差、平滑，都不自動成新方法。新構造須指出改變了哪個已知失敗前提，不能只有更多環列／資料／方程式。
- **限時製作。** 初始研究、診斷與支援最多10分鐘，首次完整預覽通常開工後30分鐘內，先訂具體截止。必要延長須到期前報原因、已有產物與新截止，原始期限保留，逾時照記。支援到點停止擴工具，轉直接可回退製作；不轉成泛用 API、求解器或驗證框架。無解、警告、缺變數、缺完成標記不算成功，退出碼0也不充分；只修必要執行錯誤，沿原工作接續。
- **先看完整結果。** 固定鏡位、光、曝光、姿勢，渲染工作人物與候選的完整頭部／全身 A/B 及主缺陷角度。涉及變形，增加實際中間態、終態與回中性。局部補片、白模、髮殼、導引或元件 .blend 不是完整預覽；沒有新完整候選就明說，舊圖標為基線。局部放大圖只補充整體。
- **先判可見成敗。** 逐項回答主缺陷有沒有減輕、完整人物是否更可信、受保護部位是否退步。完整預覽的形體或接合已失敗，停止該方向加密、參數變體、全面動作與廣泛稽核，只保留最低重現、重開、權利及回退證據。方向成立再補相關角度、第二照明及受影響門。不能以全域證明尚缺而無限推遲看圖，也不能以看起來較好豁免相關失敗。
- **接回與操作。** 保留下來的收益接回同一明確工作人物。功能須在實際顯示、求值後的幾何完成操作並回中性；屬性送達、is_bound、骨架或資料存在不等於表面可用。頭髮看實際髮型轉頭、急停、風力與回穩，剛體跟隨不算自然飄動。候選獨立重開後仍可重現，才作相應功能結論。

## 什麼算進步，何時換方法

四道門分開記錄，下方完整品質契約不變。每輪只作有證據的範圍結論：

| 決策 | 必要依據 | 對工作人物的影響 |
| --- | --- | --- |
| 採用完整外觀改善 | 完整 A/B 有可辨識淨收益；受影響功能／接觸有相關證據，退步及缺證明示 | 接回同一人物；不等於正式 runtime 或女性認可 |
| 新增完整可用操作 | 同一完整人物實際完成操作與回中性，相關範圍無已知失敗或退步 | 記功能收益；不能代替外觀改善 |
| 保留工作基底／局部研究 | 明列保留理由、可用範圍、缺口與待接回位置 | 便於後續建構；不算完整採用，不重設停滯 |
| 判退 | 實際失敗、失敗前提、停用範圍與回退清楚 | 不污染正式資產，不用更多版本或報告冒充進步 |

採用當輪完整外觀收益只要求其相關範圍有證據，不要求先完成所有尚未受影響的引擎或全域證明；但已知相關失敗、缺證不能算通過，正式完成門檻不得降低。確認未變的區域可引用核對版本／前提後的既有證據，不重跑無關廣泛稽核。無法辨識整體淨收益就保留研究，不硬採用。

- 同方法兩個無效實際輪次立即停用；重試須有新證據改變其失敗前提，先便宜否證。三個實際輪次無採用完整外觀收益，下一輪必須改變與主缺陷相關的基底／構造。形體差修形體；形體值得保留而接合／操作失敗，就重建阻塞部分，不必丟掉所有成果。歷史立即計入。
- 臉／毛髮仍不可信，任意三個實際輪次至少兩輪直接製作主要可見缺陷；不可見支援不得連續超過兩輪。每三輪檢視整位女人，失敗／未登記實作照算。純啟動錯誤、提案、元件快照不是已完成模型輪次，嘗試與成本仍保留；未知計數不捏造。
- 無採用外觀收益寫「本輪沒有採用外觀改善」；也無新增完整可用操作，必須寫「本輪未改善完整人物」，再列局部收益。研究、診斷、方向保留、資料修復、保存、推送、提示詞維護不重設外觀停滯。版本數、程式量、數值指標或封存量不能代替人物收益。

接觸結論必須與證據同範圍：

- 核實表示、插值、世界姿態和厚度；變形配對使用各自求值後的幾何。頂點離開表面不代表整個面片離開。控制點、導引、代理、髮片透明區不代表全部顯示髮絲；未證作者假設與渲染一致，不稱渲染占據精確通過／否證。
- 靜態、離散影格、連續時間分開。連續聲稱需掃掠／連續檢查或有誤差界限的保守子步進；固定根部、數值穩定不證明自然運動。
- 取樣最小值、保守下界、全域最短距離分開；包絡重疊不等於穿透，正間距不足不等於相交。凹面內外不能只看最近面法線；弦長、粒子邊長、弧長、材料伸長不能混稱；封閉邊不證明無自交。
- 解剖接合／包含須有結構依據。禁刪失敗髮絲、排除髮根、縮薄、移走或遮住問題求通過。有藝術／解剖依據的重建與尺度校準可以做，但原受影響結論失效，改根部重驗依附、解剖與接觸。來源問題不豁免，舊證據須核對版本與前提。
- 先便宜否證，不要求每輪先證全域；缺證不能說全通過。禁放寬容差、變暗膚色、換光、遮擋或縮小動作掩蓋失敗；診斷材質／光另列。

評分權重：解剖15%、臉部15%、眼睛10%、皮膚10%、毛髮15%、服裝與分層10%、骨架與動態10%、碰撞10%、引擎效能5%。先列缺陷，附確切版本、圖像／動作／量測、扣分理由與信心範圍。40＝明顯人偶／嚴重缺陷，60＝人工感強，80＝多角度可信但不足，90＝近景及動態可靠；屬審核估計。無新證據不升分，舊分不套新版；缺項未驗收，不算完整總分，自評不替代使用者認可。

**完成須全部成立：上述內容齊全；聲稱的靜態／動態範圍無可見穿模；.blend 可獨立重開並重建匯出；實際引擎材質、控制、動畫、物理、LOD、效能通過；嚴格加權至少85/100且每項至少80/100；使用者明確認可女性。** 硬性失敗不能平均掉；此前目標保持 active，不標 complete，不開始男性。

## 交付與最小交接

交付先說完整人物改善了什麼，否則明說未改善。附實際頭／身 A/B、必要缺陷角度與動態、可獨立重開 .blend 的絕對路徑、四門證據／缺口、採用或保留範圍、下一個 Blender 動作、核實 GitHub 狀態及實際時間／資源成本。沒有新完整候選不拿舊圖充成果；不請使用者批准明知判退的結果來解除停滯。

continuation 只留接續必要的來源／雜湊、有效證據、未登記輸出、採用範圍、主缺陷、待接回操作、停用方法、live job、資源、原始時間與真實計數；完整歷史留原位，不反覆複製巨大交接。已有診斷不重跑，新證據推翻原因即撤回推斷；提案不是實作或採用。

真正缺資訊時列已試路徑、證據、缺口、仍可做的部分與解鎖條件；blocked 依工具規則，不因困難、逾時或一次失敗自行停止。已授權離線製作、可回退開發整合與歷史保存自主完成，不反覆詢問。
